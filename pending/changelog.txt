🔧 **Claude Code アップデート**
**v2.1.245**
・Linux ディストリビューション（Arch Linux、CachyOS、Fedora Rawhide など）で glibc 2.44 を搭載している場合の起動時クラッシュを修正

**v2.1.243**
・`/usage` に Loops の詳細を追加：ループごとの実行回数、合計トークン数、実行あたりのトークン数、最終実行日時を表示し、暴走や過剰トークン消費の `/loop` タスクを簡単に発見できる
・`modelPicker` 設定を追加：`/model` ピッカーに順序付きラベル付きモデルリスト（Vertex/Bedrock ID を含む任意の ID 表記）を追加または差し替えてカスタマイズできる
・`promptCacheTtl` と `subagentPromptCacheTtl` 設定を追加：APIキー・クラウドプロバイダーのユーザーが、メイン会話では1時間のプロンプトキャッシュを維持しつつサブエージェントは5分に設定できる
・`modelPricing` マネージド設定を追加：組織との契約料金と割引乗数を、リスト価格の代わりに `/cost`・ステータスライン・テレメトリーのコスト計算に使用できる
・`/login` → Anthropic Console に「Sign in with your Console account」（推奨）のキーレスサインインを追加：APIキーを許可しない組織のユーザーもサインインできる
・`/status` に `Skipped sources` 行を追加：優先度の高いマネージドソースがアクティブなため適用されていないマネージド設定ソース（例：`managed-settings.json`）を一覧表示する
・`/mcp` と `/plugins` に、組織が認証を管理している claude.ai コネクターに `managed` マーカーを追加
・GitHub が Claude Code on the Web に未接続の claude.ai ユーザーに `/web-setup` を指すヒントを追加
・`/status` に GitHub 接続状態を示す行を追加（Pro/Max 向け）、未接続時は `/web-setup` を案内する
・`/tasks` とエージェント詳細ダイアログに、各サブエージェントが実行したモデルと effort レベルを表示
・非インタラクティブ（`-p`）および SDK セッションでリモート MCP サーバーが接続断後に復旧しない問題を修正：自動再接続または失敗として報告するようになった
・クライアント ID メタデータドキュメントをサポートするサーバー（例：Linear）からデスクトップアプリ起動の MCP サーバーサインインが "Invalid redirect URI" エラーで失敗する問題を修正
・一時的なサーバーサイド無効化がキャッシュされ後続フラグ取得が失敗した場合に起動時 auto モードが利用不可のままとなる問題を修正
・API 一時過負荷時にクライアントへ再試行要求から約1分後に auto モードのツールコールが「一時的に利用不可」として拒否される問題を修正
・`/model` ピッカーが Ultracode の選択を無視する問題を修正：Ultracode を選択すると現在のセッションに即座に適用されるようになった
・`/resume` が最新50件のセッションしか表示しない問題を修正：スクロールで追加読み込みが可能になった
・ターン途中リスタート後のクラウドセッション再開時に、通常の継続メッセージではなく pending フックやバックグラウンドタスク通知がプロンプトとして再送される問題を修正
・2.1.232 のソケットディレクトリ強化後、ユーザー名前空間やルートレスコンテナ内でクロスセッションメッセージングがサイレントに無効化される問題を修正
・スクリーンの別の部分が再描画された際にコンテナ外へはみ出したテキスト（例：`/login` のサインイン URL）の先頭カラムが失われる問題を修正
・絵文字の直後に入力したスペルミスのある単語に `spellcheck` が下線を引かない問題を修正
・最後のバックグラウンド Bash タスクが完了してもバックグラウンドサブエージェントが起動しない問題を修正
・Anthropic API がレスポンスを開始しない場合にセッションが10分以上サイレントになる問題を修正：約3分後にタイムアウトし、一度再試行後 `API Error: No response from API` を表示する
・auth・モデル利用可否・その他クライアント生成エラーメッセージがエラー行ではなくモデル出力のようにレンダリングされる問題を修正
・CI でのワークロード ID フェデレーションを修正：同一ジョブのプロセスが単一使用トークンを再交換する代わりに交換済みトークンを共有し、拒否された交換はサーバーのメッセージと共に即座に失敗する
・サインイン中のセッション（例：`/logout` 後の初回起動）でサーバー管理の `companyAnnouncements` が起動時に表示されない問題を修正
・コマンドに `$()` またはバッククォートのコマンド置換と引数が含まれる場合、`Bash(cat *)` のようなフック `if` 条件が無関係の Bash コマンドで発火する問題を修正
・`--plugin-dir` で両プラグインを一緒に読み込んだ際に `marketplace` フィールドで宣言されたプラグイン依存関係が解決されない問題を修正
・最後の LSP プラグイン無効化後に `/reload-plugins` が LSP ツールを残す問題を修正：LSP プラグイン変更前に会話再読み込みの警告も表示されるようになった
・`--agents` が無効な JSON や無効なエージェント定義をサイレントに無視する問題を修正：`--mcp-config` と同様に明確なエラーで終了するようになった
・`~/.claude.json` に無効な MCP サーバーエントリがある場合、`/status` がファイル名なしに "Found invalid entries in: ." と表示する問題を修正
・`/rename` でセッション名変更後に `/clear` がプロンプトバーからセッション名を削除する問題を修正（新しいセッション用に名前は保持される）
・`~/.claude/history.jsonl` に不正なエントリがある場合に Ctrl+R 履歴検索と上矢印履歴が壊れる問題を修正
・modifyOtherKeys / kitty プロトコルで修飾キーをエンコードするターミナルで Ctrl+`[` が vim の INSERT モードから抜け出せない問題を修正
・`NO_PROXY` に `localhost` はあるが小文字 `no_proxy` にはない場合にローカル IDE 接続が `HTTPS_PROXY` を経由してルーティングされる問題を修正：両方の大文字小文字が尊重されるようになった
・ブロックされたコマンドが exit 0 で終了した場合（例：プロキシの 403 ページを表示する `curl`）に Bash ツール結果からサンドボックスのネットワーク違反詳細が削除される問題を修正
・セッションアイドル中にレート制限ウィンドウがリセットされた後、ステータスライン `rate_limits` フィールドと `/usage` がリセット前の使用率を表示し続ける問題を修正
・`claude --teleport <session>` がコミットされていない変更がある際に、スタッシュして続行する提案ではなく終了する問題を修正
・古い GitHub CLI（`gh auth token` がない）が既に認証済みの場合に `/web-setup` が繰り返しログインを求める問題を修正
・バージョンアップの自動クリーンアップ後に Claude in Chrome の接続が失われる問題を修正：ネイティブホストが安定した `claude` ランチャー経由で起動するようになった
・[VSCode] 機能フラグ取得前に開始されたセッション（例：インストール直後）が設定済みデフォルトモードや auto モードではなくデフォルトの権限モードで開く問題を修正
・[VSCode] サブエージェントのツールアクティビティ中に展開した Focus ビューのセクションが自動的に折りたたまれる問題を修正
・起動時間を改善：サンドボックスと MCP の起動が最初のフレームをブロックしなくなり、単純起動ではサブコマンド登録をスキップ、ワークフロー検出・設定・トラストストア処理が軽量化された
・ネイティブインストールと自動更新のダウンロードサイズを改善：バイナリが zstd 圧縮になった（Linux x64 で約340 MB → 75 MB 程度）
・`ANTHROPIC_AUTH_TOKEN` で Anthropic API に直接認証するセッションの使用テレメトリーの組織への帰属を改善
・ネイティブバイナリサイズを改善：組み込みスキルとプロンプトテキストのコンパクト格納により約2 MB削減
・ネイティブビルドのメモリ使用量を改善：コードがオンデマンドで読み込まれるようになった（セッションあたり約40〜70 MB削減）
・長時間セッションのピークメモリ使用量を改善（ヒープが大きくなるにつれてより早くガベージコレクションを実行）
・SSH 経由の `/login` を改善：サインイン URL が即座に表示され、`c` キーで URL のコピー方法を報告、フルスクリーンでのテキスト選択方法のヒントを表示
・effort `xhigh`/`max` で thinking が無効の場合のエラーを改善：レベル・thinking を無効にした設定・修正として `/effort high` が明示される
・`/loop` を改善：何もすることがない連続したウェイクアップがターミナルで1行に折りたたまれるようになった
・サンドボックス化された Bash ツールのプロンプトが許可されたネットワークホストを表示しなくなった：Claude がリクエストを試みて新しいホストを承認できる
・`/model` ピッカーと組み込みの `claude-api` スキルを更新：Sonnet 5 の料金を $2/$10 per Mtok の標準リスト価格として表示
・macOS でのコンピューター使用がデスクトップ・Dock・Finder ウィンドウのクリックに他のアプリと同様に Finder 権限付与を要求するよう変更
・`/model`・`/fast`・`/effort` が Bedrock・Vertex・Foundry でもテレメトリーが無効でも即座に実行されるよう変更
・`claude remote-control` がサーバーセッション途中での環境変数削除で終了してアタッチ済み Remote Control セッションを放棄する問題を修正：復旧するようになった
・`claude remote-control`（サーバーモード）停止・再起動後に管理者・所有者ロールを持たないチームおよびエンタープライズメンバーでスタックする問題を修正
・クロスセッションメッセージング受信ソケットが30秒以内に完全な行を送信しない接続を閉じるよう変更
・別ターミナルに Remote Control が保持されている会話再開時のメッセージを改善：他のマシンのセッションにはアクセスできないことを明示するようになった
・[VSCode] 長いセッションでの履歴トリミングを改善：古いツールアクティビティ行を先に削除
・[VSCode] Claude アカウントでサインイン時の拡張機能使用テレメトリーの組織への帰属を改善
