🔧 **Claude Code アップデート**
**v2.1.226**
・バグ修正と信頼性の向上

**v2.1.225**
・Claude Codeの使用量警告にゲートウェイのspend-limitサポートを追加。上限到達メッセージに上限額・リセット時刻・オペレーターのメッセージが表示されるようになった（ゲートウェイ側も2.1.225が必要）
・信頼されていないディレクトリに対して`claude agents`にワークスペース信頼プロンプトを追加（`claude`と同じ挙動）
・長期有効な`CLAUDE_CODE_OAUTH_TOKEN`が保存済みログインの短期トークンに置き換えられ、再起動までヘッドレスセッションが壊れる一時的な401エラーを修正
・macOSでキーチェーン読み取りタイムアウト後にMCP OAuthサーバーが未認証かのように401エラーを連発する断続的な障害を修正
・autoモードで権限チェック自体のsafety-filterによる拒否が連続ブロック上限に計上されていた問題を修正。アクションは引き続き拒否されるが、モデルに再試行ではなく先へ進むよう通知するようになった
・ヘッドレスセッションや起動時にクロスセッションメッセージが通知・期限切れなく滞留し続ける問題を修正
・非常に大きな会話が圧縮された後にRemote Controlセッションを再開すると会話履歴が壊れる問題を修正
・agentsリストで別プロジェクトのセッションにホバーすると次のエージェントの起動ディレクトリが変わる問題を修正
・`claude self-hosted-runner`で`--base-dir`を作成・書き込みできない場合にセッションごとに登録後失敗していた問題を修正。起動時に明確なエラーで終了するようになった
・Claude Code on the webセッションがスタックとして誤報告され、再接続ごとに増加するイベントバックログを再送信していた問題を修正
・Remote Control改善：Claudeアプリから添付された写真が別ツール呼び出しでディスクから読み取る代わりに、直接Claudeに表示されるようになった
・[VSCode] Focus viewが最新のto-doリスト・保留中の質問のコンテキスト・解決済みの回答を折りたたんでしまう問題を修正。thinking専用の折りたたみに「Thought for Ns」が表示され、ターン完了時に再折りたたみされるようになった
・SendMessageで他のマシンのRemote Controlセッションに名前指定で会話を開始できるようになった（`ListAgents`に`name [ref]`として表示）
・SendMessage：確認済みのRemote Control送信先が、一覧取得できなかった場合に同名のローカルセッションに置き換えられることがなくなった
🔗 https://code.claude.com/docs/en/changelog
