🔧 **Claude Code アップデート**
**v2.1.198**
**新機能**
・Chrome 版 Claude が一般提供（GA）開始
・`claude agents` でバックグラウンドエージェント通知を追加 — 入力待ち・完了セッションが `Notification` フック（`agent_needs_input` / `agent_completed`）を発火
・`/dataviz` スキルを追加 — チャート・ダッシュボードのデザインガイダンスと実行可能なカラーパレットバリデーターを提供
・Gateway 改善 — AWS 上の Claude Platform（anthropicAws）をアップストリームプロバイダーとして追加、model-not-found レスポンスがフェイルオーバーチェーンを進めるように
・バックグラウンドエージェントのワークフロー改善 — `claude agents` から起動されたエージェントが worktree でのコード作業完了時に commit・push・ドラフト PR を自動作成するように
・Explore エージェントがメインセッションのモデル（opus 上限）を継承するように（従来は haiku 固定）
・サブエージェントと context compaction がセッションの extended thinking 設定を継承、委譲タスクの出力品質が向上

**バグ修正**
・応答途中の短い通信断（ECONNRESET 等）が turn を中断する問題を修正 — バックオフ付きリトライに
・サンドボックスプロセスが同一ホストに繰り返しアクセスした際の過剰なバックグラウンド分類子リクエストを修正
・web・desktop・VS Code のタスクパネルでバックグラウンドタスクが「Running」のまま固まる問題を修正
・エージェントチームの信頼性向上 — API エラーで死亡したチームメートが「failed」を lead に報告、応答しないチームメートへのメッセージが即座に再試行を促すように
・ブランチ切り替えやセッション外コミット時に `/diff` パネルが更新されない問題を修正
・フルスクリーンモードで Markdown テーブルの右端がオーバーフローして折り返される問題を修正
・AWS 上の Claude Platform / Mantle で STS トークン失効時に「Please run /login」で行き詰まる問題を修正 — `awsAuthRefresh` が自動実行されるように
・macOS バックグラウンドエージェントセッションで Local Network entitlements 追加により「no route to host」を修正
・worktree の出入り後に `/desktop` が「Cannot determine working directory」で失敗する問題を修正
・macOS で agents ビュー表示中に約52秒ごとに「Reconnecting…」が繰り返し表示される問題を修正
・`claude attach <id>` 内で `←` を押すとシェルに戻ってしまう問題を修正（エージェントビューに遷移するように）
・`claude --bg` を `--print`/`-p` と組み合わせると接続不能なセッションがサイレントに作成される問題を修正 — 競合フラグを事前に拒否
・SDK・デスクトップアプリセッションでワークフロー進捗ビューの最初のエージェントがリストから消える問題を修正
・`.claude/rules/` の条件付きルールがシンボリックリンク経由の場合に読み込まれない問題を修正
・macOS Warp のフルスクリーンモードで Cmd+クリックが URL を開かない問題を修正
・フルスクリーンモードでダブルクリックの単語選択がスキームを含む URL 全体を選択するように修正
・plan mode でセッション開始時に読み取り専用ツール呼び出しが自動許可されない問題を修正
・`/branch` のデフォルトフォーク名が compaction サマリーから派生していた問題を修正（最初の実プロンプトから派生するように）

**改善**
・focus mode 改善 — ターン中のサブエージェントがアクティビティサマリーに表示、完了バックグラウンド通知が単一カウントにまとめられる
・highlight.js 11 へのアップグレードによりコードブロック・diff・ファイルプレビューのシンタックスハイライト精度が向上
・Mac から SSH 接続時のキーボードショートカットヒントが opt/cmd 表記に（従来は alt/super）
・API リトライ UX 改善 — 2回目の試行後にエラー理由を表示、API 過負荷時にステータスページリンクを表示
・agents ビューから `/login` でサインインダイアログを開けるように
・サブエージェントが起動エージェントからのメッセージを通常のタスク指示として扱うように
・`/agents` ウィザードを削除 — サブエージェントの作成・管理は Claude に依頼するか `.claude/agents/` を直接編集
