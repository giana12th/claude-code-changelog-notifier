🔧 **Claude Code アップデート**
**v2.1.167**
・バグ修正と信頼性の向上

**v2.1.166**
・`fallbackModel` 設定を追加 — プライマリモデルが過負荷または利用不可の場合に試行される最大3つのフォールバックモデルを設定可能。`--fallback-model` はインタラクティブセッションにも適用
・デニルールのツール名位置でグロブパターンサポートを追加（`"*"` はすべてのツールを拒否）；許可ルールはMCP以外のグロブを拒否し、デニルールの不明なツール名は起動時に警告
・クロスセッションメッセージング強化：`SendMessage` から他の Claude セッション経由でリレーされたメッセージはユーザー権限を持たない — 受信者はリレーされた権限リクエストを拒否し、オートモードはそれらをブロック
・`MAX_THINKING_TOKENS=0`、`--thinking disabled`、およびモデル単位の思考切り替えは、Claude API 経由でデフォルトで思考するモデルで思考を無効化（3Pプロバイダーは変更なし）
・Claude Code は予期しない再試行不可エラーが API に拒否された場合、フォールバックモデルで1回再試行；認証、レート制限、リクエストサイズ、トランスポートエラーはすぐに表示
・`claude update` はダウンロード前にターゲットバージョンをアナウンス（以前はサイレント）
・`claude agents`：リストに URL を入力すると、その URL を含むセッションでフィルタリング
・処理不可画像が送信された際の「image could not be processed」エラーと追加トークン使用の反復発生を修正
・リモートセッションが、スタートアップ時のワーカー登録中に短時間のバックエンド障害が発生した場合、永続的にスタックする問題を修正
・2026.1+ の JetBrains IDE ターミナル（IntelliJ、PyCharm、WebStorm など）で同期出力を有効化してちらつきを修正
・Kitty キーボードプロトコルを使用するターミナル（WezTerm、Ghostty、kitty）で Shift+非ASCII文字（例：Shift+ä → Ä）がドロップされる問題を修正
・Windows で殺されたプロセスの子がその出力パイプを保持している場合、PowerShell コマンド検証が時間予算をはるかに超過してハングする問題を修正
・macOS で daemon が終了した際、接続中に orphaned `claude --bg-pty-host` プロセスが 100% CPU でスピンする問題を修正
・`/voice` 切り替え後の古い認証チェックをクリアするために voice モードが `/login` を必要とする問題を修正
・無効なエントリを含むマネージドセッティングが、残りの有効なポリシーの実装をサイレントで無効化する問題を修正
・マネージドセッティング `allowedMcpServers`/`deniedMcpServers` 述語が `${VAR}` 参照を使用する場合にマッチしない問題を修正
・バックグラウンドエージェントセッションが git worktree に入った場合、`claude agents` から再度開かれたときに「No conversation found」でクラッシュループする問題を修正
・Ctrl+O トランスクリプトビューでストリーミング中に思考テキストが重複する問題を修正
・リモートセッション内で実行されている場合、`/doctor` が矛盾した「リモートセッション内ではない」チェックを失敗と表示する問題を修正
・`claude agents` のディスパッチと返信入力で複数行プロンプトを入力する場合、カーソルが最初の行の終わりで固まる問題を修正
・Unicode サポートのない端末でバックグラウンドエージェント行の間に空白行が表示される問題を修正
