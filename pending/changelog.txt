🔧 **Claude Code アップデート**
**v2.1.157**
・プラグインの自動ロード: `.claude/skills` ディレクトリのプラグインがマーケットプレイスなしで自動ロードされるように
・プラグイン初期化コマンド: `claude plugin init <name>` でプラグイン用スケルトンを `.claude/skills` に生成
・オートコンプリート強化: `/plugin` 引数にサブコマンド、インストール済みプラグイン名、既知マーケットプレイスのプラグイン名を補完
・Agent Sessions: `settings.json` の `agent` フィールドがディスパッチセッションで尊重される、`--agent <name>` でオーバーライド可能
・EnterWorktree: セッション中に Claude 管理ワークツリー間の切り替え可能に
・バックグラウンドエージェント: 完了後、ワークツリーがアンロック状態で残され、`git worktree remove`/`prune` で手動削除可能に
・tool_decision イベント: `OTEL_LOG_TOOL_DETAILS=1` 時に `tool_parameters`（bash コマンド、MCP/スキル名）を含める
・【バグ修正】ゼロバイトまたは破損した画像がクラッシュせずテキストプレースホルダーに
・【バグ修正】auto/bypass-permissions モード時の意図しない権限プロンプトを修正
・【バグ修正】完了セッションのリタイア処理、Esc キャンセル、ワークツリー孤立化を修正
・【バグ修正】スリープ/ウェイク後の日付表示、tmux clipboard の copy-on-select を修正
・【バグ修正】`--worktree` 使用時の canonical repo root 復帰を修正
・【バグ修正】`/model` ピッカーの "Newer version available" ヒント誤表示を修正
・【バグ修正】全画面モードのマークダウン記号表示、ターミナルフリーズ、スクロールバック重複を修正
・【バグ修正】VSCode/Cursor/Windsurf のペースト重複、WSL2 の画像ペーストを修正
・パフォーマンス: メッセージレンダリング再計算を排除して長い/再開セッションを高速化
・VS Code: GPU アクセラレーション無効化でテキスト破損を防止
・Feature of the Week: ステータス領域に通知として表示
・オートコンプリート: エージェント dispatch 入力で部分文字列マッチング
・ヘルプテキスト: "bash commands will be sandboxed" バナー削除、"/ide for..." ヒント削除
・`"workflow"` キーワードをプロンプトで無視する設定追加（`/config` で "Workflow keyword trigger"）
