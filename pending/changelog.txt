🔧 **Claude Code アップデート**
**v2.1.147**
・確定的なマルチエージェントオーケストレーション用の `Workflow` ツールを追加。デフォルトは無効 — 有効化するには `CLAUDE_CODE_WORKFLOWS=1` を設定する
・ピン留めされたバックグラウンドセッション（`claude agents` 内の `Ctrl+T`）がアイドル時も起動し続け、Claude Code のアップデートを適用するためにその場で再起動されるようになった。メモリ不足時はピン留めされていないセッションの後に解放される
・`/simplify` を `/code-review` にリネーム。選択した労力レベルで正確性バグを報告するようになった（例: `/code-review high`）。`--comment` を渡すとインライン GitHub PR コメントとして結果を投稿できる。従来のクリーンアップ・修正動作は削除された
・prototype-pollution および thenable-based エスケープに対して REPL と Workflow ツールのサンドボックスを強化
・自動アップデーターを改善: 一時的なネットワーク障害を再試行し、失敗時に具体的なエラーカテゴリと OS エラーコードを報告し、更新失敗時に現在のバージョンを表示する
・大きなファイル編集の差分レンダリングパフォーマンスを改善
・プロンプト履歴が連続する重複エントリを記録しなくなった — 矢印↑キーでプロンプトを呼び出して再送信しても別のコピーが追加されない
・エンタープライズログイン制限（`forceLoginOrgUUID` および `forceLoginMethod` マネージド設定）がサードパーティプロバイダーおよび API キーセッションに対して適用されていなかった問題を修正
・`!` コマンド出力の `&` が `&amp;` として表示される問題を修正。ヘッドレスマシンで `gcloud auth login` 等のコマンドから URL をコピペする際に問題が生じていた
・ヘッドレス/SDK モードで未知のスラッシュコマンドが何もせず静かに無視されていた問題を修正 — 現在はエラーメッセージを表示する
・小さい端末でフルスクリーンでない場合に `/help` がタブヘッダーが壊れた状態で表示され、1 ページにコマンドが 1 件しか表示されない問題を修正
・シェルスナップショットがアンダースコアで始まる名前のユーザー関数を削除していた問題を修正。それらを参照するエイリアスが壊れていた
・`tools:` フロントマターに複数の `Agent(...)` タイプを宣言したプラグインエージェントが最後のエントリ以外をすべて削除していた問題を修正
・`PowerShell(git push*)` のようなフック `if` 条件が一致しない問題を修正 — `PowerShell(*)` のみが機能していた
・PowerShell ツールがデフォルトフォーマッターに依存するコマンドの出力を削除していた問題を修正
・Windows で、PowerShell スクリプト実行に対して「はい、今後は確認しない」を選択すると、以降の実行で実際にマッチするルールが書き込まれるようになった
・winget または Microsoft Store 経由でインストールした `pwsh` を使用した際に、PowerShell ツールが Windows で終了コード 1 で失敗する問題を修正
・`/effort` のスライダーが間違ったレベルで開く問題を修正 — 現在の労力レベルから開始するようになった
・MCP サーバーのページネーションで 2 ページ目以降のリソース・テンプレート・プロンプトが削除される問題を修正
・Windows Terminal でストリーミング中のアタッチされたバックグラウンドセッションでフルスクリーンがちらつく問題を修正
・Windows でバックグラウンドジョブのワークツリーを削除する際に NTFS ジャンクションをたどってメインリポジトリに入り込む問題を修正
・スキルまたはカスタムスラッシュコマンドのみが入力されたセッションを `/background` が拒否する問題を修正
・ユーザーまたはスキルが明示的に `AskUserQuestion` に依存している場合に auto モードが抑制していた問題を修正。auto モード分類器がユーザーの回答を意図シグナルとして認識するようになった
・`/theme` の「新しいカスタムテーマ」およびカラーエディターダイアログが Esc に反応しない問題を修正
・Agent SDK 経由で実行した際のストリーミングセッション終了時の未処理例外を修正
・Windows でスクロール完了待機中のまれなハングを修正
・バックグラウンドセッションの結果にワイド（CJK）文字が含まれる場合の Windows のエージェントビューリストの古いデータと重複行を修正
・貼り付けたテキストが実際のコンテンツではなく `[Pasted text #N]` プレースホルダーとしてエージェントに渡される問題を修正
・プラグインのマニフェストがデフォルトディレクトリと重複するパスを列挙していた場合に `claude plugin details` および `/plugin` のプラグインコンポーネント数が 2 倍になる問題を修正
・バックグラウンドセッションが「今後は確認しない」で許可済みのツールのパーミッションを再度要求していた問題を修正
・GNOME Terminal の右クリックおよびミドルクリックペーストでテキストが挿入されない問題を修正
・`CLAUDE_CODE_SUBAGENT_MODEL` がエージェントチームによってスポーンされた teammate プロセスに適用されない問題を修正
・タブまたは改行が後に続くスラッシュコマンドが未知のコマンドとして扱われる問題を修正
・`/plugin`、`/status`、`/mobile`、`/sandbox`、`/permissions` メニューのいくつかの間隔とレイアウトの不具合を修正
・削除済みメディアをモデルが繰り返し再読み込みしようとする問題を引き起こす、ストリップされた画像の問題を修正
