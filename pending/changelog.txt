🔧 **Claude Code アップデート**
**v2.1.173**
・Fable 5 モデル名に `[1m]` サフィックスが付いている場合に正規化されなかった問題を修正 — Fable 5 はデフォルトで 1M コンテキストを含むため、サフィックスが自動的に除去されるようになった
・sandbox が settings で有効になっている場合、Windows 起動時に誤って "sandbox dependencies missing" 警告が表示される問題を修正

**v2.1.172**
・サブエージェントが独自のサブエージェントをスポーンできるようになった（最大5段階）
・Amazon Bedrock で `AWS_REGION` が設定されていない場合、AWS SDK の優先順位に合わせて `~/.aws` 設定ファイルから AWS リージョンを読み取るようになった。`/status` でリージョンの取得元を確認できる
・`/plugin` でマーケットプレイスのプラグインを閲覧する際に検索バーを追加
・`claude_code.lines_of_code.count` OTEL メトリクスに `model` 属性を追加
・usage credits がない状態で 1M コンテキストを使用するセッションが永続的にスタックする問題を修正 — セッションが自動的に標準コンテキスト制限以下にコンパクトされるようになった
・会話に複数の画像が含まれている場合に "an image in the conversation could not be processed and was removed" エラーが繰り返し表示される問題を修正
・ワーカーが返答した後も agents ビューがセッションを最大 30 秒間 Working 状態のスピナー付きで保持する問題を修正
・バックグラウンドエージェントが事前ウォームされたワーカーにディスパッチされた際、別ディレクトリのプロジェクト設定（`.mcp.json` の承認・信頼）を読み取る可能性があった問題を修正
・デーモン自動更新後、古いバージョンで開始されたセッションへのバックグラウンドセッション attach が EAUTH で失敗する問題を修正
・スポーンしたネストエージェントが停止した後、バックグラウンドサブエージェントが agent パネルで "active" のままスタックする問題を修正
・`claude agents` dispatch 入力の `/model` 提案が誤ったスラッシュプレフィックス付きで表示され、組織で無効化されたモデルが表示される問題を修正
・`availableModels` の制限がサブエージェントのモデルオーバーライド、agent dispatch モデルピッカー、アドバイザーモデルに適用されない問題を修正
・`availableModels` の allowlist に `claude-opus-4-8` のようなバージョン固有 ID を使用すると `/model` ピッカーの Opus および Sonnet 1M 行が非表示になる問題を修正
・Bedrock の `/model` ピッカーがプロバイダーが提供しないモデルを提示する問題を修正 — 選択するとセッションモデルがサイレントに切り替わり、複数行に選択マーカーが表示されていた
・`ANTHROPIC_DEFAULT_OPUS_MODEL` に既に 1M コンテキストサフィックスが含まれている場合、モデル ID に重複したサフィックス（例：`[1M][1m]`）が付く問題を修正
・権限のあるユーザーの plan mode で `opusplan` モデル設定が 1M コンテキストなしで機能しない問題を修正；`opusplan[1m]` ワークアラウンドが plan mode で Opus に正しく切り替わるようになった
・`WebFetch(domain:*.example.com)` ワイルドカードドメインルールが allow・deny・ask ポジションでサブドメインに一致しない問題を修正；パターン中間のワイルドカード（例：`Read(secrets-*/config.json)`）を持つファイルパーミッションルールが起動時に拒否される問題も修正
・サブエージェントのチャットタブが開いている状態で上矢印キーによるプロンプト履歴にメインエージェントのプロンプトが表示される問題を修正
・リモートセッションでメモリ recall がマウントされたチームメモリストア（`CLAUDE_MEMORY_STORES`）を見つけられない問題を修正
・プロンプト文字列やコメントで `Date.now()`/`Math.random()` に言及しているだけのスクリプトをワークフローバリデーションが拒否する問題を修正
・マウストラッキングを完全にサポートしない Windows コンソールでのマウストラッキングを無効化
・長いプラグインリストから戻った後に `/plugin` マーケットプレイスリストのカーソルが失われる問題と、プラグインブラウザから Esc を押すと誤ったタブに戻る問題を修正
・ストリーミングのツール使用状態が変化しない場合、冗長なメッセージ正規化を削除し、完全なメッセージ履歴変換を回避することで長い会話でのパフォーマンスを向上
・アイドル時の CPU 使用量を削減：アイドル中に `/goal` ステータスチップが 5 Hz でターミナルを再レンダリングしないようにし、サブエージェントが並列実行中の UI 再レンダリングを削減
・Claude in Chrome のツール読み込みを改善：ブラウザツールがツールごとに個別ではなく、単一のバッチ呼び出しで読み込まれるようになった
・非インタラクティブの Usage Policy 拒否メッセージを改善し、新しいセッションの開始またはモデルの変更を提案するようにした
・`/code-review` で claude.ai にサインインしていない場合も `ultra` オプションを表示し、クラウドレビューには claude.ai アカウントが必要な旨を説明するようにした
・Remote Control フッターインジケーターを "/rc active" に短縮し、幅の狭いターミナルでは非表示にした
・pending loops がコンテナを維持しないリモートセッションで `/loop` のプロモーションを停止
・[VSCode] PowerShell ツール呼び出しが適切なコマンド表示とパーミッションダイアログではなく生の JSON としてレンダリングされる問題を修正；表示されるシェル出力から ANSI エスケープコードを除去
