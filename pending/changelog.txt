🔧 **Claude Code アップデート**
**v2.1.211**
・`--forward-subagent-text` フラグと `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 環境変数を追加。stream-json 出力にサブエージェントのテキストと思考を含めることが可能に
・【セキュリティ】チャットチャネルに中継される権限プレビューで、双方向オーバーライド・ゼロ幅・そっくりな引用符などの特殊文字を無効化し、ツール入力が承認メッセージを視覚的に改ざんできないよう修正
・【修正】PreToolUse フックの `ask` 決定をオートモードがオーバーライドしていた問題を修正。フックの `ask` がプロンプトで最低限として機能するように
・【修正】多くのセッションが1つの認証情報ストアを共有している場合、スリープ解除後に全セッションが同時にログアウトしていた問題を修正
・【修正】アイドル状態のウェブセッション後にプラグイン MCP サーバーが再接続されなかった問題を修正
・【修正】Vertex/Bedrock でモデルが明示的に設定されている場合、起動時にデフォルト Opus モデルを試みず、スプリアスな代替通知も出力しないよう修正
・【修正】明示的なモデル上書きで起動したサブエージェントが、再開またはフォローアップメッセージ時に親のモデルに戻っていた問題を修正
・【修正】プロジェクト設定除外時にネストされた `.claude/rules/*.md` ファイルが読み込まれていた問題を修正
・【修正】DOS デバイス接尾辞（`.prn`）や末尾のドットで終わるファイル名を受け入れ、複数のハードリンクを持つファイルを拒否するよう検証ロジックを修正
・【修正】リモートおよび CLI セッションから Chrome 内へのファイルアップロードを修正
・設定タブ・統計情報・差分ビュー等のローディング状態を表示する際の 300ms 遅延を修正
・停止したばかりのバックグラウンドセッションを再度開くとき、同じセッション ID で空白のチャットが開始される問題を修正
・`CLAUDE_CODE_MAX_OUTPUT_TOKENS` などの integer 環境変数が科学記法とデジット区切り記号（`1e6`、`64_000`）をサポート
・メモリインデックス警告でフロントマターと HTML コメントを除外し、読み込まれたコンテンツのみを測定するよう修正
・ターミナルレイアウトとレンダリングパフォーマンスを改善
・Windows でのシンク済みスキル/プラグインディレクトリ命名を強化
・`/clear` 後も CCR ウェブ取得/検索プロキシが動作するよう修正
・「常に許可」権限ルールをリポジトリルートに保存し、git ワークツリー全体でセッション間にわたって有効に
・Vim モードの S/s（代替文字/行）が NORMAL モードで動作するよう修正（vim 標準動作に準拠）
🔗 https://code.claude.com/docs/en/changelog#2-1-211
