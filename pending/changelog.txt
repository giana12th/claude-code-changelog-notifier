🔧 **Claude Code アップデート**
**v2.1.232**
・`subagent_type: "fork"` のサブエージェントがデフォルトで会話全体とプロンプトキャッシュを引き継ぐようになった。インタラクティブセッションでのチームメイト以外のエージェント起動がデフォルトでバックグラウンド実行になった
・プロンプトで `@` を入力すると名前で別のClaudeセッションをメンションでき、Claudeが `SendMessage` を使って直接そのセッションにアクセスする
・`SendMessage` が、refで確認を求めるのではなく、1つのライブセッションに完全一致する名前に直接配信するようになった
・同じマシン上のインタラクティブセッションが一意な名前を保持するようになった。既存のライブセッションと同じ名前でセッションを開始または名前変更すると `name-word-word` のバリアント名が付与され通知される
・`/config` に「Dialog expiry」と「Messages from your other sessions」（クロスセッション受信の accept/hold/refuse）の行を追加した
・GitLabトークンファミリー（`glrt-`, `gloas-`, `glptt-`, `glagent-`, `glimt-`, `glsoat-`, `glcbt-`, `glft-`, `glffct-`）のシークレット編集と、ルーティング可能な `glpat-`/`gldt-` トークンの完全編集を追加した。`glab` CLIの設定ストアが `gh` と同様のサンドボックスおよびクレデンシャルパス保護を受けるようになった
・プラグインマーケットプレイスにGitLabサポートを追加した。`gitlab.com` のリポジトリURL（ネストされたサブグループを含む）が `github.com` URLと同様にクローンされるようになり、クローン認証失敗時のヒントが実際のgitホスト名を示すようになった
・設定で `additionalMarketplaces` と `allowedMarketplaces` が `extraKnownMarketplaces` と `strictKnownMarketplaces` のよりわかりやすいエイリアスとして受け付けられるようになった
・エンタープライズポリシー: `blockedMarketplaces` のURLエントリが、CLIがgitクローンとして分類した場合もそのURLをブロックし続けるようになった
・Gateway: `desktop:` オーバーレイが手動で列挙した11個のキーのみから全リリース済みDesktop設定を受け付けるようになり、起動時にDesktop自身のスキーマで検証される。不明または無効なキーは起動を失敗させる
・Gateway: 空の `managed.policies[].match.groups`/`admin.admin_groups` エントリや不正な `email_domain` 値（空、または `@`・空白・カンマを含む）が、誰にもマッチしないまたはadminアクセスを付与するのではなく、起動時に失敗するようになった
・Fableへのアクセス権を持つ組織に対して、Fable 5が `/advisor` でアドバイザーとして再び提供されるようになった。使用クレジットの同意は `/model fable` で設定する
・変数書き込みパラメータが `$PSDefaultParameterValues` をサイレントに上書きし後続コマンドのファイルアクセスをリダイレクトできたPowerShellの権限バイパスを修正した
・Git BashがパスバリデーションでRegularファイルとして見えるCygwinスタイルのシンボリックリンクを辿っていたWindowsの権限バイパスを修正した。これらを通じた書き込みに権限承認が必要になった
・ネストされたgitリポジトリが親ディレクトリから信頼を継承していた問題を修正した。各リポジトリが独自の信頼確認を必要とするようになった
・サーバーがプロトコルバージョンプローブに応答しないまたは不正な応答を送信した場合、MCPコネクションが30秒のフルタイムアウトまでハングしていた問題を修正した
・クラウドセッション内のブリッジでホストされたRemote Controlセッションがそのセッションのトランスクリプトまたはクレデンシャルを継承していた問題を修正した
・Claude DesktopまたはIDEから開始したRemote Controlセッションがローカルセッション再開のたびに新しいclaude.aiセッションとして表示されていた問題を修正した。既存のセッションに再接続するようになった
・アイドル中にRemote Controlセッションが新しく接続したクライアントに到達不能として見えていた問題を修正した
・セッションワーカーの再起動時にRemote Controlブリッジセッションが会話履歴を復元しなかった問題を修正した
・Remote Control: claude.aiまたはアプリからセッションが削除された会話を再開すると、ログインに関するエラーメッセージを出して失敗するのではなく代替セッションを開始するようになった（v2.1.227でリグレッション）
・管理設定の読み込みに失敗した際、Cloud gateway `/login` が「Press Enter to continue」の後サイレントに終了するか応答なしのターミナルを残していた問題を修正した。理由が表示されるようになった
・音声サービスが接続を拒否した際、ネイティブビルドのボイスモードが「listening…」のまま固まる問題を修正した。拒否が即座に表示されるようになった
・mTLSクライアント証明書のローテーションに再起動が必要だった問題を修正した。Claude Codeが接続エラー時に更新された証明書とキーを自動的に再読み込みするようになった
・不正なAWSまたはVertexリージョン値がリクエストURLの構築に使用されていた問題を修正した。デフォルトリージョンにフォールバックするようになった
・Bedrock、Vertex、およびgatewayデプロイでストリームのアイドルタイムアウトエラーが復旧せずリクエストを失敗させていた問題を修正した
・切り詰められたテキストを含むコンテンツサイズのオーバーレイが1列幅広くレンダリングされ、先頭切り詰めテキストが省略記号に折りたたまれていた問題を修正した
・長いシェルコマンドまたはエージェント説明のプレビューが絵文字の途中で切れた際の文字化けを修正した
・`known_marketplaces.json` への並行書き込みによりプラグインマーケットプレイスがサイレントに登録解除されることがあった起動時の競合状態を修正した
・再起動後も継続する作業が実行中の場合に `/update` と `/tui` が再起動を拒否していた問題を修正した
・SDKおよびリモートセッションで使用制限ガイダンスが利用できないスラッシュコマンドを提案していた問題を修正した
・`--advisor fable` のインタラクティブ起動の同意メッセージが、終了したばかりのインタラクティブセッションで `/model fable` を実行するよう指示していた問題を修正した
・フルスクリーンストリーミングを改善した。更新のたびに会話全体が再正規化されなくなったため、長いセッションでも応答性が維持される
・管理設定の承認ダイアログを改善した。エンドポイントURLを表示し、テレメトリのみの変更に対してより明確な文言を使用し、ルーティンなOpenTelemetryオプションをスキップし、サーバー管理のサンドボックスバイナリオーバーライド（`sandbox.bwrapPath`, `sandbox.socatPath`, `sandbox.ripgrep`）に対して承認を要求するようになった
・`/feedback` と `/bug` が、Claudeが応答中に呼び出された際、ターンの完了を待たず即座に開くようになった
・`/plugin install plugin@marketplace` がまずマーケットプレイスを更新するようになったため、新しく公開されたプラグインを手動でマーケットプレイスを更新せずにインストールできるようになった
・`/code-review` のhigh・xhigh・maxエフォートが他のレベルと同様にバックグラウンドエージェントで実行されるようになった
・貼り付けおよびクリップボードの画像がイベントループをブロックせずに読み込まれるようになった
・Remote Controlがネットワーク障害後約30分間再接続を継続するようになり、1時間内に数回の障害が発生してもドロップしなくなった
・Remote Control: 会話の再開が、同じマシン上でRemote Controlを保持している別のClaude Codeからサイレントに奪い取らなくなった。移動するには `/remote-control` をそこで実行する
・エージェントパネルを更新した。完了したサブエージェントが `/tasks` フッターヒントとともに即座に非表示になり、「↓ N more」オーバーフロー表示が視認性のために左に移動した
・Remote Control: ターミナルがセッションが別のデバイスに引き継がれたか、別のアプリから終了されたか、削除されたかを表示し、それを取り消すような再接続を提案しなくなった
・Bashの入力リダイレクション（`< file`）がすべてのプラットフォームで引数のスペルと同様に権限チェックされるようになった
・完了したバックグラウンドエージェントを再開する際に表示されるメッセージを短縮した
・Coworkセッションがユーザースコープのメモリファイルからの外部@インポートをインライン展開しなくなった
・共有 `/tmp` 上の自動生成されるクロスセッションメッセージングソケットディレクトリを強化した。事前に設置されたシンボリックリンクや他のユーザーのディレクトリを使用する代わりに拒否するようになった
・保護されたパスのバイパスに対してLinuxファイルシステムサンドボックスを強化した
・`sandbox.ripgrep` がユーザー・管理・`--settings` の設定からのみ有効になるように変更した。プロジェクト設定がサンドボックスのripgrepバイナリを上書きできなくなった
・カスタムサブエージェントの作成を提案するスタートアップのヒントと、`/powerup` ツアーのマッチングナッジを削除した
