🔧 **Claude Code アップデート**
**v2.1.282**
・幅の広いターミナルでClaudeの文章幅を制限する`maxProseWidth`設定を追加（テーブルとコードブロックはフル幅を維持）
・プロジェクトの設定ファイルで無視された、またはテレメトリをオフにしたテレメトリ変数を一覧表示するstartup noticeと`/status`・`claude doctor`エントリを追加
・`managed-mcp.json`と排他的に`claude --chrome`を実行できるようにする`allowClaudeInChromeWithManagedMcp` managed settingを追加；Chromeがブロックされたときのエラーにもこのキー名が表示されるよう変更
・Postgresの短時間の停止（データベースフェイルオーバーなど）中に`/readyz`をready状態に保つため、Claude apps gatewayに`store.readiness_grace_seconds`を追加
・fullscreenモードの`/feedback`下書きリストにスクロールバーを追加（マウスがリスト上にある間に表示）
・サードパーティgateway経由で回答されたターンなど、APIが復号できないweb検索結果を含む会話履歴ですべてのリクエストが400エラーで失敗する問題を修正
・継続または再開されたセッション（`--continue`、`--resume`）が変更された形式で以前のメッセージを再送信し、APIがClaudeの以前の推論を破棄する可能性があった問題をさらに修正
・`/model`、`/rename`、`/artifacts`など即時スラッシュコマンドをClaudeが作業中に使用した際、以前のextended thinkingが破棄される問題を修正
・`--tools`リストが以前の会話で提示されたビルトインツールを省略して再起動した際、継続または再開した会話が以前のextended thinkingを失う問題を修正
・"Invalid `data` in `redacted_thinking` block" APIエラーですべてのターンが失敗するセッションを修正；thinking blocksを破棄して1回リトライするよう変更
・サマリーリクエストが拒否された際にcompactionが失敗する問題を修正；フォールバックモデルでリトライするよう変更
・thinkingがオフでeffortがhighより上のセッションで、セーフティ関連のモデル切り替え後に"Effort 'xhigh' isn't available with thinking turned off"エラーでターンが失敗する問題を修正
・SDK-hostedセッション（Claude Desktopなど）で未回答のFable usage-credits promptがモデルを切り替える問題を修正；ターンが終了するよう変更、Remote Controlクライアントにmodel-switch noticeが表示されるよう変更
・フルFable model idを指定した`/model`がusage credits promptを表示せずAPIエラーで停止する問題を修正
・別プロセスがミッドリフレッシュで終了または強制終了された後、"another Claude Code process is refreshing it"ログインエラーで最大1分間リクエストが失敗する問題を修正
・別のClaude Codeウィンドウがサインインを更新中に開始されたセッション（複数VS Codeウィンドウで一般的）がorganization policy fetchをリトライしない問題を修正
・リポジトリシンボリックリンク経由でCLAUDE.mdとルールを読み込む際、`..`やmacOSの`/Network`または`/.vol`スタイルカーネルパスに到達、またはmacOSの`/home`へのルールリンクが一覧表示される問題を修正
・設定ファイルでパターン中央に`:*`を含むBash permissionルールがスキップされる問題を修正（`--allowedTools`は尊重していた）；すべてのソースで機能するよう変更、マッチ方法についてstartup warningを表示
・リモートセッションのworkerが再起動した際に、復元されたpermission promptで承認されたコマンドが2回実行される問題を修正
・`disableClaudeAiConnectors`や`allowManagedPermissionRulesOnly`などのboolean lock keysで誤った値を無視するmanaged settingsを修正；ロックが適用され、startupでキー名が表示されるよう変更
・ネストされた1つの値が無効な場合にmanaged `permissions`・`autoMode`・`worktree`・`attribution`設定が完全に無視される問題を修正；残りのブロックは引き続き適用されるよう変更
・managed `allowManagedPermissionRulesOnly`下で、repository・user・`--add-dir`のスキル・コマンド・skills-directoryプラグインマニフェストが`allowed-tools`を通じて自分自身のツールを事前承認する問題を修正
・Amazon BedrockとBedrock Mantleのsafeguardブロックメッセージにrequest IDが表示されない問題を修正；ブロックメッセージにmessage IDも表示されるよう変更
・Vertex AI: Claude Codeが認識しない新しくリリースされたモデルに対してweb searchが提供されない問題を修正
・BashとPowerShellがディスク容量不足を"Exit code 1"として隠し、大きな出力ファイルをtempに残す問題を修正
・同じ呼び出しで他のパラメーターも無効な場合、tool input validation errorが1つの不明・欠落・誤ったパラメーターのみ表示する問題を修正；それらがすべて列挙されるよう変更
・セッション中にターミナルのbracketed paste modeがリセットされた後、貼り付けた複数行テキストが1行ずつ送信される問題を修正
・`SessionStart`フックのあるプロジェクトでstartup時にプロンプトのサンプルテキストが点滅して消える問題を修正
・fullscreenモードで起動時に最初のフレームの前に空白画面が点滅する問題を修正
・ターミナルがまだ高さがある状態で短くなった際（シェルコマンドがストリーム出力中にプロンプト行を削除するなど）、non-fullscreenレンダラーに文字化け・誤配置された行が表示される問題を修正
・再描画された行のCJK文字や絵文字が次の行に折り返す際、diffの最終列に残る古い文字を修正

・`/install-github-app`がキャンセル後に"cancelled"と表示しつつブランチのpushとAPIキーシークレットの保存を続ける問題を修正；中止すると残りのステップが停止し、完了した内容が報告されるよう変更
・Bedrock・Vertex他サードパーティプロバイダーで`/feedback`・`/bug`・`/share`が保存中にキャンセルしてもレポートファイルを保存し続ける問題を修正
・設定ファイルでまだ有効または読み取れない場合にpluginアンインストールが成功を報告してオプションを削除する問題を修正；停止してファイル名を表示するよう変更
・削除後にインストール済みプラグインのリストが読み取れない場合にpluginアンインストールがオプションとシークレットを削除する問題を修正；それらが保持され、アンインストールがその旨を表示するよう変更
