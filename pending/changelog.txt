🔧 **Claude Code アップデート**
**v2.1.222**
・worktree分離セッションとそのサブエージェントがメインチェックアウトに対して破壊的なgitコマンドを実行できた問題を修正。すべてのセッションタイプでファイル編集とBashに分離が適用されるようになった
・PreToolUse自動許可フックがバックグラウンドエージェントタスク（サマリー、圧縮、リネーム）でツール制限をバイパスしていた問題を修正
・TeamおよびEnterpriseの`/usage-credits`で、以前のリクエストが却下されたメンバーが新しいリクエストを送れなくなっていた問題を修正
・HTTPSプロキシ環境下でスタートアップの接続チェックがハングして失敗する問題を修正。APIリクエストと同じプロキシ対応トランスポートを使用し、タイムアウト時に明確なメッセージが表示されるようになった
・実際に完了したレスポンスで「Connection closed mid-response」エラーが報告される問題を修正
・`/usage`がMCPサーバーへの使用量を過剰に集計していた問題を修正。サーバーのシェアはツール結果を実際に消費したリクエストのみを反映するようになった
・ブランチのpush後（GitHub REST API経由を含む）に作成されたPRにセッションがリンクされない問題を修正
・org制限環境で`model: opus`スタイルのサブエージェント・チームメートのファミリーエイリアスが、親モデルにフォールバックせず、ファミリー内で最新のorg許可モデルにステップダウンするようになった
・カスタム`ANTHROPIC_BASE_URL`ゲートウェイでサーバーのキープアライブpingが届いているにもかかわらずストリームのアイドルタイムアウトが発火する問題を修正
・セッショントークンが無効な場合にclaude.aiコネクタが誤って認証要求フラグを立てる問題を修正。代わりに`/login`ヒントが表示されるようになった
・MCPサーバー削除後などローカルで利用できなくなったツールのエラーが表示されない問題を修正
・`SendMessage`が長いサマリーを拒否して送信が失敗する問題を修正。文字数制限超過時はトランケートするようになった
・サブエージェントのトランスクリプトビューでスピナーのeffortラベルがサブエージェント自身の`effort:`設定ではなくセッションのeffortレベルを表示していた問題を修正
・ファイルウォッチャーがファイルシステムエラーに遭遇した際や終了時にまれにクラッシュする問題を修正
・`--ax-screen-reader`モードでバックスペースのたびにスクリーンリーダーが入力行全体を再読み上げする問題を修正。行末削除は削除された文字のみをエコーするようになった
・`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST`が設定されている場合にホストのモデル選択キーが古い`managed-settings.json`に優先しない問題を修正
・自動モードのセーフティを改善：`SendMessage`で他のエージェントセッションに送信されるメッセージがディスパッチ前に権限クラシファイアで評価されるようになった
・`disable-model-invocation`でスキルを呼び出そうとした際の拒否メッセージを改善。Claudeがワークフローを複製する代わりにスキルを実行するよう求めるようになった
・`/diff`ビュー、Remote Controlワークスペースdiff、Claude Code on the webセッションでのファイル編集diffが生のgit blobコンテンツを使用し、ワークスペース設定のdiffドライバー・textconvを無視するようになった
・Remote Controlの自動起動の変更：リポジトリローカルの設定（`.claude/settings.json`または`.claude/settings.local.json`）では自動起動を有効化できなくなった（無効化は引き続き可能）。有効化はユーザースコープで`/config`から行う
・ultraplan機能を削除
🔗 https://code.claude.com/docs/en/changelog#2-1-222
