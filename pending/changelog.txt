🔧 **Claude Code アップデート**
**v2.1.289**
・マネージドマシンで、複合シェルコマンドのネストされた部分に対する deny/ask ルールがユーザーインストール済み mod の承認に優先されなかった問題を修正
・多数の未閉 `<script>` タグを含む短いコードブロックや深くネストされた `${` 置換でターミナルがフリーズする問題を修正
・シンボリックリンク経由で IDE 上で @-mentioned・変更・選択されたファイルに `Read` の deny ルールが適用されなかった問題を修正
・[VSCode] サインアウトが頻繁に発生することがあった 2.1.288 の `claude auth status` の変更を差し戻し
・ハイライト済みビューを最終幅で一度だけレイアウトすることで、plugin コードペインでの大きなファイルの表示速度を改善
・ローカルフォルダのマーケットプレイスからインストールした plugin の古いコピーを `plugin list`・`plugin eval`・`plugin update` が表示する問題と、シンボリックリンクの `--plugin-dir` へのホットリロードを修正
・アップグレード後の最初のセッションでインストール済み mod が読み込まれない問題を修正
・Background tasks ダイアログがフルスクリーンで開いている間、plugin のプロンプト上部の行に古い行が表示される問題を修正
・リンクが localhost アドレス・パス中の `@`・大文字ホスト・`file:` パスを使用している場合に plugin ペインに何も表示されなかった問題を修正
・ユーザーインストール済み plugin が組織管理の MCP サーバーのサインインツールの説明を上書きできた問題を修正
・plugin がターミナルの未知のボーダースタイルで Box を描画した際に起動時にフリーズまたは強制終了する問題を修正
・plugin のオンスクリーンハンドラーが非同期にスローした際に supervised・background セッションが終了する問題を修正
・高さのない plugin リージョンが拡大し続けた際にインターフェースエラーでセッションが終了する問題を修正
・サンドボックスが自動許可する際に、展開された値を持つ環境変数プレフィックスの後ろのコマンド（例：`TZ="$HOME" rm -rf build`）を Bash の deny/ask ルールが見逃す問題を修正
・サンドボックスの自動許可下で、コマンドの前に変数代入だけが来た場合に Bash の deny/ask ルールがスキップされる問題を修正
・フォルダにマーケットプレイスマニフェストも含まれている場合に `claude plugin validate` が plugin をスキップする問題を修正
・チームメイト向けに `agent.spawn` を追加し、plugin フックイベント全体で一つの agent id を使用するよう変更、`$.agent.list()` に idle および waiting 状態を追加
・mod の `ui.render` フックが書き込んだ値が描画中に行をスローした際に "unrecoverable interface error" でセッションが終了する問題を修正（エンジンが代わりに独自の行を描画）
・タブ・孤立したエスケープと C1 制御文字、またはタブと CRLF 行末を持つ短いテキストが下の行に重なって描画される問題を修正
・mod のペインまたはバンドの右揃えコンテンツが close マークや `[-]` の下に描画される問題を修正（ターミナルのエッジから1列分内側に配置）
・描画中に失敗した mod の `Client` が周囲の描画をすべてダウンさせる問題を修正（単独で失敗し `ui.fault` を発生させるよう変更）
・`claude plugin validate` が Anthropic マーケットプレイス自身の plugin を失敗判定し、`--json` でクリーンな `plugin.json` を一覧表示する問題を修正
・描画に失敗した mod のバンドが一時的に下のカードに回避を指示する問題を修正
・失敗した plugin コンポーネントがメッセージなしで失敗した場合に `Error` または何も表示されない問題を修正
・mod のバンドまたはペインの描画失敗時に mod の作者が見る行を改善（mod 名を表示し何も描画されなかったことを明示）
・多数の未閉 `<script>` タグを含む短いコードブロックで公開された artifact ページがリーダーのブラウザタブをフリーズまたはクラッシュさせる問題を修正
・描画中にターミナルがスローした後、mod の Client リージョンがセッション全体を通して失敗したままになる問題を修正
🔗 https://code.claude.com/docs/en/changelog#2-1-289
