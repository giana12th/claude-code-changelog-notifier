🔧 **Claude Code アップデート**
**v2.1.219**
・Claude Opus 5（`claude-opus-5`）を追加。デフォルトの Opus モデルに変更。コンテキスト 1M トークン対応、fast mode 料金は入力 $10 / 出力 $50 per Mtok
・`sandbox.network.strictAllowlist` 設定を追加。allowlist 未登録のホストへのサンドボックスコマンドをプロンプトなしで拒否
・`DirectoryAdded` フックを追加。セッション中に `/add-dir` または SDK `register_repo_root` コントロールリクエストで新しい作業ディレクトリが登録されたときに発火
・headless stream-json の init イベントに `mcp_server_errors` を追加
・stream-json にネストされたサブエージェント転送を追加
・`claude -p` でターンが mid-stream API エラーで終了したとき回答が消える問題を修正
・fast mode から Opus 4.7 を削除。`/fast` は Opus 5 と Opus 4.8 に適用されるよう変更
・サブエージェントがデフォルトで最大深度 3 のネストされたサブエージェントを生成できるように変更（従来は深度 1）
🔗 https://code.claude.com/docs/en/changelog#2-1-219
