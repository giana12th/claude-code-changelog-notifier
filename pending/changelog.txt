🔧 **Claude Code アップデート**
**v2.1.204**
・headlessセッションのSessionStart hookでhookイベントがストリーミングされない問題を修正（リモートワーカーがhook実行中にidle-reapされる原因となっていた）

**v2.1.203**
・ログインの有効期限が近づくと警告を表示するように（バックグラウンドセッションが中断される前に再認証可能）
・manual permission mode時にフッターにグレーの⏸バッジを表示し、アクティブなモードが常に確認できるように
・セッションの追加作業ディレクトリをMCPの`roots/list`に追加。セットが変わると`notifications/roots/list_changed`を送信
・macOSでバックグラウンドエージェントセッションの開閉・切り替えが誤ったメモリ不足検出により15〜20秒停止する問題を修正（2.1.196でのリグレッション）
・daemonのセッショントークンが古くなったとき、バックグラウンドセッションがattach・返信・停止に永久に応答しなくなる問題を修正。セッションが自動回復するように
・`claude agents`に戻ると実行中のsubagentがサイレントに停止しプロンプトが最初からやり直しになる問題を修正。作業が引き継がれるように
・インタラクティブセッションでのメモリとターンごとのCPUリグレッションを修正。context-usage indicatorがターンごとにトランスクリプト全体を再分析しなくなった
・Windowsでバックグラウンドエージェントがdaemonから古い`PATH`を継承し、ツールが見つからなくなる問題を修正
・バックグラウンドおよびagent-viewセッションがシェルからエクスポートされた`ANTHROPIC_BASE_URL`を無視し、APIキーがデフォルトエンドポイントに送信されて401エラーになる問題を修正
・git worktreeが多いリポジトリでBashが"argument list too long"エラーになる問題を修正
・worktree分離されたsubagentが自身のworktreeではなく親チェックアウトでシェルコマンドを実行することがある問題を修正
・マルチリポジトリワークスペースでworktree作成がネストされたリポジトリを拒否し、バックグラウンドセッションが分離・編集できなくなる問題を修正
・バックグラウンドエージェントの作業ディレクトリが削除・ファイルで置き換え・無効パスになったときにクラッシュループする問題を修正。明確なエラーで1回失敗するように
・バックグラウンドdaemonの自動アップグレード失敗が実行中の全バックグラウンドセッションをサイレントに終了させる問題を修正
・他のエージェントが生成したバックグラウンドエージェントを`TaskStop`と`TaskOutput`が見つけられない問題を修正。エラーに実行中エージェントのidと説明が表示されるように
・スラッシュコマンドが利用できない場所で`claude agents`コンポーザーが入力したメッセージを破棄する問題を修正
・別のセッションで既に開いている会話の停止セッションを開くとエージェントリストがクラッシュする問題を修正
・質問に答えた後もバックグラウンドセッションがエージェントリストで"Needs input"と表示される問題を修正
・バックグラウンドエージェントの起動失敗時に実際のエラーの代わりに"exit_with_message"のみ表示される問題を修正
・daemonからフォークされたバックグラウンドセッションがsettings.jsonの`effortLevel`変更を無視する問題を修正
・アタッチされたバックグラウンドセッションが`CLAUDE_CODE_DISABLE_MOUSE`および`CLAUDE_CODE_DISABLE_MOUSE_CLICKS`の無効化設定を無視する問題を修正
・全ての名前付きエージェントが完了した後も`/exit`が実行中のバックグラウンドエージェントについて誤って警告する問題を修正
・`WorktreeCreate` hookが設定されているとき、git以外のディレクトリから開始したバックグラウンドセッションがファイルを編集できない問題を修正
・`claude agents`の`@`ディレクトリピッカーが登録済みgit worktreeを表示しない問題を修正
・Windowsで`/clear`の後にバックグラウンドタスクの出力が空ファイルに永久に置き換えられる問題を修正
・長いトランスクリプト履歴を上にスクロールするとコンテンツがジャンプする問題を修正
・bashモードでシェル履歴サジェストが表示されているときに入力するとターミナルがチラついたりジャンプする問題を修正
・バックグラウンドセッションに再アタッチするときに`^[[I`/`^[[O`エスケープコードがそのまま表示される問題を修正
・language serverが診断結果やナビゲーションリクエストに応答しているにもかかわらず、LSPのみのプラグインが誤って未使用とみなされる問題を修正
・長い応答のストリーミング中の応答性を改善。ライブプレビューの更新が画面全体を再レンダリングしなくなった
・subagentの動作を改善。エージェントがタスク全体を別のsubagentに再委任しにくくなった
・大きなバンドル依存関係を遅延読み込みに変更し、バイナリサイズと起動メモリをそれぞれ約7 MB削減
・左矢印キーがバックグラウンドタスク・diff・ワークフロー詳細ビューを閉じなくなった。代わりにEscキーを使用
・空の`claude agents`ビューが常にセクション（Needs input / Working / Completed）を説明とともに表示するように
・起動時の"claude command missing or broken"警告を削除。代わりに`/doctor`と`/status`で確認可能に
・`claude agents`フッターから冗長なナビゲーションヒントを削除
・[VSCode] 全セッションのRemote Controlを有効にするSettingsトグルを追加
