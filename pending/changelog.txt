🔧 **Claude Code アップデート**
**v2.1.131**
バグ修正:
・Windows上でVS Code拡張機能がアクティベーション時にクラッシュしていた問題を修正（バンドルされたSDK内のハードコードされたビルドパスと`createRequire`ポリフィルのバグが原因）
・Mantleエンドポイント認証が失敗していた問題を修正（`x-api-key`ヘッダーの欠如が原因）

**v2.1.129**
新機能:
・`--plugin-url <url>`フラグを追加：URLからプラグイン`.zip`アーカイブを取得して現在のセッションで使用可能
・`CLAUDE_CODE_FORCE_SYNC_OUTPUT=1`環境変数を追加：自動検出を回避するターミナル（Emacsの`eat`など）での同期出力を強制有効化
・`CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`を追加：HombrewまたはWinGetインストール時にバックグラウンドでアップグレードを実行し再起動を促す
・プラグインマニフェスト変更：`themes`と`monitors`は`"experimental": { ... }`下で宣言すること（トップレベル宣言は後方互換性のため機能するが`claude plugin validate`が警告を表示）
・Gateway `/v1/models`ディスカバリーが`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`でopt-inに変更（v2.1.126–2.1.128では自動だった）
・Ctrl+R履歴ピッカー改善：デフォルトで全プロジェクト横断の全プロンプトを検索（v2.1.124以前の動作に戻した）、Ctrl+Sで現在プロジェクト/セッションに絞り込み可能
・Bedrock、Vertex、Foundry、`ANTHROPIC_BASE_URL`ゲートウェイ利用時、ファーストパーティAnthropicサーフェスを指すspinner tipsを非表示
・`skillOverrides`設定が機能するように：`off`でモデルと`/`から非表示、`user-invocable-only`でモデルからのみ非表示、`name-only`で説明を折りたたむ
・`claude_code.pull_request.count` OpenTelemetryメトリクスがMCPツール経由のPR/MR作成もカウント対象に
・ポリシー拒否エラーにAPI Request IDを含めサポートデバッグを容易化
バグ修正:
・認識不可の400ステータスコードで生JSONではなく根本的なエラーメッセージを表示
・`/clear`：ターミナルタブタイトルをリセットしていなかった問題を修正
・`/rename`のセッションタイトルチップがパーミッションダイアログ実行中に消えていた問題を修正
・サブエージェント実行時にエージェントパネルが非表示になっていた問題を修正（v2.1.122からの回帰）
・外部エディタハンドオフ（Ctrl+G）で会話履歴が空白になる問題を修正
・`/context`：ASCII グリッド視覚化がコンテキストに含まれていた問題を修正（ターン毎に約1.6kトークンを浪費）
・`/agents` Libraryリスト：矢印キー操作で強調表示エージェントがビューポート内に留まるよう修正
・`/branch`：成功メッセージに新ブランチのセッションIDを含めていなかった問題を修正（`/resume`用）
・keycap/ZWJ/肌色emojiを含む太字ヘッダーが末尾文字を失う問題を修正
・エンタープライズ/チームユーザーで`user:inference`スコープを持たないOAuth認証情報のポリシー未適用を修正
・スリープ復帰後のOAuthリフレッシュレースで全セッションからログアウトする問題を修正
・プロンプトキャッシュ1時間TTLが5分に無言でダウングレードされていた問題を修正
・`/clear`やcompact後、`/effort`または`/model`変更時にキャッシュミス警告が誤表示される問題を修正
・`Bash(mkdir *)`, `Bash(touch *)`等のallowルールがプロジェクト内パスで尊重されていなかった問題を修正
・`deniedMcpServers`の`*://`スキームワイルドカードが大文字小文字混在ホスト名にマッチしていなかった問題を修正
・音声モードで`--debug`実行時に無害なWebSocket警告がエラーとしてログされていた問題を修正
・VS Code拡張機能の`/clear`：会話コンテキストと表示トランスクリプトをクリアしていなかった問題を修正
