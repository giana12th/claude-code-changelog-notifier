🔧 **Claude Code アップデート**
**v2.1.306**
・ cloud sessions で `claude -p` が環境変数なしで起動した際に「Not logged in」と表示される問題を修正
・ MCP ツールが多いセッションで API エラーが「prompt is too long」に置き換えられ、不要なコンパクションが発生する問題を修正

**v2.1.305**
**追加**
・ `sandbox.allowNestedUserNamespaces` を追加。Linux のサンドボックスコマンドがユーザー名前空間（Chromium、rootless podman 向け）を作成可能に
・ `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加。無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）がリセット前に使用制限解除を検知可能に
・ [VSCode] SessionStart / Setup フック実行中に「Running start-up hooks」スピナーとスクリーンリーダーアナウンスを追加
・ [Claude Tag] 管理者の Add place 検索に Claude 未参加のパブリック Slack チャンネルを追加

**変更**
・ `allowedMcpServers` の変更: `managed-mcp.json` の stdio サーバーで `env` のみに `${VAR}` を使うものをフィルタリングしなくなった（除外したい場合は `deniedMcpServers` を使用）
・ Claude Desktop がパスでマウントするプラグインで、組織の managed 設定に `allowManagedPermissionRulesOnly` がある場合 `allowed-tools` を保持しなくなった
・ `/artifacts` 削除確認が変更: 1 または Enter で保持、2 で削除、Esc でキャンセル（`y`/`n` は無効）
・ モッドのドックパネルが端末幅の 45% 以内に制限されるように変更
・ [VSCode] セッションが時間内に開始しないときのメッセージを変更: 出力ログを先頭に表示し、原因をリスト化
・ [Code Review] 以前のブロッキング所見が残っている状態で再レビューが LGTM で開始しなくなった

**改善（6件）**
・ `/usage` の改善: 各警告が1行の修正方法になり `f` で適用。VS Code と `/doctor` にも同じ修正が表示
・ MCP 同意ダイアログで、プロンプト向けの Enter が Accept と誤認識されにくくなった
・ モッドの `Image` が iTerm2 3.5 以降でフルスクリーンレンダリングで画像を描画
・ Remote Control: スポーンモードのメッセージ改善（`w` でモード保存の旨が表示）
・ [Cloud sessions] セルフホスト環境削除時にブロック要因と影響範囲を表示するように
・ [Claude Tag] 大規模組織でチャンネルリスト読み込み中もプラグイン/スキル/バンドル編集が可能に

**バグ修正（22件）**
・ Vertex・Bedrock 等でツール検索を拒否すると全リクエストが失敗する問題を修正（2.1.304 のリグレッション）: ツール検索なしで再試行
・ `/effort` と `/autocompact` が `modelOverrides` と大文字小文字や `[1m]` タグが異なる場合に適用されない問題を修正
・ ベアリポジトリで新しいワークツリーがローカル HEAD から開始される問題、未変更のサブエージェントワークツリーがクリーンアップされない問題を修正
・ フルディスク時に Bash コマンドが生の `ENOSPC` ファイルパスで失敗する問題を修正（ディスクフルエラーメッセージに変更）
・ cloud session または SDK の `setMcpServers` で渡した MCP サーバーが同名サーバーで後から置き換えられる問題を修正
・ フォールバックモデル切り替え後にサブエージェントの作業で誤ったモデル名が表示される問題を修正
・ cloud sessions とチームメイトで、コンパクションで最古メッセージが省かれた際に通知されない問題を修正
・ スケジュール済み Cowork cloud sessions で WebFetch URL 承認待ちにより各サブエージェントが 5 分間待機する問題を修正
・ Workflow 再開時に完了済みの `pipeline()` / `parallel()` エージェントが再実行される問題を修正
・ Remote Control で `/resume` で会話切り替え後に空の「(session)」エントリが残る問題を修正
・ 狭い端末で `/usage` の行が切れる問題を修正
・ 起動時の警告がロゴ上に生テキストで表示される問題を修正（デバッグログへ移動）
・ スクリーンリーダーモードで検索ボックスが記号表示になる問題、ハイライトされたテキストに余分なスペースが入る問題を修正
・ Self-hosted runner: `TERM` 設定時に stdout 共有スクリプトが `Resource temporarily unavailable` で失敗する問題を修正（2.1.300 のリグレッション）
・ Self-hosted runner: `GIT_CONFIG` 経由で設定を読む git credential helper によるリポジトリアクセス失敗を修正（2.1.296 からのリグレッション）
・ Self-hosted runner: バックグラウンドランナーが出力を開き続けているとフックがタイムアウトと報告される問題を修正
・ [VSCode] `spinnerVerbs` が短い動詞の場合「Compacting...」が切れる問題を修正
・ [Cloud sessions] 「installs packages」エラーで既存環境の保存が誤って拒否される問題を修正
・ [Claude Tag] 別 GitHub アカウントに移動したリポジトリをアクセスバンドルに再追加できない問題を修正
・ [Claude Tag] DM スレッドで設定した Routine が他の Routine の会話再起動後に投稿しなくなる問題を修正
・ [Claude Tag] Slackスレッドの Routine が会話終了後に成功を報告するが投稿しない問題を修正（スキップして作成者に通知）
・ [Code Review] PR に複数プッシュがある場合に最新コミットを見逃す問題を修正
