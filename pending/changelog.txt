🔧 **Claude Code アップデート**
**v2.1.259**
・`managedMcpServers` managed設定を追加: 組織がすべてのユーザーにHTTP/SSE MCPサーバーを提供可能（`.mcp.json`と同じエントリ形式）; コマンドの実行を指定するエントリはスキップされる
・`--permission-prompts none` を無人ヘッドレスホスト向けに追加: プロンプトが発生するものは自動的に拒否され、アクティブな権限モード（auto modeを含む）が引き続き判断を行う
・`glab mr create/merge/close/reopen/note/update` の認識を追加: GitLabのマージリクエストがツール要約でMR !Nとして表示され、フッターのMRバッジが更新される
・`claude plugin validate` に `--json` を追加: 機械可読な検証レポートを出力
・複数セッションが互いの `~/.claude.json` の変更を上書きしてしまう問題を修正: ワークスペースの信頼設定がリセットされなくなり、多数のセッションを同時実行してもMCP/プロジェクトの状態が失われない
・thinkingが一度拒否された会話が、以降のターンでも毎回拒否され続けていた問題を修正
・Bashの `Read()` 拒否ルールがオプション値として渡されたファイル（`--ignore-revs-file=.env`, `-f.env`, `@file`）、`git diff`/`git grep` のファイルオペランド、または `cd DIR && cat FILE` の複合コマンドをカバーしていなかった問題を修正; 拒否されたファイルを含むディレクトリへの `grep -r`/`cp -r` は確認を求めるようになった
・テレメトリが無効なセッションでOAuthトークンが更新された際にプロンプトキャッシュが無効化されていた問題を修正
・数百のツール呼び出しを含む長いターンの後にフルスクリーンモードで会話が空白になっていた問題を修正
・auto modeがコマンドやスキルのフロントマターの `model:` に指定されたサポート外モデルでターンを実行してしまっていた問題を修正: ターンはセッションモデルを維持するようになった
・Vertex形式のモデルID（`@YYYYMMDD` サフィックス）でClaude Codeが認識しないモデルバージョンの場合に `CLAUDE_CODE_MAX_CONTEXT_TOKENS` が無視されていた問題を修正
・シェルコマンドの実行中のライブ出力プレビューが、行折り返し発生時に最新行を隠してしまっていた問題を修正
・claude.aiユーザー向けに起動するたびに実行されていたバックグラウンドのGitHub接続チェックを修正: 結果が起動間で記憶されるようになった
・添付ファイルエントリにペイロードがない保存済みセッションで `--resume` が失敗し、`--continue` が空の会話を開いていた問題を修正
・インタラクティブセッションでカスタムコマンドとスキルのフロントマター `model:` が無視されていた問題を修正
・古いバージョンから引き継いだ会話でArtifactの公開が "unexpected parameter `note`" エラーで一度失敗していた問題を修正
・MDMや管理設定ファイルによって設定されたポリシーヘルパーがすでに実行されていた場合、起動時にmanaged `forceRemoteSettingsRefresh` が無視されていた問題を修正
・`git rev-parse` が "not a git repository" 以外のメッセージで失敗するマシンで、フックが作成したworktreeをworktree分離が拒否していた問題を修正
・クラウドセッションのOpenTelemetryメトリクスとイベントに `user.email`、`organization.id`、`user.account_uuid` 属性が欠けていた問題を修正
・起動時にツールの一覧取得中に切断したMCPサーバーが、エラーを報告せずにツールなしで接続済みと表示されていた問題を修正
・ファイル編集の権限ダイアログで変更行が末尾省略で表示されることがあった問題を修正
・一時的なgitプローブの失敗後にリポジトリ検出が既知のリポジトリIDを削除していた問題を修正
・管理設定ファイル、ドロップイン、MDMのplist、またはHKLM値を解析できない場合に管理設定が未適用になっていた問題を修正: Claude Codeはソースを示して起動を拒否するようになった
・リモートコントロールセッションでStopがバックグラウンドエージェントやワークフローを実際に停止させていなかった問題を修正: 終了したタスクはプロセスが終了するまで表示され再停止可能になった
・前の停止済み実行がまだ終了中にワークフロー実行を再開するとエージェントの重複コピーが実行される可能性があった問題を修正
・github.comのマーケットプレイスリポジトリURLに末尾のスラッシュや不正な `?`/`#` が含まれていた場合、使用不可能な `.git` クローンURLが生成されていた問題を修正
・ブロックするStopフックが、ブロック後のターンでモデルのthinkingを失わせ、一部のモデルではプロンプトキャッシュが見落とされていた問題を修正
・ブラウザホストのMCPサーバーのページが消えた後、リモート（claude.ai）セッションがターン開始まで60秒かかっていた問題を修正
・メインチェックアウトにアクセスできない一般的なBashループ、xargsパイプライン、ランチャーラップコマンドをworktree分離セッションが拒否していた問題を修正
・長い応答のターミナルリサイズと初回レンダリングのパフォーマンスを改善: テキスト計測を再利用
・`/workflows` エージェント詳細を改善: JSONの結果がシンタックスカラーと実際の改行でプリティプリントされ、長い結果は展開トグルで折り畳まれる
・ヘッドレス/SDKセッションの開始を改善: MCPサーバーの接続完了時、最初のターンが最大50ms早く開始される
・`/install-github-app` を改善: GitLabリポジトリ内で実行した場合、GitHubのみであることを説明し、GitLab CI/CDのドキュメントへ誘導するようになった
・ネストされたバックグラウンドサブエージェントの結果が親サブエージェントのトランスクリプトに保存されるよう改善: 再開されたサブエージェントがそれらを保持し、共有トランスクリプトに配信が表示される
・`allowedMcpServers` をユーザーが追加したサーバーのみに適用するよう変更: 以前はallowlistでフィルタリングされていたリテラルの `managed-mcp.json` サーバーがアップグレード時にロードされるようになった; 無効にするには `deniedMcpServers` を使用
・[VSCode] セッションリストサイドバーにActiveクイックフィルターとステータスフィルターメニュー（Needs input、Working、Completed）を追加
・リモートおよびスケジュールセッションで、セッションが一時停止中にコネクタツールの権限プロンプトが承認された後に何も行わなかった問題を修正
