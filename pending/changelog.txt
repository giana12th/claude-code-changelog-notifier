🔧 **Claude Code アップデート**
**v2.1.160**
・シェルの起動ファイル（`.zshenv`、`.zlogin`、`.bash_login`）および `~/.config/git/` への書き込み前に確認プロンプトを追加
・`acceptEdits` モードで、コード実行権限を付与するビルドツール設定ファイルへの書き込み前に確認プロンプトを表示するよう変更
・`grep` でファイルを閲覧した後、Edit に別途 Read が不要に
・WSL 上で copy-on-select が Windows クリップボードに書き込まれない問題を修正
・`claude agents` から完了済みセッションを復元するとチャット履歴が失われる問題を修正
・一晩の非アクティブ後に再接続したバックグラウンドセッションで会話が失われる問題を修正
・`claude --bg` が「socket missing」で失敗することがある問題を修正
・Windows でバックグラウンドセッションを開始したディレクトリを削除できない問題を修正
・作業を再開したバックグラウンドエージェントが Completed 欄に表示される問題を修正
・セッション一覧に戻る際に `claude agents` が数秒間フリーズする問題を修正
・CPU 高負荷時に Windows で Esc・矢印キー・入力が反応しなくなる問題を修正
・バックグラウンドエージェントが非対応端末に terminal sync-output マーカーを出力する問題を修正
・マウスホイールがトランスクリプトではなくプロンプト履歴をスクロールする問題を修正
・CJK IME 候補が入力カーソルではなく左下に表示される問題を修正
・`file:///C:/...` 形式の正しいリンクが壊れたパスに書き換えられる問題を修正（Windows）
・プロジェクト名やブランチ名に非 ASCII 文字・特殊文字が含まれると voice mode の接続が失敗する問題を修正
・サードパーティプロバイダーで auto mode が利用不可の際のメッセージを修正
・`/effort ultracode` が dynamic workflows 設定を誤って原因として表示する問題を修正
・model-not-found エラーが SDK 経由実行時に誤って `--model` を提案する問題を修正
・brief モードセッション再開時に Claude の過去の返答がスクロールバックから消える問題を修正
・vim モードの `p` がカーソル位置ではなく下の行に貼り付ける問題を修正
・最近非アクティブだったバックグラウンドエージェントセッションを開く際のパフォーマンスを改善
・auto モード分類器のレイテンシを改善
・バックグラウンドセッション終了時に SIGKILL の前に SIGTERM を送信するよう改善
・`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` を削除
・起動時の JetBrains プラグインインストール提案を削除
・dynamic workflow のトリガーキーワードを `workflow` から `ultracode` に変更
