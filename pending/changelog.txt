🔧 **Claude Code アップデート**
**v2.1.140**
・Agent tool の `subagent_type` マッチングを改善 — 大文字小文字・区切り文字を区別しない値を受け付けるように（例：`"Code Reviewer"` が `code-reviewer` に解決される）
・エージェントの色パレットを更新
・`disableAllHooks` または `allowManagedHooksOnly` が設定されている場合に `/goal` がサイレントにハングする問題を修正 — 解決しないインジケーターの代わりに明確なメッセージを表示するように
・symlinked な設定ファイルが誤った change event を引き起こし、不正な `ConfigChange` フックが発火していた設定ホットリロードの回帰を修正
・バックグラウンドサービスがアイドル終了しようとしているときに `claude --bg` が "connection dropped mid-request" で失敗する問題を修正
・エンタープライズのエンドポイントセキュリティが導入されたマシンでバックグラウンドサービスの起動に失敗する問題を修正（待機時間を延長）
・リモートマネージド設定が 401 でリトライしない問題を修正 — force-refresh したトークンで一度リトライするように
・マネージドの `extraKnownMarketplaces` 自動更新ポリシーが `known_marketplaces.json` に永続化されない問題を修正
・`/loop` が完了時に通知済みのバックグラウンドタスクに対して冗長なウェイクアップをスケジュールしていた問題を修正
・見つからない実行ファイル（例：`gh`）が毎チェック時に同期的な `where.exe` の再起動をトリガーしていた Windows でのイベントループの定期的な停止を修正
・`offset` が空白付きまたは `+` プレフィックス付きの文字列として渡された場合に `Read` ツールの呼び出しが検証に失敗する問題を修正
・ターミナルがフォーカスを失ったときにネイティブターミナルカーソルが入力キャレットに留まらない問題を修正
・`plugin.json` が対応するキーを設定している場合、デフォルトコンポーネントフォルダ（例：`commands/`）がサイレントに無視されることをプラグインが警告するように — `/doctor`、`claude plugin list`、`/plugin` で表示
