🔧 **Claude Code アップデート**
**v2.1.246**
・`Bash(git * main)` のようなサブコマンドの前にワイルドカードが入る Bash allow ルールについて、サブコマンドの前に挿入されるオプションにもマッチしてしまうという警告を起動時に表示するようにした
・`/permissions` に Auto mode タブを追加し、auto mode classifier ルールの表示・編集が可能になった
・ターンの完了時刻をターン終了の所要時間行に追加（例：`✻ Sautéed for 23s · done 6:05 PM`）
・ターミナルリサイズ後にフルスクリーンモードで空白トランスクリプトが表示され、次のキー入力まで一番下にジャンプし続ける問題を修正
・diff に非常に長い1行（例：base64 文字列）が含まれる場合のトランスクリプト表示の著しい遅延を修正；該当行は切り詰めてマーカー付きで表示されるようになった
・以前のメッセージに位置しているときのフルスクリーンでの不規則なスクロール（一番下へのジャンプがトランスクリプト途中で止まる問題含む）を修正
・Claude Code の起動ディレクトリが削除されていた場合・マシンがスリープしていた場合・ホストのプロセス起動が遅い場合に、バックグラウンドセッションが45秒後に開けなくなる問題を修正
・別の Claude Code プロセスが同時に npm パッケージを再インストールしていた際に「Couldn't start the background service … EACCES」でバックグラウンドセッションが開けなくなる問題を修正
・メッセージ先頭500文字にマークダウンがない場合にメッセージ全体のマークダウンレンダリングが無効になる問題、および `+`/`N)` リストと setext 見出しのレンダリング問題を修正
・ヘッドレス/リモートセッションで受信メッセージに中断された MCP ツール呼び出しが、明示的な中断エラーではなく「no output で完了」としてモデルに報告される問題を修正
・パラメータスキーマが空（`{}`）の場合に MCP ツール引数が実際の型でなく JSON 文字列として送信される問題を修正
・実行途中で中断されたコマンドが「Ran 1 shell command」と表示されて中断の形跡が残らない問題を修正
・dynamic workflow 実行中に ← キー押下または `/background` 実行で完了済みサブエージェントが再起動される問題を修正；何個再起動されるか表示した上で確認を求めるようになった
・ワーカーがまだ起動中の状態（Windows で多発）で `claude agents` 内のセッションを開くと「was stopped while the respawn was in flight」で停止する問題を修正
・`claude agents` でバックグラウンド化した名前付きセッションが2重リストされる問題を修正；同じ会話を再バックグラウンド化すると行に番号が付く（例：`my-session (2)`）ようになった
・古いバックグラウンドセッションレコードが `.claude/worktrees/` 配下のユーザー作成 git worktree を指す場合に保持スイープがそれを削除してしまう問題を修正
・大規模セッションで auto mode ツール呼び出しが「temporarily unavailable」として拒否される問題を修正；安全確認のデッドラインをプロンプトサイズに応じてスケールするようにした
・プラグインキャッシュが同じプラグインに対して SHA 名のディレクトリを重複作成する問題を修正
・フロントマターの `name` にすでに `<plugin>:` プレフィックスが含まれるスキルがスラッシュメニューで二重表示（例：`/plugin:plugin:skill`）される問題を修正
・`claude plugin update` に bare name を指定すると失敗する問題を修正（完全修飾名のみ機能していた）
・`plugin.json` が UTF-8 BOM 付きで保存されているとプラグインインストールに失敗する問題を修正
・`skills/*/SKILL.md` にスキル定義があるプラグインで `/reload-plugins` がスキルを0件と報告する問題を修正
・フックのエラーメッセージで `${CLAUDE_PLUGIN_ROOT}` が解決されたパスではなくリテラルで表示される問題を修正
・`/rename` がテーマのプロンプトボーダーカラー（カスタムテーマの `promptBorder` 含む）をデフォルトのシアンに置き換える問題を修正；`/color` で明示的に選択しない限りテーマの色を維持するようになった
・カスタムテーマの diff カラー（`diffAdded`/`diffRemoved` とその dim バリアント）が diff および `/theme` プレビューで無視される問題を修正
・`keybindings.json` で未知のアクション名を持つバインディングがそのキーを無効化する問題を修正；バインディングはスキップされデフォルトのバインディングが維持されるようになり、`--debug` で警告がログに記録される
・`/stats` の activity heatmap がUTCより東のタイムゾーンで各日のアクティビティを1セルずれて表示する（日曜のカウントが月曜に表示される）問題を修正
・既にフォークまたはバックグラウンド化されたセッションから `/fork` すると新しいセッションが空の会話で始まる問題を修正
・`/--` で始まるプロンプト（例：Lean doc コメント）が不明なスラッシュコマンドとして拒否される問題を修正；Claude に送信されるようになった
・入力テキストが実際のパスにマッチしなくなった後も `@` ファイルピッカーが開いたままになる問題を修正
・agents ビューに移動して戻った後にステータスラインのコストと所要時間がゼロにリセットされる問題を修正
・フォーカス目的でターミナルウィンドウをクリックした際にフルスクリーンモードでポインター下のコントロールにキーボードフォーカスが移る問題を修正
・パス補完トークンまたは作業ディレクトリに null バイトが含まれるとパス補完が失敗する問題を修正
・Windows/macOS: 不正終了したセッションが `~/.claude/sessions` に残したエントリをヘッドレスセッションがクリーンアップしない問題を修正
・サードパーティの Anthropic 互換エンドポイント（`ANTHROPIC_BASE_URL`）が `id` なしで `tool_use` ブロックをストリームした際に最初のツール呼び出しで UI がレンダーエラーで停止する問題を修正
・非常に大きな既存ファイルを上書きした後に Write ツールが「Out of memory」を報告するかフリーズする問題を修正（ファイル自体は書き込まれていた）
・`~/.claude/plugins/known_marketplaces.json` が空または破損している場合に `claude plugin install <name>` がエラーを報告せず無音で終了（またはターミナルでハング）する問題を修正
・Anthropic API が受け付けないツールブロックが保存履歴に含まれる（通常はサードパーティ API プロキシによる）場合に再開セッションが毎ターン400エラーで失敗する問題を修正
・一部の Team/Enterprise ユーザー（サーバー管理設定使用）で `curl -fsSL https://claude.ai/install.sh | bash` が「Raw mode is not supported」で失敗する問題を修正
・permission モードが未設定の場合に、plan mode で終了したセッションが VS Code 拡張機能および `claude -p --continue`/`--resume` で plan mode 以外で再開される問題を修正
・sandbox の「Network request outside of sandbox」許可プロンプト待機中に `Notification` フックが発火しない問題を修正
・末尾に `&&` または `||` 演算子が残った不正なコマンドに対して常に承認を要求するよう Bash パーミッションチェックを修正
・`--strict-mcp-config` セッションがロードしない `.mcp.json` サーバーの承認を求めてしまい、バックグラウンドセッションが起動時に待機状態になる問題を修正
・サードパーティゲートウェイ（`ANTHROPIC_BASE_URL`）用 API キーが Anthropic へのテレメトリおよびメトリクスリクエストに送信される問題を修正；認証情報は自身のホスト宛にのみ送信されるようになった
・`apiKeyHelper` が短命な JWT を返す場合にアイドル後の最初のプロンプトで API エラーが見えてしまう問題を修正；期限切れのキャッシュトークンは送信前に更新され、401/403 認証エラーは静かにリトライされるようになった
・フルスクリーンおよび Ctrl+O トランスクリプトビューでセッション長に伴うメモリ増大を修正；レンダリングされた各メッセージ行がトランスクリプト全体のツールルックアップのフルコピーを保持しなくなった
・同じリポジトリ（複数の worktree など）から同時に起動された `/ultrareview` 実行とクラウドセッションが、別の起動のコミットされていない変更で開始される場合がある問題を修正
・`/autofix-pr` などのバックグラウンドクラウドセッションで表示されるタスク進捗カウント（例：`3/5`）が欠落することがある問題を修正
・Remote Control セッションが2番目のプロンプトまで claude.ai と Claude アプリでプレースホルダー名のままになる問題を修正；自動生成タイトルが最初のプロンプト後に表示されるようになった
・`requiresUserInteraction` とマークされた MCP ツールの許可プロンプトで「Yes, and don't ask again」が提示され続け書き込まれた allow ルールをツールが無視する問題を修正
・work-poll レスポンスが不正（例：プロキシの HTML ページ）な場合にセルフホストランナーがライブセッションを終了またはプロセスを停止する問題を修正；ポーリングを再試行するようになった
・`/cd`：移動後すぐに新しいディレクトリのプロジェクト設定・フック・`.mcp.json` サーバー（通常の承認プロンプトあり）・スキル・エージェントが有効になるよう改善（以前は `--resume` まで有効にならなかった）
・bash シェルでの Bash ツールのレイテンシを改善；スナップショット関数を関数ごとに base64 サブシェルを使わずにリプレイするようにした
・サブエージェントが `maxTurns` 制限に達した場合、完了したように見える代わりに出力を部分的とマークして `SendMessage` で続行するヒントと共に返すよう改善
・非インタラクティブセッション（`-p`、SDK、クラウドセッション）がサーバーエラー・接続切断・停止によって途中で切断されたレスポンスをエラーで終了するのではなく自動的に続行するよう改善
・workload identity federation セッション・起動時の `apiKeyHelper` 実行中に送信されたイベント・アイドル中のログイントークン期限切れ後の、組織へのテレメトリ使用量の帰属を改善
・Bedrock・Vertex AI・Foundry・Claude apps gateway 経由でテレメトリまたは非必須トラフィックが無効の場合も Claude が自ら `/code-review` を開始できるよう変更
・`/goal`：長時間実行されるバックグラウンド作業に対してアイドルセッションが1ゴールあたり最大3回のチェックインを開始するよう変更；次のメッセージでさらに3回が許可される
・`claude install` と `claude update` が保留中の管理設定の同意プロンプトをコマンド途中ではなく次のインタラクティブセッションまで延期するよう変更
・claude.ai から同期されたプラグインの OpenTelemetry イベントを変更：`plugin_id_hash` がプラグインの実際のマーケットプレイスを反映し、管理者インストールの `enabled_via` が `admin-install` になった
・コマンドサンドボックスのファイルシステム設定が `--setting-sources` を尊重しない問題を修正
