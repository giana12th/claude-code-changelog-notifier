🔧 **Claude Code アップデート**
**v2.1.205**
・セッションのトランスクリプトファイルへの改ざんをブロックするautoモードルールを追加
・`--json-schema` でスキーマが無効な場合に非構造化出力を黙って生成していた問題と、`format` キーワードを使用するスキーマが拒否されていた問題を修正
・`--max-turns` 制限でターンが終了した際に、Claudeが作業中に送信されたメッセージが黙って失われていた問題を修正
・NTFSジャンクションまたはディレクトリシンボリックリンクがworktree内に存在する場合、Windowsのworktree削除がworktree外のファイルを削除していた問題を修正
・`SendMessage` でバックグラウンドエージェントを再開した後、エージェントリストで「failed」または「completed」と表示され続ける問題を修正
・エージェントのターンに読み取り可能なテキストが含まれていない場合、バックグラウンドジョブがエージェントリストで「needs input」から「working」に戻る問題を修正
・バックグラウンドエージェントがアップグレード再起動の途中にある場合、`claude attach` がエラーになっていた問題を修正（待機するようになった）
・30Kのインライン制限を超えるBash呼び出し出力で作成されたPRがセッションとPRのリンクから漏れていた問題を修正
・サーバー名にサポートされていない文字が含まれている場合、`claude mcp add-from-claude-desktop` がスタックしていた問題を修正（無効な名前が報告され、残りのサーバーのインポートは続行される）
・初期化に失敗したプラグインLSPサーバーが、同じファイル拡張子を処理する別のプラグインの有効なLSPサーバーを妨害していた問題を修正
・Claudeが起動したディレクトリがコマンド実行中に削除・ロック・アンマウントされた場合のWindowsクラッシュを修正
・ディレクトリスキャン実行中にファイルウォッチャーが閉じられた場合のクラッシュを修正
・ドキュメント化されたコマンドが変更された場合のみ更新されるべきプロジェクト検証スキルが、毎セッション書き直されていた問題を修正
・ジョブリストが少し画面からはみ出した際に、エージェントビューが1行高くレンダリングされてヘッダーがクリップされていた問題を修正
・WebおよびモバイルのRemote Controlパネルでバックグラウンドタスクが古い「Running」ステータスを表示していた問題を修正（メンバーシップ変更のたびにタスク状態を転送するようになった）
・autoモードがコンテキストから解決できない変数で `rm -rf` を実行する前に確認を求めるよう改善
・自動更新バイナリのダウンロードがメモリにバッファリングする代わりにディスクにストリーミングされるようになり、アップデータのピークメモリ使用量が約400 MB削減
・バックグラウンドタスク通知が人間の入力が発生していないことを明示的に記述するようになり、トランスクリプト内の偽造された承認が実行されることを防止
・エージェントビューの改善：既存のPRを編集・マージ・コメント・プッシュしたセッションが `claude agents` でPRをリンクするようになった
・エージェントビューの改善：行にカラー付き状態ワードとクラシファイアが書いたヘッドラインが表示されるようになり、ピーク表示にはブロックされたセッションの正確な質問を含む完全なステータスが表示されるようになった
・`/doctor` が診断と修正が可能な完全なセットアップチェックアップになった。`/checkup` はそのエイリアス
・Claude Desktopペインの名前変更に先立って「Claude Browser」MCPサーバー名（「Claude Preview」と同様）を予約。ユーザー設定のMCPサーバーはどちらの名前でも登録できなくなった
・CLI 2.1.203以降でCowork VMモードのローカルエージェントセッションが「Not logged in · Please run /login」で起動に失敗していた問題を修正
🔗 https://code.claude.com/docs/en/changelog#2-1-205
