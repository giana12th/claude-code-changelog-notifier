🔧 **Claude Code アップデート**
**v2.1.217**
・プロンプト入力欄に絵文字ショートコードの自動補完を追加：`:heart:` と入力すると ❤️ が挿入され、`:hea` でサジェストが表示される。`emojiCompletionEnabled` 設定で無効化可能
・トランスクリプトの書き込み失敗時（ディスク容量不足など）や継承された環境変数でセッション保存がオフになっている場合に、サイレントに失われる代わりに警告を表示
・MCPツール出力が切り捨てられた際に全文が未切り捨て状態でメモリに保持されるメモリリークを修正
・`claude.exe` が消失する可能性があったWindowsの自動更新失敗を修正。失敗時は保存済み実行ファイルを自動復元
・バックグラウンドセッション分離がシンボリックリンクされた作業ディレクトリを正規化せず、セッションがワークスペース外に抜け出せる問題を修正
・Bedrock上のClaude Opus 4.8でauto-compactが動作せず、制限超過後に `/compact` が失敗する問題を修正
・Claude Desktopセッションで企業向けmTLS・TLS検証・OAuthスコープ・プロキシ設定が無視される問題を修正
・スクリーンリーダーモードの起動時アナウンスが最初のプロンプトレンダリングで切り捨てられる問題と、thinkingステータス行が数秒ごとに再レンダリングされる問題を修正
・`OTEL_EXPORTER_OTLP_ENDPOINT` を設定するマネージド設定がすべてのシグナルに適用されない問題を修正
・トランスクリプトに不正な添付エントリがある場合に `--resume`/`--continue` と `/resume` がTypeErrorで失敗する問題を修正
・セッション表示後に接続したRemote Controlビューワーに保留中の権限プロンプトが表示されない問題を修正
・ヘビーロードのマシンでセッションのバックグラウンド移行後や終了時にバックグラウンドシェルが停止不能になる問題を修正（Windowsで特に顕著）
・`CLAUDE.md` や `SKILL.md` の `paths` フロントマターに多数のブレースグループが含まれる場合にCLI起動時にOOMキルまたは停止する問題を修正。ブレース展開を予算制限内に収めた
・バックグラウンドセッション開始時のアタッチ時、トランスクリプトプレビューが入力エリアに密着して表示される問題を修正
・ssh/tmux経由など端末サポートが検出できない環境でも、フッターのPRバッジリンクをクリック可能なハイパーリンクとして改善（`FORCE_HYPERLINK=0` でオプトアウト可能）
・ログイン期限切れ警告を期限5日前から3日前に変更
・frontend-designプラグインのサジェストチップを生涯3回表示に制限
・同時実行サブエージェント数に上限を追加（デフォルト20、`CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` でオーバーライド可能）
・デフォルトでサブエージェントがネストされたサブエージェントを生成しないよう変更（`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` で深いネストを許可可能）
・`--max-budget-usd` がバックグラウンドサブエージェントを停止しない問題を修正。上限到達時に新規生成を拒否し、実行中のバックグラウンドエージェントも停止するよう対応
