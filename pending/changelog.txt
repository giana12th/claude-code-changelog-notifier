🔧 **Claude Code アップデート**
**v2.1.287**

**新機能**
・Claude Mods追加：プラグインがより深い動作を変更可能に
・You should know追加：サイドエージェントがユーザーとClaudeの見落としを監視・通知（`/plugin enable cc-plugin-you-should-know@builtin`で有効化、テレメトリONのファーストパーティセッション向け）
・エージェントビューに`n:<text>`フィルタ追加：セッション名とタスクをマッチング。折りたたまれたセクションでも一致を表示、Enterで最初の一致を開く
・OpenTelemetryの`user_prompt`イベントに`prompt_text`フィールド追加（ドット区切りキーをネストするバックエンド向け）
・MCPサーバーからの2025-11-25プロトコルに対応したURLプロンプト追加（サインインフローなど）。アップデート後に接続しなくなったサーバーはMCP設定に`"bareElicitationCapability": true`を追加
・Windows：Bashツールを拒否するとPowerShellツールも無効になる旨の起動警告を追加
・セルフホストランナー：GitHub CLIがインストールされていないmacOS/LinuxマシンにAnthropicマネージドgitを使うセッション向けに内蔵`gh api`（REST only）を追加

**バグ修正**
・エージェントアカウントのないリモートセッションでfastモードが組織の許可設定に関わらずオフのままになる問題を修正
・Remote Control：再接続リクエストへの応答がない場合30秒でタイムアウトしリトライするよう修正
・スクリプトファイルが見つからない`asyncRewake`設定のhookが「found issues」通知で何度もClaudeを起こし続ける問題を修正
・SDK使用中にモデルの応答ストリームが止まっているとき、ツールハートビートがSDKホストに届かない問題を修正
・BedrockとVertex起動時のモデルチェックが強制設定の`availableModels`リストを無視して`/model`がOpus一行に折りたたまれる問題を修正
・Claude in ChromeがChromeに到達できない場合にJSONパースエラーが表示される問題を修正
・`/model`でFableを選択すると現在バージョンのIDが保存されOpus/Sonnetのように最新Fableを追跡しない問題を修正
・Opus 5.5とSonnet 5.5の切り替え時（`/model`、`opusplan`）に以前のMCPツール告知が上書きされ、拡張思考が失われることがある問題を修正
・Amazon Bedrock Guardrailsの応答中のブロックが、思考ブロックで返答が始まっていた場合にAPIエラーで終了する問題を修正
・危険な`rm`（`/`やホームディレクトリへの操作）が同じコマンドで`~`やワイルドカードパスへのリダイレクトを含む場合に常時確認保護が失われる問題を修正
・モデル切り替え中に返答が実行されていた後の全メッセージでモデルフォールバックが繰り返される問題を修正
・セッション再開後またはコンパクション後にフォルダのCLAUDE.mdが2回添付される問題を修正
・エージェントが終了してworktreeが削除された後に`claude agents`からバックグラウンドセッションを再度開けない問題を修正
・`/advisor`ペアリングチェック修正：Sonnet 5.5がOpus 4.7と4.8にアドバイス可能に。APIが拒否するアドバイザーは事前に通知されるよう
・Bashの権限プロンプトに「Contains simple\_expansion」などの内部パーサー名が表示される問題を修正
・長い会話でスクロールキーを押し続けた場合にフルスクリーンセッションが「unrecoverable interface error」で終了する問題を修正
・`__proto__`という名前のMCPツールの組織ごとのツール権限上限が無視される問題を修正
・Readの`offset`と`limit`では1行が長い場合に分割できないため、大きなMCP結果をJSONで保存してページングするよう指示していた問題を修正
・コンパクション後にコミット属性リマインダーがツール結果内に届く問題を修正
・スクリーンリーダーモードの複数の修正（検索ボックスでのカーソル位置、`/rewind`のサマリーオプション、権限プロンプトのヒント、矢印キーの説明、ファイル編集の差分表示、spinner中の繰り返し送信など）
・`CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS`がsession-titleとprompt-hookリクエストからstructured-outputフォーマットを削除しない問題を修正（Bedrockバックエンドゲートウェイが拒否する）
・セッションよりも背の高い前の画面の後に来る2番目の承認プロンプトのトップ行がスクリーンリーダーモードで省略される問題を修正
・`--include-partial-messages`が短縮された返答の`message_stop`を遅延または送信しない問題を修正
・`claude agents`でバックグラウンドセッションが待機中の権限プロンプトを表示しないことがある問題を修正
・`/ultrareview`がコミット済みの`.gitattributes`（UTF-16保存など）を読めない場合に`.git/info/attributes`についてアドバイスする問題を修正
・`claude remote-control`がHTTPプロキシ経由で登録に失敗する際に「Check your organization permissions」という誤解を招くエラーが表示される問題を修正
・Linux上のサンドボックス化されたBashコマンドがClaude Code実行可能ファイルのオープンハンドルを継承する問題を修正
・「Reduce motion」設定が有効でもツールドットと3つのスピナーが動き続け、`/rewind`の確認画面が「ago」時間を更新し続ける問題を修正
・`claude agents`のスクリーンリーダーモードで時間が毎秒変化する問題を修正（最大10秒ごとに変更）
・失効したclaude.aiログインで一般的な`API Error: 401`ではなく「OAuth token revoked」が表示されない問題を修正
・`/ultrareview`がリポジトリの設定ファイル内の変数名を自分のユーザー設定にコピーするよう助言する問題を修正
・`--output-format stream-json`とSDKが`/<skill>`をプロンプトとして入力した場合の`context: fork`スキル実行のターンをストリーミングしない問題を修正
・`/feedback`と`/bug`の修正：プリフィルされたGitHub issueに最近のエラーメッセージが含まれなくなり、確認画面がレポートの一部としてリストするよう
・`claude plugin marketplace add --sparse`と`git-subdir`プラグインのインストールがhttpで提供されるリポジトリで「transport 'http' not allowed」で失敗する問題を修正
・クラウドセッションがコンパクション中に再起動した場合に以前の会話が失われることがある問題を修正
・起動時の`--plugin-url`ダウンロードと重複したプラグインリロードがセッションのキャッシュを破損する問題を修正
・Claude Desktopの起動タイムアウトや大量出力時に`/desktop`が部分的な出力を引用する問題を修正（エラーに原因が明示されるよう）
・MCPコネクタがサポートするMCPプロトコルバージョンを変更した場合にツール呼び出しが2回実行されることがあるか、再起動まで失敗し続ける問題を修正
・同期プラグインのSessionStart hookが新しいクラウドセッションで実行されない問題を修正
・トランスクリプトの「N hooks ran」サマリーと詳細デバッグログのhookカウントにClaudeの内部コールバックが含まれる問題を修正（1つ設定したhookが2つと表示されていた）
・クラウドおよびRemote Controlセッションからのファイル送信が30秒タイムアウト直後に完了した場合に失敗する問題を修正（35秒待つよう変更）
・クラウドおよびSDKセッション中に追加されたリポジトリのスキル・プラグインが読み込まれず、CLAUDE.mdが遅延して読み込まれる問題を修正
・8000ピクセルを超えるPNG/JPEG/WebP画像がリモートセッションから送信できない問題を修正（縮小したコピーを送信）
・17〜20個の添付ファイルがあるメッセージで最初の16個しか届かない問題を修正

**改善**
・`/config`：循環する設定に‹ ›表示、←/→で両方向に切り替え可能に。狭いターミナルでは各値をラベルの下に表示、PgUp/PgDnでリストをページング
・プラグインマーケットプレイスのエラーメッセージをわかりやすく改善、プラグイン一覧に依存関係未インストールの表示追加
・Claude appsゲートウェイのAmazon Bedrock拒否エラー改善：どのモデルが利用不可か開発者に表示
・SDKセッション：優先度「now」のメッセージがWebフェッチ・検索をキャンセルしないよう改善
・`/memory`：←/→キーでon/off設定を切り替え可能に
・プロンプト入力ボーダーとプロンプト前の「❯」のコントラスト改善（ライトテーマ）
・クラウドセッションおよびRemote Controlからのファイル送信：タイムアウト・ネットワークエラー・502/503/504で1回リトライするよう改善
・大きなMCPツール結果の処理：メモリ効率化、セッションファイルサイズ削減、トークンカウント用の追加アップロードなし
・別セッションからの保留メッセージのプロンプトをダッシュ線で囲んで表示（他の権限プロンプトに合わせた）
・MCP等のツール権限プロンプトのツール呼び出しをダッシュ線で囲んで表示
・ヘッドレスモードでのMCP起動改善：最初の接続が一時的に失敗したリモートサーバーを最も遅いサーバーの終了を待たずにリトライ
・リモートセッションから送信する大きなファイルをメモリに読み込まずディスクからストリーミング
・Windows：すべてのコマンドの前に実行していたサブシェルを削除しBashツールを高速化

**変更**
・リポジトリのコミット済みシンボリックリンクを通じた機密ファイルへの書き込みや作業ツリー外への書き込みが`~`ターゲットでも着地先を明示して確認を求めるよう変更
・Opus 4.7+とFableがBedrock/Vertex/Foundry/Claude appsゲートウェイでデフォルト1Mコンテキストを使用（`[1m]`サフィックスなし、`CLAUDE_CODE_DISABLE_1M_CONTEXT=1`で200Kに戻す可能）
・`claude agents`からの返答がキューに入ったメッセージとして届くよう変更。ターン実行中は`/stop`以外のスラッシュコマンドは終了後に実行
・自動モデル切り替え後にフラグ付きメッセージが届いた場合、新しいモデルのデフォルトではなく現在のエフォートレベルを維持するよう変更
・待機中の権限プロンプトを古い順に表示（新しいプロンプトが読んでいるものを覆わないよう）。カウントダウン付きのプロンプトは引き続き最前面に開く
