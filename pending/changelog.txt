🔧 **Claude Code アップデート**
**v2.1.200**
・`AskUserQuestion` ダイアログがデフォルトで自動続行しなくなった；`/config` でアイドルタイムアウトを設定できる
・「default」パーミッションモードが CLI、`--help`、VS Code、JetBrains で「Manual」に変更；`--permission-mode manual` と `"defaultMode": "manual"` も受け付ける
・`.claude.json` の `disabledMcpServers` または `enabledMcpServers` が非配列値の場合の起動時クラッシュを修正
・スリープ/ウェイク後またはスタックしたセッション再開時にバックグラウンドセッションがターン途中でサイレントに停止する問題を修正
・Esc でキャンセルしたターンがスタール再起動後に再実行されるバックグラウンドセッションの問題を修正
・クラッシュで残ったステール `daemon.lock` の PID が OS に再利用された後、バックグラウンドエージェントが二度と起動しなくなる問題を修正
・バックグラウンドエージェントデーモンのハンドオーバーを修正：古いビルドがデーモンを引き継げないようになり、ビルドの新旧はバージョンに埋め込まれたビルドタイムスタンプで判断する
・バックグラウンドエージェントロスターの複数の問題を修正：一時的な破損による孤立クリーンアップの恒久的な無効化、古いバイナリが新しいバージョンのフィールドを保持しない問題、デーモン再起動時のソケット認証トークン削除
・レート制限でテキスト出力前にサブエージェントが切断された場合に空の結果を返していた問題を修正（クリーンな失敗を返すようになった）
・バックグラウンドエージェント出力の制御バイトがエージェントビューでターミナルに届く問題を修正
・フラグが `agents` の後に置かれた際に `claude agents --plugin-dir <dir>` がエージェントビューにプラグインのエージェントとスキルを表示しない問題を修正
・プロジェクトスコープのプラグインが同じリポジトリの git ワークツリーから正しく読み込まれない問題を修正
・`/mcp` サーバーリストがスクリーンリーダーと拡大鏡のフォーカスをトラッキングしない問題を修正
・無音録音時に音声入力が誤った「Voice connection failed」メッセージを表示する問題を修正
・synchronized terminal output を有効化することで tmux 3.4+ でのレンダリングちらつきを修正
・スクリーンリーダー出力の改善：装飾グリフが非表示になり、トランスクリプト記号が短いラベルで読み上げられ、ネストされたテーブルが `Header: value.` 行として読み上げられる
・インストールスクリプトがシステムのメモリ不足でインストールが終了した場合に説明するよう改善

**v2.1.199**
・スタックされたスラッシュスキル呼び出し（`/skill-a /skill-b do XYZ`）が先頭のスキルをすべて（最大5つ）ロードするようになった（以前は最初のスキルのみ）
・SSL 証明書エラー（TLS 検査プロキシ、`NODE_EXTRA_CA_CERTS` の欠如、期限切れ証明書）が修正ヒント表示前にリトライを消費していた問題を修正 — 修正ヒントとともに即座に失敗するようになった
・API がストリーム途中でオーバーロード/サーバーエラーを発行した後、ストリーミング応答が破棄されていた問題を修正 — 不完全応答通知付きで部分的な内容が保持されるようになった
・レート制限またはサーバーエラーで切断されたサブエージェントが部分的な作業を親に返さずサイレントに失敗していた問題を修正
・サブエージェントが API エラー（例：使用量制限到達）を成功した結果として報告していた問題を修正 — エラーが親エージェントに報告されるようになった
・不正なシャットダウン後に破損したワーカーレコードが残り、Linux のバックグラウンドエージェントデーモンが約50秒ごとに自分自身とすべての実行中エージェントを終了させていた問題を修正
・macOS で SSH 経由のバックグラウンドエージェントのコールドスタートが失敗する問題を修正（2.1.196 のリグレッション）
・バックグラウンドエージェントの再起動と競合した際に `claude stop` がサイレントにアンドゥされていた問題を修正 — 再起動がストップを尊重するようになった
・長いコマンド実行中にバックグラウンドジョブの進捗インジケーターが数分間停止する問題を修正
・メモリ不足マシンでバックグラウンドセッションが汎用エラーを表示していた問題を修正 — 低メモリを示してリソース解放を提案するようになった
・バックグラウンドエージェントが完了したときにエージェントビューでリモートセッションが Working と Idle の間でちらつく問題を修正
・他のサブエージェントが作業中にアイドルサブエージェントがエージェントパネルから消えていた問題を修正；余剰アイドルエージェントが折りたたみ可能なサマリー行にまとめられるようになった
・サブエージェント表示中に `/model` または `/fast` を入力するとリードのモデルピッカーがサイレントに開いていた問題を修正 — コマンドがリードに適用されることを説明する通知が表示されるようになった
・`SessionStart`、`Setup`、`SubagentStart` フックがコード 2 で終了した際に stderr をサイレントに隠していた問題を修正 — エラーがトランスクリプトに表示されるようになった
・`claude --dangerously-skip-permissions daemon <subcommand>` がサブコマンドを実行せずチャットプロンプトとして扱われていた問題を修正
・再起動されたエージェントが以前のエージェント名を再利用した際に `SendMessage` がサイレントに誤ルーティングしていた問題を修正 — ツールが不一致を検出して呼び出し元に再ターゲットを求めるようになった
・新しいメッセージがないセッションを開くまたは再開するとトランスクリプトファイルが不必要に増大する問題を修正
・`←` または `/background` でセッションをバックグラウンド化するとエージェントビュー行から `/color` が失われる問題を修正
・スタートアップリカバリダイアログから破損した設定ファイルをリセットすると回復不可能になる問題を修正 — 先にファイルをバックアップするようになった
・セッションが異なるビルドや設定ディレクトリから実行されたときに Chrome で Claude が繰り返し再接続ページを開く問題を修正
・プランモードが状態変更ブラウザツール呼び出しのプロンプトを表示しない問題を修正；読み取り専用 `browser_batch` 呼び出しが正しく自動許可されるようになった
・一時的なサーバーレート制限エラー（使用量制限とは無関係の 429）がサブスクライバーに対して自動バックオフでリトライされるようになった
・`CLAUDE_CODE_RETRY_WATCHDOG` が非容量トランジェントエラーのデフォルトリトライカウントを 300 に引き上げ、`CLAUDE_CODE_MAX_RETRIES` の 15 の上限を撤廃した
・`claude agents` セッション行がプルリクエストリンクを冗長な「PR」ラベルなしでベアの `#N` として表示するようになった
