**v2.1.133**
・`--worktree`・`EnterWorktree`・エージェント隔離 worktree が `origin/<default>` またはローカル `HEAD` からブランチするかを選択する `worktree.baseRef` 設定（`fresh` | `head`）を追加。**注意:** デフォルトの `fresh` は `EnterWorktree` のベースを `origin/<default>` に戻す（2.1.128 以降はローカル `HEAD` だった）— 未プッシュのコミットを新しい worktree に持ち込むには `worktree.baseRef: "head"` を設定する
・カスタムの bubblewrap および socat バイナリの場所を指定する `sandbox.bwrapPath` と `sandbox.socatPath` managed settings を追加（Linux/WSL）
・管理者が SDK `managedSettings`（親ティア）をポリシーマージにオプトインできる `parentSettingsBehavior` admin-tier キー（`'first-wins' | 'merge'`）を追加
・フックが `effort.level` JSON 入力フィールドと `$CLAUDE_EFFORT` 環境変数を通じてアクティブな effort レベルを受け取るようになり、Bash ツールコマンドが `$CLAUDE_EFFORT` を読み取れるようになった
・focus モードの動作を改善
・メモリ不足時にウォームスペアバックグラウンドワーカーを解放することでメモリ使用量を改善
・refresh-token の競合で共有 credential が消去され、並行セッションがすべて 401 で行き詰まる問題を修正
・ドライブルート（`C:\`）または POSIX `/` にスコープされた `Edit`/`Write` allow ルールが誤ってマッチし、常にプロンプトを表示する問題を修正
・clock skew やスローディスクによってヒストリーまたはセッションログのファイルロックが危険にさらされた場合の未処理拒否（`ECOMPROMISED`）を修正
・会話コンパクション中に Esc を押すと誤った "Error compacting conversation" 通知が表示される問題を修正
・discovery・動的クライアント登録・トークン交換・トークン更新を含む完全な MCP OAuth フローで `HTTP(S)_PROXY` / `NO_PROXY` / mTLS が尊重されない問題を修正
・`--add-dir` / SDK `additionalDirectories` 経由で渡されたマッピングされたネットワークドライブで Read/Write/Edit が拒否される問題を修正
・claude.ai からの Remote Control の停止/割り込みがローカルの Esc と同様に CLI セッションを完全にキャンセルしないため、スタックしたツールやプロンプトの割り込み後にキューされたメッセージが進まない問題を修正
・1つのセッションの `/effort` が他の同時実行セッションの effort レベルを予期せず変更する問題と、IDE の effort 変更が無言で破棄される関連問題を修正
・サブエージェントが Skill ツール経由でプロジェクト・ユーザー・プラグインスキルを見つけられない問題を修正
・`claude --help` が `--remote-control-session-name-prefix` と並んで `--remote-control` をリストするようになった
・[VSCode] 拡張ビルドに Claude バイナリがバンドルされていない場合に `claudeCode.claudeProcessWrapper` が "Unsupported platform" で失敗する問題を修正
