🔧 **Claude Code アップデート**
**v2.1.247**
**新機能**
・**SendFeedback tool**: セッション中に問題が発生した際、Claude がフィードバックレポートを下書きし `/feedback` からレビュー・送信できるようになりました（`feedbackDrafts` 設定で無効化可能）
・**spinnerTipsOverride の強化**: `{id, text, cooldownSessions, priority}` エントリ・`tipsFile`・`label` を `spinnerTipsOverride` に追加。組織が独自のヒントをビルトインのものと並行して表示できます
・**Bash 権限プロンプトのヒント**: Bash 権限プロンプトに auto mode を案内するヒントを追加。ワンキーで「はい、かつ auto mode に切り替える」オプションが選択可能
・**コスト最適化コマンド**: `/claude-api cost-optimize` を追加。既存プロジェクトの Claude API 使用コストをプロファイリングし、caching・トークン管理・batch・effort・モデル選択など各コスト削減手段を一つずつ測定しながら検討できます
・**`/claude-api` スキルの強化**: Admin API のカバレッジ（組織メンバー、招待、ワークスペース、API キー、レートリミットレポート、workload identity federation、CMEK）を追加

**バグ修正**
・履歴検索・`/config`・`/mcp`・`/skills`・バックグラウンドタスク・`/model` で、高速な矢印キー + Enter の操作が移動した行の1つ上の行に作用してしまう問題を修正
・サブエージェントが初回呼び出しでモデル 404 エラーにより終了する問題を修正。セッションのフォールバックモデルチェーンを使用するようになり、エラータイプ・ステータス・リクエスト ID・モデルを含むエラーを親に返します
・フックやバックグラウンドエージェントがメガバイト単位のエラー出力を出した場合にセッションが「Prompt is too long」で固まる問題を修正
・kitty プロトコル端末で非ラテン文字キーボードレイアウト（例：キリル文字）使用時に Ctrl キーボードショートカットが動作しない問題を修正
・escape プレフィックス直後に分割されたマウスレポートが届いた際に `<35;150;7M` のようなテキストがプロンプトに挿入される問題を修正
・Bash sandbox の後処理クリーンアップが、sandbox 書き込み可能エリア外を指す dotfile 管理の `~/.claude/settings.json` シンボリックリンク（nix/home-manager、stow）を削除する問題を修正
・`/terminal-setup` が Zed の `keymap.json` 全体を上書きしていた問題を修正（キーバインドのマージのみ行うようになりました）
・`/rename` でセッションレジストリを更新できない場合に黙って確認していた問題を修正（他のセッションで古い名前のままになる可能性があることを通知するようになりました）
・`--agent` で開始したセッションで `/compact` と「Summarize from here」がデフォルトのシステムプロンプトでサマリーしていた問題を修正
・バックグラウンドセッションのターミナルホストプロセスが終了後も `claude agents` で「opening…」と表示され続ける問題を修正（数秒以内に理由を示してフェールし、Enter で再起動可能になりました）
・フックやバックグラウンドタスクの出力ファイルに書き込めない場合にメモリが際限なく増大する問題を修正
・SSH 経由の `/install-github-app` で、コピーショートカットが常に成功と表示していた問題を修正。サインイン URL がどのようにコピーされたかを表示し、ブラウザが開けない場合はすぐに URL を表示するようになりました
・フォアグラウンドから引き継いだシェルコマンドがバックグラウンドセッションで終了した際に内部エラーや誤解を招く `[exited with code -1]` を表示する問題を修正
・バージョンなしのマーケットプレイスプラグインの2回目のスコープインストール時にライブキャッシュディレクトリが削除・再作成されて実行中のセッションに影響する可能性があった問題を修正
・`/remote-control` で開始した Remote Control セッションが接続クライアントに作業ツリーの差分を報告しない問題を修正
・セルフホステッドランナーセッションが Claude Code の起動前に `running` を報告し、Claude デスクトップアプリから誤った「Claude is waiting for your input」通知が発生する問題を修正
・managed settings で Claude apps gateway サインインが設定されていて Anthropic エンドポイントに到達できない場合、初回起動セットアップが「Unable to connect to Anthropic services」で終了する問題を修正
・モード切り替え直後にメッセージを送信した際、クラウドセッションが前のパーミッションモードを表示することがある問題を修正
・バックグラウンドエージェント・シェル・モニターが実行中にセッションコンテナがターン間で再起動した場合にクラウドセッションが沈黙する問題を修正（再開したセッションが失われた作業を報告するようになりました）

**改善**
・**Plugin marketplace hardening**: コントロール文字や不可視文字を含む名前を拒否。`/plugin` や `claude plugin` 出力でのマーケットプレイス提供テキストがエスケープセーフになりました
・**Bedrock、Vertex、Foundry セッション**: 設定された MCP サーバーが接続に失敗した場合、ツールが存在しないと判断する代わりに Claude に通知されるようになりました
・**Sonnet 5 auto-compact ウィンドウ**: Sonnet 5 のデフォルト auto-compact ウィンドウを最大 1M コンテキストに変更。1M ウィンドウのセッションが約 934K トークンではなく約 967K トークンで auto-compact されるようになりました
・**クロスセッションピアメッセージ**: デフォルトで `Message from @<sender>: <first line>` の1行プレビューに折りたたむように変更。Ctrl+O でフル本文を展開できます
・**レンダリングされた Markdown のターミナルハイパーリンク**: ネットワーク・オートマウンターパスを指すリンク、コントロール文字を含むリンク、不可視文字で始まるリンクはプレーンテキストとして表示されます
・**PR バッジ最適化**: 最後のチェックから1分未満の場合、ターミナルフォーカス再取得時の PR バッジの GitHub 再確認をスキップするように変更
・**Analytics 起動動作**: managed settings が gateway ログインを強制するかカスタム OAuth デプロイが設定されている場合、ログイン後だけでなく起動時から analytics をオフに変更
・**Claude apps gateway サインイン識別**: サインインリクエストが `surface=claude_code` パラメータと `claude-code/<version>` User-Agent で Claude Code を識別するようになりました
・**組織サインイン強制**: ホスト提供またはユーザーごとの Windows レジストリ設定が存在する場合でも、管理者の managed settings が読み取れない場合は起動時に終了するように変更
