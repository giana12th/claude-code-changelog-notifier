🔧 **Claude Code アップデート**
**v2.1.317**
・【追加】クラウドのスケジュールタスクが未要求のコネクタを取得した際に `/schedule` で警告を表示。Web・シェルツールがアカウントのメールアドレスを送信する前に確認プロンプトを表示。Agent SDK のフックコールバックに `onFailure: "block"` を追加。Claude apps ゲートウェイ管理 API にコストレポートエンドポイントを追加。
・【変更】`SendMessage` がバックグラウンドで実行中のエージェントへより早く到達するように改善。異なるモデルで動作するサブエージェントがそのモデルの effort レベルを使用するように変更。Read ツールが変更のないファイルに対してスタブではなく実際のコンテンツを返すように変更。
・【修正】`claude auth status` が場合によってサインアウトされてしまう問題、Bedrock の "Input is too long" エラーがコンパクションをブロックする問題を含む 62 件のバグ修正。
