🔧 **Claude Code アップデート**
**v2.1.301**

**追加**
・`CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` を追加。無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）でリセットまでの時間が長すぎる使用量制限に達した場合、待機せずにリクエストを終了するようになった。
・`claude-api` スキルに OpenTelemetry トレーシングガイダンスを追加（`ant` CLI を使ったトレース先の設定方法を含む）。
・vim モードに `%` モーションを追加：対応するブラケットへジャンプ（単独使用または d/c/y との組み合わせ可）。
・mod の `Input` に `rows` を追加：ターミナル内の複数行テキストフィールド（Enter で送信、Shift+Enter またはバックスラッシュ + Enter で改行）。
・OpenTelemetry の `tool_decision` イベントに `classifier_verdict` と `permission_mode` を追加。auto モードの classifier 判定をパーミッションルールと区別可能に。
・`OTEL_LOG_TOOL_DETAILS=1` 設定時、OpenTelemetry の `tool_decision` イベントに `classifier_category` を追加（classifier ブロックが一致した組み込みルール名）。
・[VSCode] レスポンス内の LaTeX 数式レンダリングを追加（`$$`、複数行の `\[ … \]`、インラインの `$…$`・`\(…\)` 対応）。
・[VSCode] VS Code と JetBrains パネルの Pro / Max プランの使用量制限バナーに「Get more usage」リンクを追加。

**変更**
・mod フックの `.catch` ハンドラは、フック自身がスロー・タイムアウトした場合のみ実行されるように変更。フックの呼び出し配下で発生したイベントは `.catch` を呼ばずにスキップ。
・mod の `$.env.set` が、変数のセット・アンセット完了時は `{}` で、書き込みが行われなかった場合は理由を含む `{ deny }` で resolve するようになった。

**改善**
・より小さいコンテキストウィンドウのモデルへ切り替え時、会話が長すぎる場合は以前のモデルが先に要約を実行するように。
・長時間実行中のサブエージェントのレンダリングパフォーマンス改善：進捗トレイルが毎回再処理される代わりにインクリメンタルに更新。
・Artifacts：スクロールテキストがモバイルアプリのスティッキーヘッダー上に表示されないよう修正。
・Mods：VS Code・デスクトップ・モバイルアプリで、質問ダイアログ上のツリーが Markdown を保持し最大 48 行表示可能に（ターミナルは 12 行のプレーンテキストのまま）。

**バグ修正（37件）**
・`WorktreeCreate` フックで作成された worktree に未プッシュのコミットがある場合、確認なしに削除されなくなった。
・`fable`（および `best`）エイリアスが最新 Fable モデル非対応の組織でエラーを返さなくなった（前バージョンで1回リトライ）。
・ディスク満杯でログインリフレッシュが失敗した際、「Please run /login」の代わりにディスク名とファイル削除を促すエラーを表示。
・Grep と Glob が検索プログラム失敗時、マッチなしと誤報告する代わりにエラーを返すように。
・Workflow エージェントがタスクテキストのハーネスノート読み込み後、成功を報告しながらステップをスキップする問題を修正。
・PreToolUse フックが Edit または Write をカバーしている場合でも Artifact 更新が拒否されなくなった。
・引数名が非常に多い・長いスキルやコマンドが数秒間停止する問題を修正（最初の64個・各64文字まで補完）。
・スキル、コマンド、フックが多数のプレースホルダーを持つ引数で大量メモリを消費する問題を修正。
・VTE 0.53 未満の古いターミナル（RHEL 8 の MATE Terminal など）に `>0q` や `>4m` 等の余分な文字が表示される問題を修正。
・一部の iTerm2 バージョンでスタートアップ時のプロンプトに `GOK` テキストが表示される問題を修正。
・`application-inference-profile` を含むモデル名への切り替え時、プロバイダーが Bedrock でない場合に `awsAuthRefresh` が実行される問題を修正。
・`claude auth status` などの短いコマンドがトークンリフレッシュ中に終了した際のリフレッシュタイムアウト・予期しないサインアウトを修正。
・パーミッションチェック中の mid-turn メッセージによって切り捨てられたツール呼び出しが、ユーザー拒否と誤報告されなくなった。
・小さいコンテキストモデルへの切り替え時、確認なしに要約の使用クレジットが消費されなくなった。
・LLM ゲートウェイ経由で異なるモデル名のレスポンスが返る場合に会話が繰り返しコンパクトされる問題を修正。
・vim モードで遅いマシンでの Escape 後に INSERT モードに留まる問題を修正。
・vim モードで AskUserQuestion 入力中に Esc でテキストが消える問題を修正（Esc は NORMAL モードからのみキャンセル）。
・Read ツールがバイナリファイル（.xlsm、.parquet、.epub、.heic）をテキストとして読む問題を修正。
・ヘッダー行のみで端末幅を超える Markdown テーブルがレンダリングされるようになった（プラン承認カードでも同様）。
・`/claude-api` スキルが AWS 上の Claude Platform で CMEK 外部キーエンドポイントが利用不可と誤表示する問題を修正。
・`/rewind` 後にスキルが再びモデルに一覧表示されるようになった。
・再開したセッションのコンパクション行に、以前のメッセージの保存先が表示されるようになった（フルスクリーンでも表示）。
・割り込み後に「new task? /clear to save tokens」ヒントが再表示されなくなった。
・プラグインやスキルフックの `ask` 決定のパーミッションプロンプトにプラグイン・スキル名が表示されるようになった。
・`/diff` が reftable リポジトリで競合のある cherry-pick とリバートを認識するようになった（git チェック失敗・タイムアウト時も）。
・同じセッションで Bash の `cd` 後に Workflow スクリプトを読み込み・編集・再実行した際にパーミッションを求められる問題を修正。
・dark ANSI テーマと 16 色端末でのデフォルト文字の薄い表示を修正。
・`$.model.fork` が最初のレスポンス完了前（`claude -p` やクラウドセッション）に呼ばれた際 `nothing-to-fork` を返す問題を修正。
・フルスクリーン：`/compact` とオートコンパクト中に UI が一時的にフリーズする問題を修正。
・セルフホスト型ランナー：管理設定で MCP サーバーが制限されている場合でも Slack 開始セッションがリポジトリをアタッチ可能に（`deniedMcpServers` でツールをオフにできる）。
・セルフホスト型ランナー：関連のない障害が git の missing-ref 表現を引用する場合にセッションが削除済みのソースブランチを持つと誤報告される問題を修正。
・セルフホスト型ランナー：セッション終了のリリース失敗が繰り返される際、誤解を招くリトライ告知の代わりにカウントを表示。
・Windows：停止したバックグラウンド PowerShell コマンドの出力ファイルに `[killed]` 行が含まれるようになった。
・[VSCode] パネルをクラッシュ・フリーズさせた会話がリロードのたびに同じ失敗に再オープンされなくなった。
・[VSCode] 長い thinking 中にチャットパネルが遅くなる問題を修正（更新のたびに thinking テキスト全体を再パースしなくなった）。
・[VSCode] 一部の言語サーバーで Diagnostics に「[object Object]」の代わりにルールコード（例：MD013）が表示されるようになった。
・[VSCode] dictation が提供されていない環境でネイティブ dictation オーディオモジュールが読み込まれなくなった。
