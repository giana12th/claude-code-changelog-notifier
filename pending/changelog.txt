🔧 **Claude Code アップデート**
**v2.1.296**

**追加**
・`managed.policies[]` に `code` キーを追加: `cli` と同じ設定で、Claude Desktop の Code タブにも適用される。`desktop` と合わせて Claude Desktop のゲートウェイモードを有効化する。
・サブエージェントのフロントマターと `--agents` 定義に `autoCompactWindow` を追加。サブエージェントがメイン会話のウィンドウより早く auto-compact できるようになった。
・`CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL` を追加: すべての workflow エージェントを1つのモデルで実行しつつ、他のサブエージェントは各自のモデルを維持できる。
・`CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS` を追加: 過負荷（529）リクエストのリトライ時に、より長い最大バックオフ遅延を設定できる。
・`/plugin` に、同名の有効プラグインが既に存在するためフックが省略された場合の通知を追加。
・Read ツールに `allow_large` オプションを追加: 通常のサイズ制限を超えるテキストファイルを1回のコールで読み込める。
・[Cloud sessions] セルフホスト環境の Activity タブの Sessions・Runners 一覧にステータスフィルターを追加。
・[Claude Tag] Activity ページの Memory タブで、Claude Tag Admin 権限を持つメンバーがワークスペース・チャンネルのメモリファイルを作成・編集・削除できるようになった。

**変更**
・Sonnet 5.5 のキャッシュ読み取りコストを `/cost`、ステータスライン、`--max-budget-usd`、SDK のコスト計算で $0.10/100万トークンに更新（旧 $0.20）。
・バンドルされた dataviz スキルを更新: ライトモードの第7系列に薄いバイオレット、ダークモードのプライマリテキストをより柔らかく、y 軸ラベルを `1K` のようなコンパクト表示に。
・MCP ツールの説明とサーバー指示の前送り文字数制限をデフォルト 2,048 → 4,096 文字に変更。
・`←` の動作を変更: セッションがバックグラウンドに移行中に開始したターンや `!` コマンドは、完了せずに停止されるようになった。
・[VSCode] Claude in Chrome が `@browser` で接続したセッションも含め、すべてのセッションでブラウザ操作前に確認を求めるよう変更。サイトをセッションに許可すると繰り返し確認を省略できる。
・[Claude Tag] Claude in Slack のフッター（セッションリンク・モデル・コスト）がスレッド内の最新返信にのみ表示されるよう変更。

**改善 (9件)**
・フルスクリーンモードでマウスポインター下のリンクに下線が表示されるように。
・コードが多い会話でのトランスクリプト切り替え（ctrl+o）の応答性を改善（シンタックスハイライト済みコードブロックのキャッシュ）。
・Claude apps gateway 経由の Claude Desktop Code タブが、セッションを起動できない理由を表示するように。
・拒否されたクラウドセッションのエラーが、組織ポリシーの読み込み失敗の理由を詳細表示し、claude.ai ログインをオーバーライドできる API キーまたは認証トークンを明示するように。
・`--debug` でカスタムエージェントファイルの未認識フロントマターフィールドを名前付きで報告、タイポへのヒントも表示。
・Auto mode が利用可能な回答のないチェックに対し、赤いエラーではなく薄い "Not run" 行を表示するように。
・`--debug` がコマンドフックの完了時にコマンド・プラグイン・結果・所要時間をログに記録するように。
・`CLAUDE_CODE_TRANSCRIPT_LOCAL_GC` が解放量が 10% 未満の大きなトランスクリプトの書き直しをスキップするように。
・[Code Review] 管理者設定で保存できなかった理由を表示するように。

**バグ修正 (56件)**
・管理設定の `PreToolUse` フックが `"continue": false` で拒否した場合、およびプロンプトフックがブロックした場合、ターンを終了せずにコールを拒否するように。
・管理設定の PostToolUse フックが `updatedMCPToolOutput` をより多くのセッションで適用するように。
・ヘッドレスセッションが無効化された `.mcp.json` やプラグイン MCP サーバーを起動しなくなった。
・`allowedProviders` に `"gateway"` を含む Claude apps gateway が、そのゲートウェイをユーザー設定で指定しているノートパソコンをロックアウトしなくなった。
・管理設定の `forceLoginMethod` が `forceLoginGatewayUrl` なしで `gateway` の場合、保存済みの Claude apps gateway サインインが無視されなくなった（2.1.295 のリグレッション）。
・`--teleport` が履歴を読み込めない場合に空の会話を開かなくなった。
・Haiku 5.5 および他の adaptive-thinking 専用モデルのトークンカウントが一部のゲートウェイ経由で失敗しなくなった。
・再開されたサブエージェントが、シャットダウンで中断されたツールコールをユーザーが拒否したと誤って通知されなくなった。
・フックの出力がプラグインヒントタグに似ている場合に改変されなくなった。
・共有トランスクリプトとデバッグログのシークレット削除が、値なしのキーに続く値もキャッチするように。
・古い VTE ターミナル（MATE Terminal など）でコピー後に `52;c;…` エスケープシーケンスが表示されなくなった。
・`/diff` パネルやダイアログが開いている間もトーストと通知が表示されるように。
・`UserPromptSubmit` フックや mod の `prompt.submit` フック中に Esc または割り込みを行っても、ヘッドレスセッションが終了したりプロンプトがクリアされたりしなくなった。
・ヘッドレスセッション開始後にロードされたプラグインの SessionStart フックが、同名のプラグインが既に実行済みの場合にスキップされなくなった。
・`claude self-hosted-runner` が登録拒否時に組織管理者設定を明示し、再起動されたオンデマンドランナーには新しい work order が必要と表示するように。
・セルフホストランナーの git fetch・pull・push が、`--capacity` が 1 より大きいランナーで同じリポジトリの別セッションが開始した場合に失敗しなくなった。
・Workflow スクリプトが約 20,000 レベル以上にネストされた結果をサイレントに切り捨てなくなった。
・プラグインが提供する `$` メソッドが呼び出し元エージェントの作業ディレクトリで実行されるように。
・`$.agent.register` が mod リロード・削除後もまだ実行中の mod フックからの呼び出しを拒否するように。
・mod の `$.http.fetch` が `Content-Length` が 4 MiB 制限を超える `HEAD` リクエストを拒否しなくなった。
・`claude plugin marketplace add`・`marketplace update`・`plugin install` が `constructor` という名前のマーケットプレイスで内部エラーを起こさなくなった。
・`constructor` または `prototype` という名前のプラグインシークレットが次のオプション保存時に削除されなくなった。
・クラウドセッションが機能フラグ未ロード時に、保存済み権限が許可した Claude in Chrome アクションの auto mode チェックをスキップしなくなった。
・`CLAUDE_CODE_RESUME_INTERRUPTED_TURN` が MCP ツール結果でターンが終了した場合に再起動後に完了済みターンを再実行しなくなった。
・Bash 権限チェックが `BASH_ARGV0` を割り当てて使用するコマンドに対してプロンプトを表示するように。
・Edit と NotebookEdit が非 UTF-8 ファイル（Windows-1252、Shift-JIS、GBK）を破損せずに拒否するように。
・`←` 直後のプロンプトがバックグラウンドサービスが遅い場合に2回実行されなくなった。
・SessionStart フック実行中に送信されたプロンプトが `←` でセッションをバックグラウンドにした場合に消えなくなった（`↑` で取り戻せる）。
・ヘッドレスセッションで `/clear` 後に遅くロードされたプラグインの SessionStart フック出力が新しい会話に届かなくなった。
・PowerShell コマンドがフックの `CLAUDE_ENV_FILE` への書き込み変数を参照できるように。
・クラウドセッションが認証が必要な MCP サーバーを非インタラクティブモードで呼び出さなくなった。
・クラウドセッション・Agent SDK・IDE 統合での `/code-review` が生の JSON ではなく番号付きリストで結果を表示するように。
・Auto mode が自分自身のアーティファクトの更新を誤って拒否しなくなった。

・claude.ai から同期されたプラグインが宣言されたマーケットプレイスの依存関係も同期されている場合に無効化されなくなった。
