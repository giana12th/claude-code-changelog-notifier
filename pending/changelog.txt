🔧 **Claude Code アップデート**
**v2.1.286**

**新機能:**
・権限リクエストが複数スタックした場合に「5件中2件目」のようなカウントを表示
・フルスクリーンモードのリスト「N more」行にマウスサポートを追加: クリックでリスト末尾にジャンプ、ホバーと押下状態付き

**バグ修正:**
・gcpAuthRefresh/awsAuthRefreshの認証情報期限切れ時に複数のClaude Codeプロセスおよび IDE extensionがそれぞれログイン用ブラウザを開く問題を修正
・並列ツール呼び出しのバッチ後にセッションがクラッシュ/強制終了した場合、`claude --resume` と `--continue` が以降のすべてのターンを失う問題を修正
・ツールまたはhookがテキストの代わりにオブジェクト・数値・真偽値を返した場合（再開セッション含む）のAPI 400エラーを修正
・非常に大きな履歴を持つクラウドセッションがトランスクリプト読み込み中にコンテナが停止されウェイクアップできなくなる問題を修正
・Claude appsゲートウェイのスペンドメーターが1時間プロンプトキャッシュ書き込みを安い5分レートで計算し、web searchなどサーバーサイドツール実行のストリームターンで最初のモデル呼び出しの入力トークンのみカウントしていた問題を修正
・別のClaude Codeウィンドウで`/login`成功後も`~/.claude/.credentials.json`が残っている場合にmacOSセッションが「Not logged in」または「Login expired」と表示し続ける問題を修正
・Anthropic APIがデフォルトまたはモデルエイリアスが解決するモデルを拒否するとすべてのターンが失敗する問題を修正: 同一ティアの前のモデルで1回リトライするようになった
・組織のポリシーがRemote Controlをオフにした後もRemote Controlセッション（`claude remote-control`含む）が接続を維持し続ける問題を修正: 通知とともに切断するようになった
・フォールバックモデルがfastで実行できない場合、リジェクトと`--fallback-model`のリトライが失敗する問題を修正: 通常速度で実行しインタラクティブセッションで一度通知するようになった
・MCPディスカバリーキャッシュが有効な場合、再認証成功後もヘッドレスセッションが「MCP servers require authentication」リマインダーを繰り返す問題を修正
・`claude auth status`がConsoleサインインの保存されたAPIキーを`claude.ai`と報告する問題を修正: `api_key`と報告しVS Code extensionがAPIキーセッションとして扱うようになった
・`/status`がAPIキーと並んでAnthropicプロファイルを両方有効であるかのようにリストアップする問題を修正: プロファイルが未使用としてマークされるようになった
・Remote Controlで送信されたメッセージの添付ファイルが届かない場合にClaudeに通知されない問題、およびファイルの最後のダウンロード試行に10秒しか与えられないことがある問題を修正
・Claude Code終了中に到着したRemote Controlメッセージが配信済みマークされ未回答のままになる問題を修正: 次のセッション実行時にキューに残るようになった
・MCPエラーメッセージで認証情報名の前に「Bearer」または「Basic」がある場合にその値が表示される問題を修正
・パーセントエンコードされたBearerトークンがエラーメッセージで部分的にしかマスクされない問題を修正
・ゼロ幅スペースなど不可視文字を含む鍵名のシークレットがリダクションされたログとトランスクリプトに表示される問題を修正
・`)`, `"`, `]`, `&`, 2番目の`@`などの句読点を含むURLパスワードや`[::1]`などのブラケットホストを持つssh URLのパスワードの一部がログとトランスクリプトに表示される問題を修正
・シークレットリダクション後に無効なJSON行を含む`/feedback`がディスクに保存するzipのセッショントランスクリプトを修正
・MCPコネクターが古いMCPハンドシェイクを削除した後最大1日間ツールを表示しない問題を修正
・ClaudeからのMCPサインイン再要求が保留中のサインインリンクを置き換えそのリンクが機能しなくなる問題を修正
・MCPサーバーがまだ接続中または接続直後に行われたツール呼び出しが`/usage`でサーバーに帰属されない問題を修正
・claude.aiで有効なプラグインが一時的なサーバーエラー後にセッションでClaude Codeから見えなくなることがある問題を修正
・実行中のサブエージェントに入力されたメッセージがサブエージェントが読んだ後にトランスクリプトに二重表示される問題を修正
・サブエージェントに登録名がない場合、ハンドバックメッセージにエージェント名の代わりに生のタスクIDが表示される問題を修正
・TaskCreate/Get/Update/List、TodoWriteが有効なセッションでフォアグラウンドサブエージェントがタスクトラッキングツールを見逃すことがある問題を修正
・worktreeアイソレーションで生成されたサブエージェントが最初のファイル読み取り時にworktreeコピーからCLAUDE.mdとそのインポートを二度読み込む問題を修正
・接続が数分間中断した場合にWorkflowツールのサブエージェントが元のプロンプトから再起動される問題を修正
・バックグラウンドエージェントまたはチームメートのトランスクリプト表示中に`/compact`、`/clear`、`/rewind`を入力するとメインの会話に対して静かに動作する問題を修正: ダイアログがターゲットを示して確認を求めるようになった
・承認待ち中にバックグラウンドジョブが完了表示される問題を修正
・モデルフォールバックが1ターンだけ続く場合にコミット帰属リマインダーがツール出力内で再送信される問題を修正
・フルスクリーンモードで折りたたまれた行の単語間スペースをクリックすると展開せずに行がハイライトされる問題を修正
・詳細のない行（長い名前のアクション行など）がリスト画面で他の行の詳細を右にずらす問題を修正
・非常に長いファイル名のファイルがクラウドセッションに届かない問題を修正
・Claude Codeが読み込みを拒否するマーケットプレイスのプラグインエラーが「not found」の代わりに理由と修正方法を表示するよう修正
・`/plugin`のDiscoverタブがマーケットプレイス名のチェック行に引用符なしで表示する問題を修正

**改善:**
・コミットガイダンスの改善: プロジェクトまたはユーザースキルに`verify`という名前のスキルがある場合、docs-only/tests-onlyコミットを除きコミット直前に実行するようClaudeに通知するようになった
・サブエージェントのビューでのsend now (ctrl+enter)の改善: サブエージェントの実行中コマンドをバックグラウンドに移動しメッセージがすぐに読まれるようになった
・バックグラウンドエージェントからの返信の改善: あなたが言ったことの別途まとめで始まらないようになった
・claude.aiアーティファクトリンク読み取りの改善: WebFetchがArtifactツールと同じ確認フローを使用するようになった
・fetch、skill、ファイル読み取り、sandboxネットワーク、Claude in Chrome、workflowスクリプト、notebook editの権限プロンプトをファイル編集プロンプトの外観に合わせて改善
・BashとPowerShellとMonitorの権限プロンプトをファイル編集プロンプトに合わせてダッシュ行の間にコマンドを表示するよう改善
・フルスクリーンモードのリストスクロールバーの改善: 「N more」行が来るたびにバーがシフトしなくなり、クリックまたはホールドでスクロールできる↑/↓矢印が追加された
・外部エディター(Ctrl+G)の改善: 行番号をとるエディターがプロンプトのカーソル位置の行で開くようになった
・多くのスキルまたはプラグインコマンドがインストールされている場合のスラッシュコマンド候補の応答性を改善
・出力スタイルピッカーの改善: Defaultではなく現在のスタイルで開き各スタイルの説明が名前の下に表示される; 数字キーでスタイルを選択できなくなった
・`/hooks`のhook詳細画面の最後の行が「it」ではなく「this hook」と表示されるよう改善
・モデルフォールバック通知がコンテキストウィンドウが1Mから200Kトークンに縮小された場合を通知するよう改善
・MCPサーバーが既に接続されている場合のホストからのMCPサーバーイネーブル再送信時のSDKと`-p`セッションの応答性を改善

**変更:**
・何も実行/キューに入っていない間に送信されたプロンプトが灰色ではなく通常テキスト色で即座に表示されるよう変更
・失敗したAPIリクエストのリトライ方法の変更: 1つの制限がモデル呼び出し全体をカバーし、デフォルト設定で最大14リクエストを送信するようになった
・`--bare`がコマンドラインで指定されたMCPサーバーのみを接続し、システムリマインダーを送信せず、バックグラウンドタスクを開始しないよう変更; タイムアウトに達したシェルコマンドはバックグラウンドに移動せず停止するようになった
・send-nowキー(ctrl+enter)がskillのシェルコマンドをバックグラウンドに移動するよう変更
・レート制限されたドメインの安全チェックのWebFetchエラーがClaudeにループでリトライしないよう通知するよう変更
・プラグインのインストールがgitリポジトリまたはフォルダーであるnpmソースを拒否し、レジストリパッケージからのみ依存関係をインストールするよう変更
・リスト画面(`/artifacts`、`/mcp`、`/skills`、`/hooks`など)が各行の詳細を名前の後の1列に常に揃えるよう変更
・リストのオーバーフロー行が「↑ N more」/「↓ N more」と表示されるよう変更
・`/hooks`が設定されたhookのリストをイベントごとにグループ化して表示し、hookの閲覧が1回のEnterで済むよう変更
・テーマピッカーがターミナルに合わせたスクロールリストに変更; 数字キーでテーマを選択できなくなった
・`/exit`のworktree削除がClaude Codeがそこで起動したサーバーとシェルを停止した後に実行されるよう変更
・`claude-api`スキルのManaged Agentsの例が限定的なネットワーキングで環境を作成するよう変更
・`/ultrareview`と`claude ultrareview`の出力からブラウザリンクを削除

**Windows:**
・`claude`がすでに信頼しているフォルダーで異なる文字ケースで信頼レコードが保存されている場合に`claude --bg`とagentsビューがそのフォルダーを拒否する問題を修正

**VS Code Extension:**
・ブックマーク追加: Claudeの返答を保存しBookmarksサイドパネルで表示したままにする
・Claudeが尋ねる質問とあなたの回答を会話に追加: 質問カードに回答後、各質問とあなたの選択を示すQuestions行が表示される
・チャットパネルの質問カードにオプションプレビューを追加: ハイライトされた選択のモックアップまたはスニペットがオプションの横または下に表示される
・メッセージと一緒に送信されたターミナル出力、ブラウザタブ、ブラウザの指示、選択されたコードを開く行をメッセージの下に追加
・会話がサイドバーで開いていた場合にタブで2つ目のコピーが開く問題を修正: サイドバーがそれに切り替わるようになった
・Claude Codeが1MB以上の出力を印刷した場合に設定ダイアログが再確認なしに保存失敗を報告する問題を修正
・extensionが応答しなくなった場合に「Teleporting session…」スピナーが無限に表示される問題を修正
・Manage pluginsダイアログの改善: オフになっているプラグインが他の設定のために有効のままである場合に通知しフォルダー衝突を説明する
・StopとEscapeを現在のターンのみ終了するよう変更; バックグラウンドエージェントはエージェントマップから個別に停止できる
・「✻ Claude Code」ステータスバーアイテムがすべてのウィンドウに表示されるよう変更し、ファイルが開いていない場合でもClaudeを開けるようになった

**クラウドセッション:**
・Claudeがメッセージを送信した後にセッションがアイドルになった場合、回答済みの質問カードまたは承認済みのツール呼び出しが返信を受け取らない問題を修正
・admin settingsで組織環境のセットアップスクリプトをクリアした後も新しいクラウドセッションが古いスクリプトを引き続き実行する問題を修正
・セルフホスト環境のadminページのRunnerアクションメニューが開いた数秒後に自動的に閉じる問題を修正
・クラウドセッションが起動しなかったルーティーン実行がSucceededと表示される問題を修正: Failedと表示されるようになった
・クラウドセッションのOutputsカードでオーディオまたはビデオファイルをクリックすると空のファイル検索が開く問題を修正: ファイルが再生されるようになった
・スケジュールされた実行が遅れている場合、ルーティーンのページが過去の次回実行時刻の代わりに「Due」とスケジュールされた時刻を表示するよう変更

**Claude Tag (Slack統合):**
・Claude TagのadminのスペンドリミットページにAdd channelボタンを追加: チャンネルIDまたはSlackリンクからプライベートチャンネルを含む任意のチャンネルに制限を設定できるようになった
・デフォルトのSonnetモデルを使用できない組織でメモリリコールが何も見つからない問題を修正
・Enterprise Grid管理者がチャンネルを別のワークスペースに移動し最初の投稿でClaudeにメンションしない場合にSlackチャンネルがClaude設定を失う問題を修正
・Slackスレッドで質問に回答した後にまだプッシュしていない作業を失いながら新しいマシンで最初から始めることがある問題を修正
・大きな組織でClaude Tagのスペンドリミットページのadminにパブリックチャンネル名がSlack IDとして表示される問題を修正
・SlackからのセッションタイトルをClaudeの改善: Slack IDやエスケープコードなしで入力した言葉として表示されるようになった
