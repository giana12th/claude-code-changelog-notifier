🔧 **Claude Code アップデート**
**v2.1.143**
・プラグインの依存関係強制を追加：別の有効なプラグインが対象に依存している場合、`claude plugin disable` が拒否するようになった（無効化チェーンのコピー可能なヒント付き）。また `claude plugin enable` は推移的な依存関係を強制的に有効化する
・`/plugin` マーケットプレイスの閲覧ペインに推定コンテキストコスト（ターンごと・呼び出しごとのトークン推定値）を追加
・ワークツリーが実用的でないリポジトリ向けに、バックグラウンドセッションが `EnterWorktree` なしで作業コピーを直接編集できる `worktree.bgIsolation: "none"` 設定を追加
・PowerShell ツールが `-ExecutionPolicy Bypass` を渡すようになった。`CLAUDE_CODE_POWERSHELL_RESPECT_EXECUTION_POLICY=1` でオプトアウト可能
・バックグラウンドセッションがアイドル後の再起動時に設定したモデルとエフォートレベルを保持するようになった
・アタッチされたエージェントセッションで Shift+Tab がサイクルに auto モードを含むようになった
・`scopes` 値が配列でない破損した `.credentials.json` が CLI 起動時にハングしたり OAuth トークンリフレッシュを無音で中断したりする問題を修正
・Windows Terminal と WSL で `claude agents` の右クリックペーストが動作しない問題を修正
・繰り返しブロックするストップフックが永遠にループする問題を修正。8回連続ブロック後に警告でターンが終了する（`CLAUDE_CODE_STOP_HOOK_BLOCK_CAP` で上書き可能）
・Claude がイテレーション間でアイドル中に、Esc/Ctrl+C が保留中の `/loop` ウェイクアップをキャンセルしない問題を修正
・バックグラウンドシェルや委譲されたサブエージェントがまだ実行中に `/goal` 評価器が起動する問題を修正
・settings.json の `env` 内の `NO_COLOR`/`FORCE_COLOR` が Claude Code 自身の UI カラーを削除する問題を修正。これらはサブプロセスにのみ適用されるようになった
・Windows でセッション一覧表示時にエージェントビューが PowerShell プロセスを繰り返し生成する問題を修正
・プロンプトなしの `/bg` がフォークされたセッションに "continue" を送信する問題を修正。フォークは入力を待つようになった
・`--agent <name>` が `plugin:` プレフィックスなしでプラグイン提供のエージェントを見つけられない問題を修正
・エージェントビューからセッションを削除してもトランスクリプトファイルが削除されない問題を修正
・Windows Terminal でアタッチされたバックグラウンドセッションのスクロール中に古いフラグメントがレンダリングされる問題を修正
・ホストのスリープまたは macOS App Nap 後にバックグラウンドエージェントが誤ってワーカーストール検知を大量に発生させる問題を修正
・5xx エラーメッセージが設定されたゲートウェイやクラウドプロバイダーを示す代わりに status.claude.com を指す問題を修正
・PowerShell ツールが Bedrock、Vertex、Foundry ユーザー向けに Windows でデフォルト有効になった。`CLAUDE_CODE_USE_POWERSHELL_TOOL=0` でオプトアウト可能
・`claude agents` が `--add-dir`、`--settings`、`--mcp-config`、`--plugin-dir` を受け付け、ダッシュボードおよびそこから起動されるバックグラウンドセッションに適用するようになった
・`claude agents` がビューから起動されるセッションのデフォルトを設定するために `--permission-mode`、`--model`、`--effort`、`--dangerously-skip-permissions` を受け付けるようになった
・`claude --bg --dangerously-skip-permissions` が retire→wake を超えて持続するようになった
・バックグラウンドセッションがウォームスペアの入力に IDE ファイル参照を無音でキャプチャし、`claude agents` からディスパッチされた次のプロンプトに参照が追加される問題を修正
・`git worktree remove` が失敗したとき、ワークツリーのクリーンアップが `rm -rf` にフォールバックしなくなった。gitignore されたファイルや進行中のファイルの損失を防ぐ
・フルディスクアクセスが許可されていても macOS のバックグラウンドジョブセッションが `~/Documents`、`~/Desktop`、`~/Downloads` 配下のファイル読み込み時に "Operation not permitted" エラーが発生する問題を修正
・`/bg` が `--mcp-config`、`--settings`、`--add-dir`、`--plugin-dir`、`--strict-mcp-config` を保持するようになった。バックグラウンドセッションは再起動後も MCP サーバーと設定を維持する
・`claude agents` から起動されたバックグラウンドセッションが settings.json の `permissions.defaultMode` を尊重するようになった（以前は auto モードに上書きされていた）
・Windows で、レスポンスのストリーミング中に `claude agents` で ← を押すとエージェントリストがすべての入力に反応しなくなる問題を修正
・`/bg` と `←`-デタッチが `--fallback-model` を保持するようになった。バックグラウンドワーカーが過負荷時にハードフェイルする代わりにフォールバックモデルにデグレードする
・`/bg` と `←`-デタッチが `--allow-dangerously-skip-permissions` を保持するようになった。フォークされたワーカーは Shift+Tab サイクルでバイパス権限を利用可能に保つ
・バックグラウンドデーモンの起動が `~/.local/bin/claude` ランチャーが見つからないまたは実行不可能な場合に実行中のバイナリにフォールバックするようになった
・`claude agents --allow-dangerously-skip-permissions` がパーミッションサイクルで利用可能にする代わりに、ディスパッチされたセッションをデフォルトでバイパスモードにする問題を修正
