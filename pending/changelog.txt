🔧 **Claude Code アップデート**
**v2.1.231**
・MCP OAuth sign-inで、Slackのようなpre-registered OAuth clientを使用するサーバーでリダイレクトURIミスマッチが発生していた問題を修正

**v2.1.229**
・`claude remote-control --continue` で最新のRemote Controlセッションを再開できることをドキュメント化
・self-hosted runnerセッションにサーバー提供のClaude Code hookサポートを追加（マネージド環境の動作に対応）
・長いthinkingポーズ中にVertex・Bedrockアップストリームでアイドルタイムアウト切断が発生しないよう、gatewayストリーミングレスポンスにSSEキープアライブpingを追加
・プラグインマーケットプレイスに`command`ソースを追加：ローカルコマンド（IDEなど）がプラグインディレクトリを出力し、セッションごとに再解決されて再起動なしで適用される（`mode: "link"`で置き換えとして使用可能）
・`ListAgents`が切断されたRemote Controlセッションを`offline`としてマーク、クラウドセッションを`cloud`としてラベル付けするよう変更
・ストリーミング中に長いレスポンスの一部が消えて端末に2回表示される問題を修正
・ツールコールの`glob`、`file_path`、`command`の値が文字列以外の場合にエラー画面にクラッシュする問題を修正（`--resume`でも発生していた）
・非常に狭い端末ウィンドウでプログレスバーやMarkdownテーブルをレンダリングする際のRangeErrorクラッシュを修正（`claude --continue`/`--resume`起動時にも影響）
・ツールコールやメッセージが拡張長（`\\?\`）やUNCパスでファイルを参照した際のWindowsでのクラッシュを修正
・`CLAUDE_CODE_ATTRIBUTION_HEADER`でattributionヘッダーを無効にしているユーザー（Anthropic API直接接続）でautoモードがすべてのツールコールで失敗する問題を修正
・`ANTHROPIC_BASE_URL`カスタムgatewayを使用するclaude.aiサブスクライバーで`/model`がSonnet/Opus 1Mを拒否する問題を修正
・リダイレクトURIに`localhost`の代わりに`127.0.0.1`を使用することで、厳格な認可サーバーでのMCP OAuthを修正
・ラップトップ端末でスラッシュコマンドを入力した後、Remote Controlクライアントが作業中スピナーのまま止まる問題を修正
・`/install-github-app`で生成されるClaude Code Reviewワークフローがプルリクエストにレビューを投稿せずに完了する問題を修正
・IDEエクステンションが接続されている間に数千のIDE診断を持つファイルを編集した後に発生する数秒のUIストールを修正
・ワンショットの`claude plugin`コマンドが古いプラグインバージョンのクリーンアップを妨げるlivenessファイルを残す問題を修正
・CPU制限コンテナ内の動的ワークフローがコンテナのCPU制限の代わりにホストマシンのコア数を使用する問題を修正
・アトミックファイル置換後のfile-watcherハンドルリーク、およびネットワーク・仮想ファイルシステムでスケジュールタスクウォッチャーが失敗した際のWindowsでのキャッチされないエラーを修正
・SDKと`--input-format stream-json`セッションで空白のみのメッセージが送信されたときに400 APIエラーが発生する問題を修正
・メッセージだけでAPIの32 MBリクエスト制限を超えるコンバーセーションが、画像・ドキュメントを削除できない場合でもcompactionを再試行する問題を修正（明確なメッセージで一度だけ失敗するよう変更）
・Claude DesktopセッションからのOpenTelemetryエクスポートが、そのgatewayがtelemetryエンドポイントでもある場合にDesktop管理のgatewayに拒否される問題を修正
・`managed-mcp.json`がデプロイされてサーバーがMCPサーバーを提供する場合にself-hosted runnerおよびリモートセッションが起動時に終了する問題を修正（警告と共にスキップするよう変更）
・Git Credential Managerのプロンプトでself-hosted runnerのリポジトリ準備がハングする問題を修正（認証情報がない場合はgitがすぐに失敗するよう変更）
・ワークフローのfan-outを改善：同じプレフィックスを持つ兄弟エージェントをずらし、後続エージェントがキャッシュされたプロンプトプレフィックスを読み取れるよう最適化（`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0`で無効化可能）
・"prompt is too long"エラーを改善：`/compact`を提案するだけでなく、自動compactionが回復できなかった理由を説明するよう変更
・サンドボックスを改善：ネットワークドメインリストのIPv6リテラルが括弧付き（`[::1]:443`）になり、曖昧なスペルはfail-closedとして適用され`/doctor`でフラグが付くよう変更
・ログイン成功後に`CLAUDE_CODE_OAUTH_TOKEN`オーバーライド警告を繰り返すよう`/login`を更新
・`--force`、`--amend`、`--no-verify`などの危険なフラグを持つgit/ghコマンドが自動承認されなくなるよう`/commit-push-pr`を変更
・self-hosted runner Windowsの起動に明示的な`--base-dir`が必要になるよう変更（Windowsにはデフォルトのチェックアウトディレクトリがない）
・[VSCode] "Report a problem"と`/bug`が廃止されたsurveyリンクの代わりにビルトインフィードバックダイアログを開くよう変更
・[VSCode] `/btw`サイドクエスチョンパネルをサイドドック・スタックレイアウト両方で境界をドラッグしてリサイズ可能に
・[VSCode] サイドバーにセッショングループを追加（右クリックで作成・名前変更・削除、Cmd/Ctrl・Shiftクリックで複数セッションを同時に移動）
