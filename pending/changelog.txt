🔧 **Claude Code アップデート**
**v2.1.238**
・`keybindingFlavor` 設定を追加：`"readline"` に設定すると Ctrl+W がBashのように直前の空白まで削除する（デフォルト `"classic"` は変更なし）
・プラグインマーケットプレイス：url マーケットプレイスまたはカタログエントリの `headersHelper` が、カタログや同一オリジンのアーカイブフェッチ用のHTTPヘッダー（例：短期トークン）を生成するコマンドを実行する
・カタログエントリの `headersHelper` はプラグインのインストール・更新時のみ実行され、コマンド表示後に確認する；`claude plugin install/update` は `[y/N]` を尋ねる（または `-y` を渡す）
・`claude self-hosted-runner --defer-shutdown-max-min <minutes>` を追加：SIGTERM 時に接続中セッションへのサービスを継続し、指定分数後に残りをパークして終了する
・接続ごとに新規の `Proxy-Authorization` ヘッダーを要求するエグレスプロキシ向けに `claude self-hosted-runner --proxy-authorization-command` / `--proxy-authorization-file` を追加
・長時間のインタラクティブセッションでの無制限メモリ増大を修正：サブエージェントのツール結果が最近の表示ウィンドウを離れると解放されるようになった
・セッション途中でカスタム・プロジェクト・プラグインの出力スタイルがデフォルトに戻る問題を修正
・アカウントが使用制限に近いがまだ超えていない場合に `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=true` がプロンプト提案を維持できない問題を修正
・コマンドにリダイレクトがないのに worktree 分離の Bash 拒否がリダイレクトの削除を指示する問題を修正
・単一の遅い・欠失したポーリングリクエスト後にサーバーが self-hosted runner を削除し、正常なセッションを別のランナーに移譲することがある問題を修正
・4,096文字を超えるURLで MCP elicitation ダイアログが何も表示しない問題、およびプロジェクトパスがターミナル幅に収まらないときにパーミッションプロンプトが「次回から確認しない」オプションを省略する問題を修正
・Bashコマンドが kill・タイムアウト・中断されたときの `/tmp/claude-*-cwd` ファイルの残留を修正
・バックスペースとして Ctrl+H を送信するターミナルで、キーストロークが大量に届くとき（遅い SSH/mosh 接続）に押しっぱなしの Backspace が無視される問題を修正
・パーミッションプロンプトのdiffでのテキスト折り返しを修正：幅広の複数コードポイント文字（絵文字など）やタブを含む行が切り取られなくなった
・一時停止（Ctrl+Z）したセッションをkillするとターミナルがブラケットペーストモードのままカーソルが非表示になることがある問題を修正
・stdio MCPサーバーが `initialize` より前に `server/discover` リクエストを受信し、遅延起動サーバーが毎回セッション開始時にバックエンドを起動させられる問題を修正
・プロキシによる接続拒否がプロキシ名を示さず汎用ネットワークエラーとして報告される問題を修正
・プロンプトキャッシュがすでに期限切れのときに `/model` と `/effort` のキャッシュミス警告が表示される問題を修正
・Remote Control タスクパネルのタスクごとの Stop が CLI ホストセッションで機能しない問題を修正
・クライアントが有効なロールなしでユーザーメッセージを送信したときにリモートセッションが終了する問題を修正
・`claude remote-control` で開始した Remote Control セッションが起動シェルからセッションスコープの環境変数を引き継ぐ問題を修正
・プロセスがクラッシュした Remote Control セッションが `claude remote-control` 再起動まで利用不可のままになる問題を修正；次回メッセージ送信時に再利用できるようになった
・Claude が作業中に web または Desktop から送信された Remote Control メッセージがターン終了後にトランスクリプトから消える問題を修正
・携帯やウェブで選択した Remote Control のモデルがターミナルの表示モデルを更新しない問題を修正
・ネットワークの一時的な問題でサインイン更新が遅れると Remote Control が「ログイン期限切れ」で切断される問題を修正；再試行して接続を維持するようになった
・サインアウト時に Remote Control が再接続失敗を報告する問題を修正；明確なメッセージでセッションが終了するようになった
・`claude remote-control`（サーバーモード）または Desktop/IDE ホストで実行されたセッションで `ListAgents`/`SendMessage` が「Remote Control is not connected」と報告する問題を修正
・`ListAgents` と `SendMessage` がエージェントビューが次のバックグラウンドセッション用に事前ウォームアップするアイドルワーカーを公開する問題を修正
・クロスセッションメッセージング：受信拒否セッション（例：`crossSessionInbound: "refuse"`）へのメッセージ送信が無音の成功でなく「拒否」を報告するようになった
・クロスセッションメッセージング：メッセージをドロップしたセッションが、メッセージが消えるのでなく送信セッションに通知するようになった
・macOS で単純な `claude` の起動が早くなった
・シェル条件文のzsh固有構文における Bash ツールのパーミッションチェックを改善
・Remote Control 接続の耐障害性を改善：ネットワークエッジ・VPN・プロキシからの短時間の HTTP 403 拒否を最大3分間許容し、ブロックが続く場合は拒否元を表示
・起動レスポンス改善：自動更新チェックが起動と CPU を競合する代わりに、起動後約10秒後に実行されるようになった
・バンドルされた `claude-api` skill を Managed Agents の8月19日リリース向けに更新：self-hosted サンドボックスでの web 検索/フェッチのドメイン設定とメモリストア
・フルスクリーンでの Ctrl+L と Cmd+K を常に再描画のみに変更 — ダブルプレスの `/clear` ショートカットを削除し、1行の nvim ターミナルで自動 `/clear` ループが発生しなくなった
・`claude mcp list` と `claude mcp get` で無効なサーバーをヘルスチェックのために接続する代わりに `⊘ Disabled` として表示するように変更
・プロジェクト `.mcp.json` の MCP `headersHelper`、プロジェクトや `--add-dir` エージェントファイルのインライン MCPサーバーで、そのフォルダの信頼ダイアログの承認が必要になった（`claude -p` でも同様）
・プロジェクト `.mcp.json`・プラグイン・エージェントファイルの MCP `headersHelper` が継承された認証情報環境変数なしで実行されるようになった；ユーザー・管理・claude.ai スコープのヘルパーは Claude 設定ディレクトリから実行されるようになった
