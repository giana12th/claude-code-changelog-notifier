🔧 **Claude Code アップデート**
**v2.1.267**
・`maxEffortLevel` 設定を追加（トップレベルまたは `modelSettings` 配下でモデルごとに設定可能）：Bedrock、Vertex、Foundry を含む全プロバイダーでの effort レベルに上限を設ける。ユーザーはより低いレベルを選択可能
・`--system-prompt-snapshot off` を追加：会話の記録済みプロンプトを再利用する代わりに、毎リクエストごとにシステムプロンプトを新たにレンダリングする（プロンプトテキストを反復作業する場合に使用）
・サンドボックスを必要とする組織のマネージド設定で Cowork のスケジュールタスクがクラウドの起動時に失敗する問題を修正
・モバイルクライアントで `/context` やその他のローカルコマンド出力が空白になって表示される問題を修正
・tmux や ssh セッション内のエージェントビューに再接続した後、shift+enter と option+backspace が機能しない問題を修正
・フルスクリーンモードでスクロールアップする際、薄暗い last-prompt ヘッダーが会話の最上部に表示されない問題を修正
・auto モードで出力スキーマが大きい Workflow の `agent()` 呼び出しが安全性分類器でチェックされる代わりに拒否されていた問題を修正
・macOS と Linux で、バックスラッシュを含むマーケットプレイスエントリのパスがフェッチされたマーケットプレイスの封じ込めチェックをバイパスできるケースを修正
・Claude Desktop などのホストアプリで有効期限切れの AWS または Google Cloud 認証情報が再認証エラーの前に汎用的な「request failed」で 10 回リトライしていた問題を修正
・`/compact` などのスラッシュコマンドが `-p --resume` で実行された後にセッションを再開すると、不要な「Continue from where you left off.」ターンが挿入される問題を修正
・大きいセッション（スクリプト 5MB 超）を再開すると、並列ツール呼び出しとそのフック出力が再読み込みされた会話から削除される問題を修正
・読み取り不能な場合にマネージド設定の `allowedHttpHookUrls`、`httpHookAllowedEnvVars`、`allowedChannelPlugins` が何も許可しないのではなく全てを許可していた問題を修正
・マネージド設定がサインインに Claude apps ゲートウェイを必要とするマシンで `/login` の Esc がダイアログを閉じずに何もしない問題を修正
・アップロード中に接続が切断されたアーティファクトの公開が失敗する問題を修正：アップロードが完了していないと判断できる場合は一度再試行するようになり、不明な結果として報告されなくなった
・Opus 4.7、Opus 4.8、Fable 5 などデフォルト effort がピン留めされているモデルで、カスタムコマンド・スキル・サブエージェントの `effort:` frontmatter が無視される問題を修正
・ページファイルが有効な UTF-8 でないか置換文字 (U+FFFD) を含む場合にアーティファクトの公開が役に立たないエラーで失敗する問題を修正；エラーは修正すべき行と列を示すようになった
・`claude agents` の `@` ディレクトリメニューがセッション開始後に作成されたリポジトリを一覧表示しない問題を修正
・Remote Control クライアントが Claude Desktop または VS Code セッションに参加した際、パーミッションモードが再度変更されるまで古い状態を表示する問題を修正
・`claude remote-control` のサーバー認証情報が期限切れになると（開始から約 30 日後）終了して全アタッチセッションをドロップする問題を修正；ホストは再登録して継続するようになった
・異なるモデルやモードへのリクエストが異なる制限ウィンドウを報告する場合に使用制限警告がセッション中に点滅する問題を修正
・MCP サーバーが再送信するか組み込みツールがモデルがすでに読み込んだツールを再レンダリングすると、以前の推論が削除される問題を修正
・切断された MCP サーバーやアップグレードなどで会話の途中でツールが消えると、ツールリストが書き換えられ以前の思考が破棄される問題を修正
・会話からフォークされたバックグラウンドワーカーがセッション途中に EnterWorktree を会話のツールブロックに追加し、プロンプトキャッシュの再利用を壊す問題を修正
・ToolSearch なしのセッションでセッション途中に MCP とプラグインのツールがツールリストに追加されプロンプトキャッシュの再利用を壊す問題を修正；対応モデルは遅延定義として受け取るようになった
・`/model` でモデルを切り替えると全ツール定義を再送信する（プロンプトキャッシュミス）問題を修正；コミットと PR の帰属テキストはモデル変更時に更新される会話メモとして届くようになった
・再開されたセッションが MCP コネクターが以前と異なるタイミングで再接続する際にインラインツールセットを書き換える問題を修正
・再開されたセッションが最初のターンでツールを実行した際に記録済みツールを再生する代わりにツール説明を再レンダリングする問題を修正
・claude.ai コネクターのツールがセッションと再開の間に変わると、プロンプトキャッシュミスと拡張思考の削除が発生する問題を修正
・再開されたセッションがコネクターが再接続する前に以前の MCP ツールアナウンスを書き換える（拡張思考を削除する）問題を修正
・print モード（`-p`）の会話をインタラクティブに再開する際のプロンプトキャッシュミスを修正：システムプロンプトプレフィックスが変更されなくなった
・`/diff` パネルを改善：設定前に「0 files changed」とスピナーが点滅しなくなり、空状態はパネルの中央に表示される
・Bash ツールの説明ガイダンスを改善：Claude がコマンドをエコーする代わりに平易な言葉でコマンドの内容を説明するようになった
・サンドボックス内で `pbcopy` などのクリップボードコマンドが失敗した場合に Claude が `/copy` を提案するようサンドボックスガイダンスを改善
・多くの Bash ツール呼び出しを含むセッションの `--resume` 初期レンダリング時間を改善
・プロンプト入力の応答性を改善：スピナーやストリーミングの再描画でキーストロークが1フレーム遅延することがなくなった
・プロンプトキャッシュの安定性を改善：`--system-prompt` または `--append-system-prompt` で開始されたサブエージェントとセッションが、システムプロンプトとツール定義を再レンダリングする代わりに一度記録するようになった
・Artifact ツールの公開エラーを改善：公開が拒否された場合、メッセージにその理由と対処方法が表示されるようになった
・Self-hosted runner: `--use-anthropic-git-proxy` を登録時にサーバーに報告し、レガシー git プロキシ経由でクローンしているセッションごとに警告を表示するよう変更
・Gateway: `forward_user_identity` アップストリームが、メールが転送された開発者に対して次のアップストリームにフェイルオーバーする代わりに 429 をそのまま返すよう変更；プロキシのユーザーごとの制限が維持される
・[VSCode] エディターホストが循環する親リンクを含む保存済みスクリプトの会話でフォーク・メッセージ編集・巻き戻し時に 100% CPU でハングする問題を修正
・[VSCode] WSL2/WSLg でスクリーンショットを貼り付けるとチャット入力に生のイメージバイトが挿入される問題を修正；クリップボードが提供する場合は画像がアタッチされ、そうでない場合は貼り付けが無視される
・[VSCode] チャット diff ブロックが常にダークエディターテーマでレンダリングされる問題を修正；アクティブな VS Code カラーテーマ（高コントラスト含む）に従うようになった
・[VSCode] メッセージ入力での入力中に右から左と英語が混在したテキストが誤った順序でレンダリングされる問題を修正
・[VSCode] diff ビューで Windows (CRLF) 改行のファイルの編集を受け入れると「String not found in file」で失敗する問題を修正
・[VSCode] スペースを含むパスのファイルを @-メンション でドロップする問題を修正
・[VSCode] リモートホストにのみワークスペースフォルダーが存在する Remote-SSH で接続されたウィンドウでセッションリストビューが読み込まれない問題を修正
・[VSCode] 大規模またはシンボリックリンクが多いワークスペースでファイルを表示する際の暴走 ripgrep プロセスを修正
・[Claude Code on the web] GitHub Enterprise Server セッションで、トークンが期限切れになると GitHub アカウントが切断済みとして表示される問題を修正；PR とイシュー操作が自動的に更新するようになった
・[Claude Code on the web] Claude GitHub App のない組織で `gh` と GitHub API 呼び出しが失敗する問題を修正；接続された GitHub アカウントを使用するようになり、接続されていない場合はその旨を伝える
・[Claude Tag] Claude Tag 管理者設定のプリセット接続フォームに「カスタムコネクターを使用する」リンクを追加；最初からやり直すことなくカスタム接続に切り替え可能
・[Claude Tag] 組織の使用クレジットが枯渇した際に Claude が「The API rejected the request as invalid」と返す問題を修正；その旨と追加方法を説明するようになった
・[Claude Tag] チャンネルのトップレベルで Claude が投稿したメッセージの編集または削除リクエストがスレッドで、それを投稿したセッションに届く代わりに修正として回答される問題を修正
・[Claude Tag] 管理者設定 > レビューリクエスト でのツールアクセスリクエストへの **Connect** が「Authorization failed」で失敗したり、リクエストされたアクセスバンドルが削除済みとして表示される問題を修正

**v2.1.266**
・2.1.265 のリグレッションを修正：LLM ゲートウェイおよびプロキシ設定に影響するもの。文書化されていない `CLAUDE_CODE_USE_GATEWAY` 環境変数が 2.1.265 で単独で Cloud ゲートウェイサインインを強制するようになり、API キー・`apiKeyHelper`・カスタム認証ヘッダーとともに設定された構成が「Not signed in to the Cloud gateway」ですべてのリクエストに失敗するようになっていた。この変数は単独では再び無視される；構成の変更は不要
