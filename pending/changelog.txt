🔧 **Claude Code アップデート**
**v2.1.150**
・内部インフラの改善（ユーザー向け変更なし）

**v2.1.149**
・`/usage` でスキル・サブエージェント・プラグイン・MCPサーバーごとの利用制限内訳を表示するようになった
・`/diff` の詳細ビューでキーボード（矢印・`j`/`k`・`PgUp`/`PgDn`・`Space`・`Home`/`End`）によるスクロールが可能になった
・Markdown出力でGFMタスクリストチェックボックス（`- [ ] todo` / `- [x] done`）が箇条書きではなく正しくレンダリングされるようになった
・Enterprise: `allowAllClaudeAiMcps` マネージド設定を追加し、`managed-mcp.json` と並行してclaude.aiクラウドMCPコネクタを読み込めるようになった
・PowerShellの権限バイパスを修正：組み込みの`cd`関数（`cd..`・`cd\`・`cd~`・`X:`）が検知されずにワーキングディレクトリを変更し、後続コマンドがワークスペース外を読み取れた問題
・gitワークツリーでのサンドボックス書き込み許可リストが共有`.git`ディレクトリのみではなくメインリポジトリルート全体を対象にしていた問題を修正（`hooks/`と`config`は拒否）
・PowerShellのプレフィックス/ワイルドカード許可ルール（例：`PowerShell(dotnet.exe build *)`）がネイティブ実行ファイルとスクリプトを事前承認しなかった問題を修正
・パーサーが`cd`/`pushd`/`popd`をまたいで`PWD`/`OLDPWD`/`DIRSTACK`の古い変数追跡値を信頼していた権限解析の欠陥を修正
・BashツールのfindがmacOSのシステムファイル/vnodeテーブルを枯渇させ、大規模ディレクトリツリーでホストがクラッシュする問題を修正
・マネージド設定の承認ダイアログが起動時に承認後もターミナルが固まる問題を修正
・`/ultraplan` とリモートセッション作成で作業ツリーに実際の変更がない場合に "Could not capture uncommitted changes" で失敗する問題を修正
・`otelHeadersHelper` でスクリプトパスにスペースが含まれると黙って失敗する問題を修正（ヘルパーの失敗は`/doctor`とデバッグログに報告されるようになった）
・thinkingスピナーがツールコール間でアンバーのままになり、新しいthinkingバーストにも持ち越される問題を修正
・短い行が多い出力で折りたたまれたBash出力が非表示行数を誤って表示する問題を修正
・スラッシュコマンドの引数ヒントが入力ボックスをオーバーフローする際に末尾に入力した文字が切り取られる問題を修正
・`name:` フロントマターがディレクトリのベース名と異なるスキルをTab補完した後に引数ヒントとプログレッシブ引数サジェストが表示されない問題を修正
・ステータスバーがスキル/エージェントの`effort:`フロントマターで適用されたエフォートレベルではなくユーザーのベースライン`/effort`設定を表示する問題を修正
・Ctrl+Oのトランスクリプトビューが開かれた時点で固まり新しいメッセージが追従しない問題を修正
・呼び出したプロンプト履歴エントリの編集を上下矢印キーでさらにナビゲートすると編集が失われる問題を修正
・無関係な設定を切り替えた際に`/config`終了サマリーがauto-compactとテーマへの意図しない変更を報告する問題を修正
・キャッシュされたセッションメタファイルにオプションフィールドが欠けている場合に`/insights`がクラッシュする問題を修正
・入力が欠けた不正なPowerShellとHistoryツールコールがトランスクリプト折りたたみで誤って読み取りに分類される問題を修正
・claude.aiまたはClaudeモバイルアプリからRemote Controlセッションをリネームしても`claude --resume`のローカルセッション名が更新されない問題を修正
・送信したばかりのプロンプトが上矢印履歴に二重表示される競合状態を修正
・フルスクリーンモードで「Jump to bottom」ピルをタップしても即座に消えない問題を修正
・`/feedback`レポートにコンテキスト圧縮前の会話を含めることで、長いセッションの早い段階で発生した問題のトリアージが容易になった
