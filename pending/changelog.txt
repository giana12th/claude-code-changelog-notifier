🔧 **Claude Code アップデート**
**v2.1.293**
・Claude Haiku 5.5（`claude-haiku-5-5`）を追加。Anthropic APIのデフォルトHaikuモデルに設定。コンテキスト1M、$0.10/$0.50/Mtok（100Kトークン超のプロンプトは$0.50/$2.50）
・`subagentStatusLine`ペイロードに`agentType`を追加。スクリプトがカスタムサブエージェントタイプを識別できるようになった
・modの`$.tool.register`に`isDeferred`を追加。`false`を指定するとツールスキーマがtool searchを経由せず最初からプロンプトに含まれる
・コンテキスト圧縮前の最後の操作を、圧縮後に完了済みとして誤認識し、完了した作業を取り消したり再実行したりする問題を修正
・HTTP MCP接続が閉じるまで全リクエストを保持し続けるメモリリークを修正
・Claudeの作業中に送信したメッセージが、`←`でセッションをバックグラウンドに移した際に失われる問題を修正。キュー済みメッセージが移動できない場合、`←`は現在位置に留まりその旨を表示するようになった
・`/model`のeffort ←/→が最高・最低レベルを超えて折り返し、誤ってLowをモデルのデフォルトeffortとして保存する問題を修正
・`--chrome`で起動したセッションで`/tui`がClaude in Chromeを切断したり、`--no-chrome`を無視したりする問題を修正
・ホスト、パーミッションルール、または`--tools`リストでツールが除外されたセッション（再開済みセッションを含む）で、Claudeが`SendMessage`でサブエージェントに継続またはメッセージを送るよう指示される問題を修正
・自分のツールリストから除外されているだけなのに、組み込みツールがセッション全体で無効化されていると通知されるサブエージェントと`--agent`セッションの問題を修正
・claude.aiで同期したスキルの編集済みの説明が、新しい会話か`/clear`まで時々モデルに反映されない問題を修正
・ログインが期限切れまたは期限切れ間近の場合に、`claude logs`、`stop`、`kill`、`rm`、および`claude daemon status`、`stop`、`uninstall`が時々サインアウトさせる問題を修正
・セッションフォルダの一時的な読み取り失敗（例：ファイルが多すぎる）後に、フッターのエージェント数が消える問題を修正
・`worker`という名前のカスタムエージェントが起動時に"Agent"と表示される問題、およびエージェント終了後にエージェント詳細ダイアログのタイトルからエージェントタイプが消える問題を修正
・publishコールのストリーミング中に、ArtifactツールのトランスクリプトRowが一時的に`Artifact("(unprintable path)")`と表示される問題を修正
・Linuxの`/ultrareview`アップロードが、サンドボックスコマンド実行中に設定ファイルが"解析できない"として、別のチェックアウト内にあるリポジトリなどを誤って拒否する問題を修正
・split-indexファイルに関する`/ultrareview`アップロードの拒否が、gitがindexを読み取れなくなる可能性のあるgitコマンドを提案する問題を修正
・非常に長いRemote Controlおよびクラウドセッションで、返答がストリーミングではなく一度にブロック単位で表示される問題を修正
・Remote Controlが認証情報の回復ごとにセッションの開始履歴を再アップロードする問題を修正
・`claude remote-control`で起動したセッションでPushNotificationが"Remote Control inactive"と報告する問題を修正
・プラグインhooksワーカーの再起動中に、`classic.*`イベントのmodのhooksがスキップされ、settings hooksが単独で応答する問題を修正
・`$.session.append`を呼び出すmodで`claude plugin test`が失敗する問題を修正。テストは新しい`mock.session`で追加された行を読み取ることができるようになった
・Docker Desktop（`~/.docker/bin`以下のリンク）を使用したMacで、`claude plugin eval`がBashを許可するすべての実行を拒否する問題を修正。拒否メッセージはリンクを保持した認証情報ストアのどの部分かを示すようになった
・`desktop`ポリシーが`builtinBrowserEnabled`などのClaude Desktopの組み込みブラウザキーを設定した場合に、Claude appsゲートウェイが起動を拒否する問題を修正
・`claude agents`が提供したbypassパーミッションを、同意が`.claude/settings.local.json`または`--settings`ファイルにのみ保存された場合にバックグラウンドセッションが無視する問題を修正。同意を最初に求め、bypassを無視したセッションは残り続ける短い通知を表示するようになった
・プロンプトに未送信テキストがあるとき（移動をキャンセルするようになった）や、質問が回答待ちのときに、`←`が10秒後にセッションをバックグラウンドに移す問題を修正
・セッションをバックグラウンドに移すために`←`を押した直後に、パーミッションプロンプトでEscまたはフィードバックなしのNoを押してもターンが停止しない問題を修正
・セッションフォルダが読み取れない場合（例：ファイルが多すぎる）に、agentsビューがセッションリストをプレースホルダーの行に一時的に置き換える問題を修正
・ReadツールではなくBashツールのcat, head, tail, `sed -n`またはgrepコマンドでファイルを閲覧する際に、パススコープのルールとネストされたCLAUDE.mdファイルが読み込まれない問題を修正
・同じ語句で始まり終わるペーストされたテキストが、タイプされたかのようにClaudeに送信される問題を修正
・ペーストの直後にタイプまたはペーストされたアクセントが最後の文字に結合された際に、ペーストされたテキスト内のスキル名がタイプされたものとして扱われる問題を修正
・レポート送信中にCtrl+OまたはCtrl+Zを押すと`/feedback`が下書きリストに戻り、送信がキャンセルできなくなる問題を修正
・ファイルまたはフォルダを削除できない場合に`claude purge`が無音で停止（exit 0、またはターミナルのハング）する問題を修正。残りを削除し、削除できなかったものを一覧表示し、exit 1で終了するようになった
・keybindings.jsonチェックの修正：単独の" "（スペースキー）がエラーとして報告されなくなった。また"ctrl+ k"のようなキーが警告を出すようになった
・スペースだけの行でのvimモード`>>`と`<<`がカーソルを行末より後ろに残し、続く`x`が何も削除しない問題を修正
・vimモードの修正：Visualモード（`V`から`d`）で行全体を削除した後、カーソルが最初の非空白に移動し、その後の`.`がカーソル行に作用するようになった
・Windows：ステータスライン、hook、またはシェルコマンドの停止が、同じプロセスIDを割り当てられた無関係なプロセスを時々終了させる問題を修正
・2.1.281で行ったauto modeの拒否メッセージの変更（Claudeに拒否が正確なコマンドだけでなく結果もカバーすると伝えていた）を元に戻した
・2.1.290で行った、コンテナ再起動で保留中の`/loop`ウェイクアップまたはスケジュールされたタスクが失われた後にクラウドセッションがスリープしたままになる問題の修正を元に戻した。Claudeは通知されなくなり、セッションはスリープしたままになる
・TeamおよびEnterprise organizationsの起動を改善：ポリシーとmanaged settingsがより早く取得され、停止したリクエストは3秒後に再試行される
・Claude in Chromeを改善：ブラウザがタブの報告に時間がかかる場合でも、拒否されるページアクションが減った
・ブラウザに接続できない場合のクラウドセッションでのClaude in Chromeメッセージを改善：複数のorganizationに所属している場合、extensionが同じorganizationにサインインする必要があること、およびその変更方法を表示するようになった
・Bash編集のdiff注記を改善：一覧のファイルがコマンド実行中に変更されたことを示すようになった。他のプロセスによる書き込みが含まれる場合もある
・artifactsを改善：Claudeが2週間以上前の正確なバージョンにライブラリをピン留めするようになった
・セッション未使用中のclaude.aiスキル同期を、10分ごとから約40分ごとに変更した
・モデルに通知するエージェントリストとMCPサーバーの順序を変更：非ASCII文字を含む名前がASCII名の後にソートされるようになった
・OpenTelemetry `claude_code.at_mention`ログを、プロンプト読み取りごとに最大100エージェントと100 MCP-resourceイベントのみ出力するよう変更
・Self-hosted runner：オーケストレーターのポーリング間隔を一定の5秒から4〜6秒のランダムに変更。同じ環境の複数のレプリカが同時にポーリングを停止しないようにした
・[Claude Tag] 接続されていないワークスペースのメッセージにSlackがラベルを付けた場合に、ワークスペース間で共有されるEnterprise Gridチャンネルでワークスペースが設定されていないとClaude in Slackが表示する問題を修正
・[Claude Tag] 管理者がチャンネルのconnectors、plugins、skillsまたはrulesを変更した場合に、Claude in Slackがチャンネルでタスク途中に停止する問題を修正。変更はClaudeが完了後に適用されるようになった
・[Claude Tag] Claude in Slackにスレッドのroutineを追加メモ付きで実行するよう依頼すると、投稿できない別の実行が開始される問題を修正。実行はそのスレッドで続行されるようになった
・[Claude Tag] Claude Tag admin settingsのaccess bundleのAdd a connectorダイアログが、1つのGoogleサインイン後にすべてのGoogle connectorを接続済みとして表示する問題を修正
・[Claude Tag] Claude Tag admin settingsを改善：未接続のEnterprise Gridを、Connectボタンと共に一覧表示するようになった
・[Claude Tag] Claude in Slackが、管理者のみ投稿できるアナウンスチャンネルに、イントロを投稿せずに参加するよう変更
・[Claude Tag] Claude Tag admin settingsのチャンネルルール上限を、各ワークスペースおよびorganization全体のSlackページで20から50に変更
・[Code Review] Code ReviewのAdd a repositoryダイアログを改善：GitHub書き込みアクセスがないなど、追加できなかった各リポジトリとその理由を一覧表示するようになった
