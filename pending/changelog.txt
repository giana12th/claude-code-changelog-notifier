🔧 **Claude Code アップデート**
**v2.1.224**
・自己ホスト型環境を追加: `claude self-hosted-runner` コマンドで自分のマシンやコンテナを Claude Code のウェブ・モバイル・デスクトップセッションの実行場所にできる（Team・Enterprise プラン）
・`archive` プラグインソースを追加: git や npm なしで HTTPS 経由の zip からプラグインをインストールできる。オプションで SHA-256 ピン止めも可能
・貼り付けたテキストが変更されてコマンドのテキストが変わる場合に、キャンセル＆確認ステップを追加
・Bedrock 向けに `ANTHROPIC_BEDROCK_REGION_PREFIX` 環境変数を追加: `AWS_REGION` から導出されたプロファイルより特定のクロスリージョン推論プロファイルを優先できる
・`crossSessionInbound` および `dialogExpiry` 設定を追加: バイパス権限で実行中のセッションへのクロスセッションメッセージは承認待ちで保留され、他のセッションへのメッセージは自動配信される
・サンドボックスのクレデンシャルマスキングオプションを追加: 構造化環境値に対する `extract` と `onExtractNoMatch`、JWT 対応マスキングに対する `decode: "jwt"` と `maskClaims`、AWS SigV4 再署名に対する `awsPairs`/`sigv4`（`network.tlsTerminate` が必要、ユーザー・managed・`--settings` 設定からのみ有効）
・クロスセッション `SendMessage` を追加: Claude Code セッション同士が `ListAgents` でお互いを探し、任意のマシン上でメッセージを送り合えるようになった（macOS・Linux）
・長い（200文字超の）プロジェクトパスが共有プレフィックス配下で別プロジェクトのセッションディレクトリに解決される問題を修正: セッション一覧・リネーム・フォーク・削除・`/resume` がプロジェクト間で混在しなくなった
・`SendMessage` がチームメイトのインボックスへの書き込みが失敗しても「Message sent」と報告していた問題を修正: 配信失敗はエラーとして報告されるようになった
・サンドボックスのファイルシステム deny エントリをスラッシュ付き（例: `denyRead: "~/.aws/"` ）で書いた場合に Linux・macOS でサイレントにバイパスできた問題を修正
・サンドボックス違反の詳細が Bash ツールの結果に表示されなかった問題を修正: Claude がどのファイルまたはネットワークアクセスが拒否されたか・理由を確認できるようになった
・ターン途中で接続した MCP ツールがツール検索で延期されるものの、モデルに名前がアナウンスされていなかった問題を修正
・同じプラグインが複数プロジェクトにインストールされている場合にプラグインインストール記録がサイレントに破損していた問題を修正
・貼り付けコンテンツが古くなったり、プレースホルダー番号が衝突した際に間違ったデータが添付されたりテキストがサイレントに失われたりしていた問題を修正
・Wayland でのコピーオンセレクトがクリップボードに届かないことがあった問題を修正: 2つの選択書き込みの競合を解消
・フィードバックサーベイのトランスクリプト共有が長いセッションでサイレントに失敗していた問題を修正: 共有失敗時はエラーが表示されるようになった
・Remote Control の自動起動が古いログイントークンでコールドスタート時に断続的に失敗していた問題を修正
・Remote Control および SDK クライアントが `/clear` などの出力なしコマンドの後に空白の「(no content)」メッセージを表示していた問題を修正
・Remote Control セッションがサーバーセッション期限切れ後に再作成された際に以前のローカル会話履歴が新しいセッションにアップロードされていた問題を修正
・フルスクリーンモードを改善: 最新の区間だけでなく、繰り返しのコンパクション全体でコンパクション前の履歴がスクロールバックに保持されるようになった
・Remote Control を改善: 接続中のウェブ・モバイルクライアントがコンパクションの進捗とコンパクション後の境界を表示するようになった; `/clear` のリセットが接続クライアントに伝播するようになった
・Remote Control を改善: 接続失敗時に 8秒のトースト通知だけでなく、詳細と再接続ショートカット付きの永続的な失敗インジケーターが表示されるようになった
・セッションあたり 200 サブエージェントの上限を撤廃: 長時間実行セッションで新しいエージェントが拒否されなくなった（同時実行・深さ制限は引き続き適用）
・managed 設定を変更: 組織の設定が変更されていない場合、再ログインや組織切り替え後に承認プロンプトが再表示されなくなった
・フィードバックサーベイのトランスクリプト共有を変更: 同意のうえで、最後のリクエストのモデル設定（システムプロンプト・ツール定義・モデルパラメーター）もアップロードされるようになった。シークレットは従来通り編集され、共有サイズが大きすぎる場合はこれらのフィールドが最初に除外される
・Bash ツールの説明を変更: コマンドの出力はモデルに表示されるが、ユーザーには確実には表示されないことを常に注記するようになった
・貼り付けのプレースホルダー番号が承認後に再採番されるよう変更
・Remote Control を変更: コンパクションや `/resume` 後に新しいセッションが生成された際に古いサーバーセッションがアーカイブされるようになった
・[VSCode] 接続が失敗した後も Remote Control が接続済みと表示されていた問題を修正
・セッション再開がユーザーが無効化した後も Remote Control をサイレントに再接続していた問題を修正（`--resume`・SDK ホスト・VS Code 拡張）
・[VSCode] `remoteControlAtStartup` を明示的に有効化したときにセッションが設定を反映していなかった問題を修正

**v2.1.223**
・`strictKnownMarketplaces` および `blockedMarketplaces` の managed 設定にオーナーワイルドカードエントリ（`"owner/*"`）を追加: GitHub org 配下のすべてのマーケットプレイスリポジトリを一括で許可・ブロックできる
・ワークフローエージェント・フォークされたスキル・スラッシュコマンド・再開されたバックグラウンドエージェントのリクエストしたサブエージェントモデルが制限されていて親モデルで代替実行される場合に警告を追加
・クラウドセッションで `claude --teleport <session id>` を使ってローカルで継続する方法を示す `/teleport` ヒントを追加
・細工したコマンドで権限チェックから一部を隠せていた Bash の権限バイパスを修正
・タブや不可視の Unicode でパディングされたコマンドが承認ダイアログでコマンドの一部を隠せなくなるよう権限プロンプトを修正
・ワークフロースクリプトが動的 `import()` を使ってワークフローサンドボックス外のコードを実行できていた問題を修正
・エージェント定義の `bypassPermissions` モードが組織のバイパス権限無効化ポリシーを無視していた権限ギャップを修正
・中間の `/cd` 後にセッションを再開すると空で戻ってくる問題を修正
・`vertex_ai/claude-*` や `bedrock/anthropic.claude-*` などのプロバイダープレフィックス付き ID で登録された Claude モデルがゲートウェイモデル検出で隠れていた問題を修正
・`modelOverrides` のキーが Anthropic モデル ID でない場合にセッションの正規モデル ID として扱われていた問題を修正: 未知のキーはドキュメント通り無視されるようになった
・managed 設定を修正: サーバーから配信された設定がマシンローカルの `managed-settings.json` や MDM プロファイルの環境ブロックを無効化しなくなった: 管理者環境はキー単位でマージされるようになった
・`sandbox.filesystem.denyWrite` が作業ディレクトリをカバーしている場合に Linux でサンドボックス化されたコマンドの起動に失敗していた問題を修正
・フォークされたバックグラウンドエージェントが再開中に親プロンプトの再構築に失敗した際にセッション中ずっと「already resuming」でスタックしていた問題を修正
・履歴に不正な診断添付ファイルが含まれていた場合に再開したセッションの毎ターンが失敗するか、アプリが応答しないエラー画面のまま残っていた問題を修正
・通常と異なる `git push` 出力のパース時に稀にハングしていた問題を修正
・`CLAUDE_CODE_DISABLE_1M_CONTEXT` を変更: ネイティブ 1M ウィンドウを持つすべての Claude モデルを固定リストではなく自動コンパクションで 200K に制限するようになった: 自動コンパクションがセッションを 200K に保てていない場合に起動時の警告が表示される
・自動コンパクションを変更: 不明なモデル ID のセッションを想定コンテキストウィンドウ内に収めるようになった: `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1` で以前の挙動に戻せる
・`/review` を `/code-review` のエイリアスに変更（`/code-review <level> <pr#>` で現在の差分または PR をレビュー）: 詳細なクラウドレビューには `/code-review ultra` を使用
・`/code-review` の引数なし実行時に最後に入力したレベルを再利用するよう変更: レベルを変更するには `/code-review high` のように入力する
