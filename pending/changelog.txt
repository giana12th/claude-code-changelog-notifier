🔧 **Claude Code アップデート**
**v2.1.302**

**追加**
・`CLAUDE_CODE_AUTO_MODE_MODEL` を追加。クライアント側 auto mode 分類器が使用するモデルを選択できる（サーバー側 auto mode のモデルは変更しない）
・`/config` に `Idle compaction` 行を追加。アイドル圧縮のオン/オフを切り替えられる。圧縮後の通知にも無効化方法が記載されるようになった
・`/design-sync` と `/design-login` に、スタンドアロンの Claude Design（claude.ai/design）が2026年12月14日に終了する旨の通知を追加
・[Cloud sessions] ルーティーンのページに、直近の実行が開始されなかった理由（例: 組織の同時クラウドセッション数上限到達）を示すバナーを追加

**変更**
・`claude -p` およびパーミッションモード未指定の Agent SDK セッションが、サードパーティプロバイダー上でテレメトリ無効またはクリーンインストール時に `default` モードで開始されるよう変更。`--permission-mode auto` で auto モード維持可能
・フォークサブエージェント（`subagent_type: "fork"`）が `claude -p`、Agent SDK、デスクトップアプリ、VS Code でもデフォルトで有効に変更。`CLAUDE_CODE_FORK_SUBAGENT=0` で無効化可能。`claude mcp serve` では常に提供されない
・デスクトップアプリと VS Code でメイン会話のサブエージェントが常にバックグラウンドで実行されるよう変更（ターミナルと同様）。サブエージェント自身の Agent 呼び出しは `claude -p`、Agent SDK、デスクトップアプリ、VS Code でデフォルトフォアグラウンドに変更
・`← for agents` のフッターヒントがセッション開始10秒後に非表示になるよう変更。応答待ちエージェント数は引き続き表示
・新しい会話が共有プロンプトキャッシュから Claude in Chrome の指示を読み取れるよう、システムプロンプト内の配置場所を変更
・プロンプトおよびエージェントフックが同時に最大12件実行されるよう変更。残りはキューで待機
・組織ポリシーで `/feedback` が無効な際のメッセージを変更。組織管理者ではなく GitHub Issues へのリンクを案内するように
・[Claude Tag] 管理設定で Claude のアクセスを「Bundles」「Connectors」「Skills and plugins」「Channels」の4タブに整理するよう変更
・[Claude Tag] 組織設定のロールページで、Claude Tag チャンネルマネージャー向けロールが折りたたまれたセクションに表示されるよう変更

**改善（7件）**
・多数プラグイン有効時の起動時間を改善。プラグインファイルの読み込みに必要なファイルシステム呼び出しを大幅削減（特に Windows）
・サーバー側分類器を使用した auto mode を改善。会話が安全性チェックに長すぎる場合、すべてのツール呼び出しを拒否する代わりに圧縮されるようになった
・別フォルダから再オープンしたバックグラウンドセッションに LLM ゲートウェイがない場合のメッセージを改善。「Not logged in」ではなく理由が表示されるように
・[Cloud sessions] 起動失敗時のエラー表示を改善。「Something went wrong」ではなく「Connection lost」または「Server error」と表示
・[Claude Tag] リポジトリ検索を改善。最大100の GitHub アカウントと、GitHub App インストールの最初の5,000件を超えるプライベートリポジトリも検索可能に
・[Claude Tag] 「Add place」で入力・貼り付けたチャンネルを全チャンネル一覧読み込み完了を待たずに即座に表示するよう改善
・[Claude Tag] 「Add > Domain」がページ読み込み直後から利用できるよう改善（全チャンネル読み込み待ち不要）

**バグ修正（43件）**
・ターン停止中に会話圧縮中だった場合の「Prompt is too long」エラーを修正
・セッション途中での Vertex または Bedrock への切り替え後、「diagnostics: Extra inputs are not permitted」エラーでリクエストが失敗する問題を修正
・Read ツールが任意サイズの画像ファイルを全量メモリに読み込む問題を修正（128 MB超は拒否）
・`/autocompact` と `/effort` が、`anthropic/claude-opus-4-1` などプレフィックス付きゲートウェイで誤ったモデルに保存される問題を修正
・ToolSearch またはコンパクション後に再読み込みされたツールがプロンプトキャッシュミスを引き起こす問題を修正
・`claude plugin` 等のサブコマンドが設定書き込み完了前に終了し、変更が失われたり `.tmp` ファイルが残る問題を修正
・プラグインマーケットプレイスが更新のたびに再クローンされる問題、git reftable 形式使用時に新規インストールプラグインのバージョンが「unknown」と表示される問題を修正
・PowerShell ツールがプラグインの `bin/` フォルダ内のコマンドを見つけられない問題、検索結果なし時に `Select-Object` 等へのパイプでエラーが出る問題を修正
・デスクトップアプリで利用できない場所への MCP サーバー認証/再接続リンクが表示される問題を修正
・Claude が空の編集リストを送信した場合のアーティファクト公開失敗、および差し戻し後の誤った再試行を修正
・auto mode 分類器ブロックの `classifier_category` が OpenTelemetry `tool_decision` イベントにほぼ含まれない問題、`OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT` が低い場合に新しい属性が既存属性を押し出す問題を修正
・長いリストスクロールやセクション折りたたみ後、エージェントビューの行が空白のままになる問題を修正
・未サインイン時に `claude remote-control --help` がヘルプを表示せず終了する問題を修正
・`/design consent` と `/design revoke` がクラウドセッションで失敗時に利用できない `/design-login` を提案する問題を修正。claude.ai/design/settings へのリンクを案内するように
・プロトコルバージョン 2026-07-28 を交渉したが `resultType`、`ttlMs`、`cacheScope` を省略した MCP サーバーでツール表示や呼び出しが失敗する問題を修正
・クレジット払いモデルへのプロンプト候補がクレジットを消費する問題を修正。クレジット課金後はスキップされるように
・バッククォート内の URL が折り返し時に最初の行のみクリック可能になる問題を修正。ハイパーリンク対応端末では URL 全体が1つのリンクになった
・`claude plugin details <name>@builtin` がプラグイン未発見時に `claude plugin list` を提案する問題を修正。`/plugin` へのリンクを案内するように
・リンク内に絵文字が含まれる場合に1列余分に折り返され、質問プレビューで非表示になったりテーブルがリストになる問題を修正
・git 2.56 以降でワークツリー分離が存在しないディレクトリを指す `.git` ファイルがある場合に作成/再開を拒否する問題を修正
・クラウドセッションのコストと使用量が新しいプロセスで再開後にゼロからリスタートする問題を修正
・[Self-hosted runner] reftable フォーマットのチェックアウトを再利用するセッションで git フェッチが「bad object refs/heads」で失敗する問題を修正
・[Windows] exFAT または FAT32 ドライブ上のプロジェクトで全ファイル書き込みが拒否または確認を求められる問題を修正
・[VSCode] リプライストリーム中、リスト内の未閉じコードブロック後のテキストがプレーンテキスト表示になる問題を修正
・[VSCode] サーバー URL にクエリ文字列が含まれる MCP サーバーのサインインで壊れた認証ページが開く問題を修正
・[VSCode] Claude 拡張機能を持つブラウザが利用できない場合に `@browser` バナーが「Browser connected」と表示される問題を修正
・[Cloud sessions] 最新メッセージ以外で「Rewind to here」が失敗する問題を修正（セルフホストランナーは v2.1.246 以降が必要）
・[Cloud sessions] GitHub が再確認中にマージコンフリクトありの PR が「準備完了」に戻る問題を修正
・[Cloud sessions] クラウドセッションが予期せず停止後にルーティーン実行が「Completed」と表示される問題、開始前アーカイブ時に「Cancelled」ではなく失敗と表示される問題を修正
・[Cloud sessions] リポジトリのリネームまたは移動後に差分ビューに変更が表示されない、または読み込みに失敗する問題を修正
・[Cloud sessions] 途中で失敗したスケジュール済みルーティーン実行が1時間以上後に最初からやり直され、同じ作業が繰り返される可能性があった問題を修正
・[Cloud sessions] 別デバイスから送信されたメッセージがページリロードまたはタブ切り替えまで表示されない場合がある問題を修正
・[Remote Control] コンピュータがオフラインになった後にサブエージェントのペインが無限スピナーになる問題を修正。Remote Control が切断されていると表示されるようになった
・[Claude Tag] Claude が以前のメッセージを編集して返答した後、「is thinking…」が残り続ける問題を修正
・[Claude Tag] Slack 返信の番号付きまたは箇条書きステップ内のコードブロックの URL が山括弧で囲まれ、コピーしたコマンドが壊れる問題を修正
・[Claude Tag] Slack に添付された HEIC、SVG、TIFF、BMP 画像が Claude に届かない問題を修正。他のファイルタイプと同様に作業ファイルとして渡されるようになった
・[Claude Tag] ロールで Claude Tag を制限している組織で、新しいチャンネルマネージャーが Slack での Claude アクセスを失う問題を修正。マネージャーロールが Slack での Claude Tag も付与するように
・[Claude Tag] 1つのホストを共有する MCP サーバーを持つカスタムコネクターが管理設定で1つのコネクターとして表示される問題を修正。各サーバーが独自のコネクターとして表示されるように
・[Claude Tag] 1つの Slack ルックアップが停止した際に「DMs are temporarily unavailable」と返してメッセージを破棄する問題を修正。先にリトライするようになった
・[Claude Tag] Slack Enterprise Grid での Claude へのダイレクトメッセージが Slack のワークスペースドロップダウンを無視する問題を修正。最後に開いた接続済みワークスペース下で実行されるように
・[Claude Tag] チャンネル月額上限通知がチャンネルマネージャーが上限を引き上げられると示す問題を修正。組織オーナーと使用量ページへのリンクを案内するように
・[Claude Tag] Claude の Slack 返信内のリンクが直後の太字/斜体の記号や全角句読点を吸収し、リンクとフォーマットが壊れる問題を修正
・[Code Review] GitHub の接続後に Code Review 設定の再開が失敗する問題を修正。管理設定に戻るとリポジトリピッカーが再表示されるように
