🔧 **Claude Code アップデート**
**v2.1.212**
・`/fork` がバックグラウンドセッション（`claude agents` に独自の行として表示）に会話をコピーするようになった。作業を続けながら利用可能。これまで `/fork` が起動していたセッション内サブエージェントは `/subtask` に変更
・`claude auto-mode reset` コマンドを追加。確認プロンプト付きでデフォルトの auto-mode 設定に戻す（`--yes` でスキップ可）
・WebSearch ツール呼び出しにセッション全体の上限を追加（デフォルト 200、`CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION` で調整可）。際限ない検索ループを防止
・サブエージェントの生成にセッションごとの上限を追加（デフォルト 200、`CLAUDE_CODE_MAX_SUBAGENTS_PER_SESSION` で変更可）。`/clear` でリセット
・2分以上かかる MCP ツール呼び出しが自動的にバックグラウンドに移動し、セッションを使い続けられるよう改善。閾値の設定や無効化は `CLAUDE_CODE_MCP_AUTO_BACKGROUND_MS` で可能
・agent view で `/resume` を入力するとリストから削除済みのセッションも含む過去セッションのピッカーが開き、選択したセッションをバックグラウンドセッションとして再開可能に
・plan mode でファイル変更を伴う Bash コマンド（例: `touch`、`rm`）がパーミッションプロンプトや SDK `canUseTool` コールバックなしで自動実行されていた問題を修正
・`.claude/worktrees` のリポジトリにコミットされたシンボリックリンクをたどって worktree を作成すると、リポジトリ外にファイルが作成される可能性があった問題を修正
・ツールが失敗または mid-stream で完了したときに `continue:false` フックの停止が無視される問題、およびフックのインフラエラーがユーザー拒否として誤報告される問題を修正
・print/SDK モードで Bash ツール実行中に SIGTERM が発生した際にコマンドのプロセスツリーが孤立する問題を修正。CLI はターンを中断し、ツリーを kill して 143 で終了するよう変更
・Group Policy が PowerShell 5.1 をブロックしている Windows 環境で `/background` と `claude --bg` が "EUNKNOWN: unknown error, uv_spawn" で失敗する問題を修正。daemon が PowerShell 7 を優先するよう変更
・path autocomplete ポップアップが開いている間、シェルモード（`!`）でファイルパスを含むコマンドが実行できない問題を修正
・auto-mode 拒否通知で長い拒否理由が emoji の途中で切れると文字化けする問題を修正
・extended key reporting を持つターミナルの agent view dispatch input で Ctrl+J が改行を挿入できない問題を修正。`?` ヘルプオーバーレイに改行ショートカットを表示するよう改善
・`/ultrareview` が `#123`、`PR 123`、貼り付けた PR URL などの PR 参照を拒否する問題を修正。エラーヒントに実際に入力したコマンド名を表示するよう改善
・`/ultrareview <branch>` でリモートに存在するブランチを origin からフェッチしない問題を修正。タイポ時には最も近いブランチ名を提案するよう変更
・`/clear` 後の新しい会話で `/ultrareview` が請求確認をスキップする問題を修正
・Claude Desktop で `/ultrareview` の "not a git repository" エラーがターミナルコマンドの代わりにプロジェクトのリポジトリフォルダを提案するよう修正
・リポジトリ設定に mTLS 証明書、追加 CA バンドル、OAuth スコープが設定されている場合、ホスト管理セッションが起動時に失敗する問題を修正。これらのトランスポート設定は警告付きで無視されるよう変更
・セッション再開前に offset/limit 付きで読み込まれたファイルを編集する際に "File has not been read yet" エラーが誤表示される問題を修正
・print/SDK モードで `--continue`/`--resume` によるセッション再開後に `ExitWorktree` が "no active EnterWorktree session" で失敗する問題を修正
・セッションの途中で参加した Remote Control クライアントの workflow agent グリッドが空のまま表示される問題を修正
・streaming モードのコントロールリクエストがハンドラー完了前に完了マークされ、セッション再起動時にリクエストが失われる可能性がある問題を修正
・`/fork` で作成したバックグラウンドセッションが状態書き込み失敗後にライブ親保護を失う問題を修正
・agent view で停止済みバックグラウンドセッションを再度開くと無音で失敗する問題を修正。セッションを再開するか、理由を表示して強制再起動を許可するよう変更
・agent team でチームの初期化がセッション内で再実行されたとき、停止中のチームメイトがリーダーに重複したアイドル通知を送る問題を修正
・ファイルパスが長い場合に plan 承認ダイアログのフッターで "ctrl+g to edit in `<editor>`" が分断される問題を修正
・フルスクリーンモードでターミナルの幅と高さを同時にリサイズした後、ウェルカムバナーが古いパネル幅を保持し続ける問題を修正
・狭いレイアウトで差分プレビューの行番号と +/- マーカーが失われる問題を修正
・部分的なファイル読み込み後に @-メンションが何も添付しない問題、プラグインのアンインストールが誤ったマーケットプレイスを対象にする問題、終了コード 143 で "Command timed out" が誤表示される問題を修正
・Azure Monitor など chunked transfer encoding を受け付けないエンドポイントで OpenTelemetry HTTP エクスポートが 411/400 で拒否される問題を修正
・SDK/headless モードで `TRACEPARENT` が設定されている場合、OTLP イベントログレコードに `trace_id`/`span_id` が含まれない問題を修正
・多数の画像を含む会話が誤って "Request too large" エラーで失敗する問題を修正。エラーメッセージを改善して実際の原因を説明するよう変更
・API 過負荷時に web search と web fetch が "API Error" テキストを検索結果やページコンテンツとして返す問題を修正
・web search と web fetch の信頼性向上: 529 エラーと rate-limited リクエストをバックオフ付きでリトライするよう改善
・プロンプトキャッシング改善: mid-conversation system ブロックが LLM ゲートウェイとカスタム base URL（Bedrock、Vertex、1P）でも機能するよう変更
・バックグラウンドエージェントの attach 改善: cold-attach 時にセッションが起動する間、空白の待機画面の代わりにフォーマット済みトランスクリプトを即座に表示するよう変更
・エージェント間メッセージングのトークン使用量を削減: `SendMessage` の本文が再生履歴とツール結果に重複して含まれないよう変更
・`/fork` がセッションにタイトルがない場合、プロンプトに基づいてコピーを命名するよう変更。agent view で識別しやすく
・引数なしの `/btw` が最新のやり取りのサイドクエスチョンパネルを再度開くよう変更。過去の回答を参照可能に
・バックグラウンドエージェントが完了し入力待ちがない場合、`←` フッターヒントが一瞬 `N done` とパルス表示するよう変更
・Task ツールの `mode` パラメーターを非推奨化（無視されるようになった）。サブエージェントはデフォルトで親セッションのパーミッションモードを継承するよう変更
・Enterprise の `forceLoginMethod` が VS Code 拡張機能、SDK、`setup-token`、`install-github-app` ログインにも適用されるよう変更（これまではターミナルのみ）
・セッションのトランスクリプトに各アシスタントメッセージの reasoning effort レベルが記録されるよう変更
・headless/SDK セッションがターン途中で `set_model` コントロールリクエストを適用するよう変更。次のモデルラウンドトリップから新しいモデルを使用（次のターンを待たない）
・agent view / `claude agents --json` で、sandbox、MCP-input、managed-settings プロンプトを待機しているセッションが "Working" の代わりに "Needs input" と表示されるよう変更
・auth ステータスパネルのタイトルを "Cloud authentication" から "Authentication" に更新
・以前のリリースノート（2.1.200）を修正: tmux 3.6 系まで synchronized output は未対応で、対応した新しい tmux が自動検出されるよう修正
