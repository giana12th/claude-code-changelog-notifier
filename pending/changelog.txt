🔧 **Claude Code アップデート**
**v2.1.141**
・`terminalSequence` フィールド: フック JSON出力にデスクトップ通知、ウィンドウタイトル、ベル音を制御ターミナルなしで送信可能に
・`CLAUDE_CODE_PLUGIN_PREFER_HTTPS` 環境変数: GitHubプラグインソースをSSHの代わりにHTTPSでクローン（GitHubSSHキーがない環境向け）
・`ANTHROPIC_WORKSPACE_ID` 環境変数: ワークロードアイデンティティフェデレーション用で、複数ワークスペースをカバーするフェデレーションルール時にトークンを特定ワークスペースに限定
・`claude agents --cwd <path>`: セッションリストを特定ディレクトリにスコープ
・`/feedback` コマンド強化: 最近のセッション（過去24時間または7日間）を含める選択オプション追加
・Rewindメニュー: 「ここまで要約」機能で前の文脈を圧縮しつつ最近のターンを保持
・オートモード許可ダイアログで `permissions.ask` ルールがプロンプトの原因となった場合を説明するよう改善
・ファイル編集許可プロンプトで「IDEで差分表示」オプションを復元（IDE接続時）
・`/bg` または `←←` で起動したバックグラウンドエージェントが現在の許可モードを保持するよう改善
・長い思考期間中のスピナーフィードバック改善: 10秒後にアンバー色に変化してClaudeが動作中を示唆
・プラグインメニュー操作改善: `→`/Tabでタブ切り替え、`↑`でタブストリップへ移動、フルスクリーンモードでタブヘッダーと検索ボックスがクリック可能に
・バックグラウンド副問い合わせがBedrock/Vertex/Foundry/ゲートウェイで利用不可なHaikuモデルIDを送信する問題を修正
・Windows での `claude daemon status` と `/doctor` がパイプキーファイルロック時に不透明な失敗を示す問題を修正
・`/model` でセッション間のオートコンパクト閾値が静かに変更される問題を修正
・許可モード切り替え時にツール許可プロンプトが自動解除されない問題を修正
・許可/ダイアログプロンプト表示中にEnterキーを押すと入力ボックスのテキストも送信される問題を修正
・フック受信の `transcript_path` が存在しないという問題を修正
・vim INSERT/VISUAL モード中の Ctrl+C で実行中ターンが中断されない問題を修正
・代替 `chat:submit` キーバインド（Meta+Enter、Ctrl+Enter など）が機能しない問題を修正
・Web検索ステータスが「0回の検索を実施」と表示される問題を修正
・複数行ステータスライン出力がターミナル幅を超えた行で行をドロップまたは破損させる問題を修正
・Bedrock の `awsCredentialExport` がアンビエント AWS 認証情報解決時にスキップされるのではなく常に実行（クロスアカウントアクセスの認可を修正）
・Remote Control MCPコネクタがワーカーセッショントークン回転時に401で失敗する問題を修正
・Linux で glibc と musl プラットフォームパッケージの両方がインストールされている場合のSDK「Claude Code ネイティブバイナリが見つかりません」エラーを修正
・その他多数のバグ修正
🔗 https://code.claude.com/docs/en/changelog#2-1-141
