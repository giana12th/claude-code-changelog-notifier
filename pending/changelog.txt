🔧 **Claude Code アップデート**
**v2.1.197**
・Claude Sonnet 5 の導入：Claude Code のデフォルトモデルとなり、ネイティブ 1M トークンコンテキストウィンドウと、8月31日までのプロモーション価格 $2/$10/Mtok を提供。バージョン 2.1.197 にアップデートで利用可能。

**v2.1.196**
・組織デフォルトモデルのサポートを追加 — 管理者が組織コンソールで設定し、自分で選択していない場合は `/model` に「Org default」（または「Role default」）として表示
・セッション開始時に読みやすいデフォルト名を追加し、識別やメッセージ送信が容易に
・チャットでクリック可能なファイル添付を追加 — Cmd/Ctrl+クリックで Finder/Explorer にファイルを表示
・セキュリティ：`claude mcp list`/`get` がコミットされた `.claude/settings.json` 経由でリポジトリ自己承認した `.mcp.json` サーバーを起動しなくなった；信頼されていないワークスペースは `⏸ Pending approval` と表示
・バックグラウンドジョブ起動時に、トランスクリプトの誤読により会話が永続的に削除されて元のプロンプトが再実行される問題を修正；ファイルは削除されず退避されるように
・複数の並行リクエストが使用量制限に達したときのレートリミット警告の点滅とテレメトリの二重カウントを修正
・バックグラウンドセッションのターン後に StructuredOutput のスキーマ拒否と再試行が重複してリキャップ行として表示される問題を修正
・PowerShell の `git diff`/`git grep`、`egrep`/`fgrep`、`|` を含む引用符付き検索パターンが exit 1 で失敗として誤報告される問題を修正（Bash の動作に合わせた）
・`claude agents` サイドパネルの複数の問題を修正：エージェントを開いたときのキーボードフォーカスのスタック、バックグラウンドジョブが開くたびにサブエージェントタイプを失う問題、アクティブ実行中のセッションが誤ったステータスを表示する問題
・`claude agents --dangerously-skip-permissions` が auto モードにサイレントフォールバックする代わりに、バイパス免責事項を表示し生成されたエージェントにバイパスモードを適用するように修正
・リモートセッションのミッドターンクラッシュリカバリを修正 — サーバー再起動で中断されたセッションが次のワーカーで自動再開するように
・`/cd` で移動したセッションが、旧パスに特殊文字を含む場合に非正常終了後に旧ディレクトリの再開リストに再表示される問題を修正
・`claude plugin validate` がソースが「.」のローカルプラグインをスキップし、最初のエラークラスで停止する問題を修正
・アイドルプロンプトで Esc Esc を押してもリワインドメニューが開かない問題を修正（リグレッション）；バックグラウンドエージェントの停止には Ctrl+C または Ctrl+X Ctrl+K を使用
・スコープ未指定時に MCP OAuth が認証サーバーの全 `scopes_supported` をリクエストし、GitLab セルフホストなどのエンタープライズ IdP で `invalid_scope` エラーが発生する問題を修正
・Bedrock で `/context` がすべてのツールグループに対して 0 トークンを表示する問題を修正
・`/deep-research` が検証者の失敗を「すべてのクレームが反論された」と誤報する問題を修正（正しくは `unverified`）
・マーケットプレイスが git リポジトリに裏付けられたローカルフォルダパスとして追加された場合、プラグイン依存関係のバージョン固定が適用されない問題を修正
・`claude agents` セッションステータスを修正：完了行が「Done」と「Needs your input」を行き来しなくなり、停止エージェントは「Needs attention」と表示され、PR に言及する結果にはクリック可能なリンクを表示
・音声モード有効時に非常に速いタイピング中に音声ディクテーションがスペースを飲み込み、誤って録音を開始する問題を修正
・バックグラウンドセッションの信頼性を改善：長時間のコマンドとワークフローがセッションプロセスの停止・再起動・更新後も継続するように（Windows を含む）
・バックグラウンドエージェントを改善：デーモン再起動で終了したワーカーが次回エージェントビューを開いた際に中断箇所から自動再開するように
・`/code-review` ワークフローを改善：5 つのクリーンアップファインダーを 1 つに統合し、トークン使用量を約 25% 削減
・ストリーミング中のサブツリー走査をスキップすることでターミナル UI のフレームごとのレンダリング作業を削減
・ストリーミングアイドルウォッチドッグがすべてのプロバイダーでデフォルト有効化 — 5 分間イベントなしでストリームを中断・再試行；無効化は `CLAUDE_ENABLE_STREAM_WATCHDOG=0` を設定
・`ANTHROPIC_BASE_URL` が非 Anthropic ホストを指している場合、`CLAUDE_CODE_USE_BEDROCK`/`_VERTEX`/`_FOUNDRY` の既存動作と合わせて Remote Control を無効化
・フォアグラウンドセッションからエージェントビューを開く操作が `←` 2 回押しから 1 回に変更（バックグラウンドセッションの動作に合わせた）
