🔧 **Claude Code アップデート**
**v2.1.228**
・まれな内部レイアウトエラーの後、プロセスは動き続けているのに描画が完全に停止することがあったインタラクティブセッションを修正
・git インストールフォルダの親フォルダから Claude Code を起動した場合、Windows で `git` / Git Bash が見つからないバグを修正
・前回のレスポンス後に `/model` を変更した場合、`/tui` がセッションを以前のモデルに戻すバグを修正
・インストールまたはアップグレード後の最初のセッションで、クロスセッションメッセージングが受信箱なしで開始することがあったバグを修正
・接続中の Remote Control での `/resume` が、再開した会話のタイトルや履歴を接続セッションに漏洩するバグを修正
・セッションが push しないリポジトリで `checkout` フックが失敗した場合に `claude self-hosted-runner` セッションが毎回失敗するバグを修正（該当リポジトリは警告とともにスキップされるようになった）
・バックグラウンドタスクの完了と次のターン開始の間にセッションが終了してしまう self-hosted runner のバグを修正
・セッションクリーンアップがプロジェクトのメモリフォルダ内のコンテンツを削除するバグを修正
・プラグインの唯一のバージョンがシンボリックリンクされた開発チェックアウトの場合に、バックグラウンドプラグインキャッシュのクリーンアップがキャッシュを削除するバグを修正
・上位優先設定ティアで再定義されたマーケットプレイスエントリが別のティアのカスタムヘッダーを継承する設定マージの問題を修正（マーケットプレイスエントリは完全なエントリとしてマージされるようになった）
・スキル呼び出し後に deferred-tools リマインダーがモデルに二度送信されることがあったバグを修正
・claude.ai から同期されたスキルを強化: ローカルコマンドや MCP プロンプトをシャドウしなくなり、説明はサニタイズ・ラベル付けされ、ローカルマシンでのスキル本文で `!` コマンドの実行や `@` ファイルの展開が行われなくなった
・クロスセッションメッセージを改善: 送信者と本文が折りたたまれた行の代わりにインラインで表示され、他のマシンの Remote Control セッションへのメッセージでは送信者として Remote Control セッション名が表示されるようになった
・Vertex AI クレデンシャル処理を改善: 期限切れまたは欠落している Google Cloud クレデンシャルが数分間再試行する代わりに数秒以内に失敗するようになった
・コンパクション進捗を改善: 再試行カウントダウンと停止ヒントが進捗バーのみの代わりにコンパクション中に表示されるようになった
・一部のターミナルでタブバーのジッターを減らすために、ターミナルタイトルのビジースピナーグリフを更新
・Write ツールを変更: 新しいモデルは今セッションで読み込んでいない既存ファイルを上書きできるようになり Edit ツールのルールに合わせた（古いモデルでは引き続き事前読み込みが必要）
・Pro、Max、Team プランの初回利用通知から、auto モードセッションのコストがわずかに高くなるという古い注記を削除
🔗 https://code.claude.com/docs/en/changelog#2-1-228
