🔧 **Claude Code アップデート**
**v2.1.181**
・プロンプトから任意の設定を変更できる `/config key=value` 構文を追加（例: `/config thinking=false`）— interactive、`-p`、Remote Control で動作
・macOS でサンドボックス化されたコマンドが Apple Events を送信できるようにする opt-in 設定 `sandbox.allowAppleEvents` を追加
・`CLAUDE_CLIENT_PRESENCE_FILE` 環境変数を追加：マーカーファイルを指すことで、マシンの前にいる間はモバイルへのプッシュ通知を抑制できる
・バンドルされている Bun ランタイムを 1.4 にアップグレード
・長い段落のストリーミングを改善：最初の改行を待たずにテキストが1行ずつ表示されるようになった
・自動リトライを改善：thinking中にAPI接続が切断された場合、"Connection closed while thinking" を表示する代わりに自動的にリトライするようになった
・subagentパネルを改善：アイドル状態のsubagentは30秒後に自動的に非表示になり、リストは5行までに制限されスクロールヒントが表示され、フッターにキーボードヒントが表示されるようになった
・MCP OAuth ブラウザページを Claude Code の見た目に合わせて改善し、成功時に自動的に閉じるようになった
・フルスクリーンモードでのURLオープンをネイティブターミナルの挙動に合わせ、Cmd+click（macOS）/ Ctrl+click が必要になるよう変更
・`Improved N memories` という行が、verboseモード以外では個々のファイルを列挙しないように変更
・カスタム `ANTHROPIC_BASE_URL` および Foundry において、リクエストごとのattestationトークンがターン毎に変わることでプロンプトキャッシュが読み込まれない問題を修正
・ネットワークドライブやクラウド同期フォルダで Write/Edit が0バイトまたは truncate されたファイルを生成する問題を修正
・macOSで `open`、`osascript`、ブラウザベースの認証フローがエラー -600 で失敗する問題を、Apple Events entitlement の追加により修正
・起動時のリグレッション（2.1.169で発生、フレッシュな環境で起動ごとに約120ms）を修正：MCPサーバーが設定されていない場合、最初のプロンプトが managed-settings の取得を待たなくなった
・劣化したネットワークでアカウント設定の取得が遅い場合、起動時に最大15秒間ターミナルが空白のままブロックされる問題を修正
・`.claude.json` に壊れたnullのプロジェクトエントリが含まれている場合の起動時クラッシュ（`TypeError: Cannot read properties of null`）を修正
・Spotlightがインデックス再構築中の場合、macOS TUIがセッション開始時にフリーズする（Ctrl+Cが反応しない）問題を修正
・別のClaude Codeプロセスが30日分のtranscriptクリーンアップを実行した場合、長時間アイドル状態のセッションが履歴を失う問題を修正
・foreground subagentが無制限にネストしたチェーンを生成していた問題を修正。background subagentと同じ5階層の深さ制限が適用されるようになった
・モデル切り替え直後に `/recap` と会話のforkが以前のモデルを使用してしまう問題を修正
・subagentの "Thinking" 時間が、subagent自身ではなく親エージェントの経過時間を表示していた問題を修正
・ネストしたエージェントでブロックされているsubagentが、agentパネルで "waiting" ではなく経過時間が動き続ける表示になっていた問題を修正
・APIリトライインジケーター（"Retrying in 0s · attempt N/10"）がリトライ成功後も画面に残り続ける問題を修正
・残り有効期限が短いAWSの `awsCredentialExport` クレデンシャルにより、1分ごとにクレデンシャルの再取得が発生していた問題を修正。また `aws configure export-credentials` のJSON形式を受け付けるようになった
・tools/listが失敗した場合に `claude mcp get`/`list` が `✓ Connected` と表示していた問題を修正。エラー詳細とともに `! Connected · tools fetch failed` と表示するようになった
・`/remote-control` が古い "connecting…" の表示を残してしまう問題を修正。接続完了後にtranscript内で確認が表示されるようになった
・bareの `git` がWindows上で解決できない場合、ExitWorktreeがクリーンなworktreeの削除を "Could not verify worktree state" で拒否する問題を修正
・`~/.claude/settings.json` がシンボリックリンクされた `~/.claude` 配下の相対シンボリックリンクである場合、設定変更（`/effort` や `/model` など）が ENOENT で失敗する問題を修正
・コンテキストリマインダー内のIDE選択行番号が1行ずれていた問題を修正（IntelliJ と VS Code）
・ネイティブターミナルでの選択（modifier+drag）後にフルスクリーンでCtrl+Cを行うと、クリップボードがアプリの以前の選択内容で上書きされる問題を修正
・クリップボードにテキストが含まれている場合にCtrl+Vが "No image found in clipboard" と表示してペーストできない問題を修正
・agentsディレクトリが既に存在する場合、エージェント作成が "EEXIST: file already exists" で失敗する問題を修正（Windows/OneDrive）
・AskUserQuestionのプレビュー内容が、word-wrapされずにダイアログの端で切れてしまう問題を修正
・AskUserQuestionの複数選択の質問で、送信時に入力した "Other" のフリーテキスト回答が黙って失われる問題を修正
・UTCより遅れたタイムゾーンで `/stats` の "Most active day" と日別トークンチャートの日付が1日早く表示される問題を修正
・Linuxで、Claude Code起動後にインストールされたクリップボードユーティリティを `/copy` とcopy-on-selectが検出しない問題を修正
・タブインデントのコードが、Write（ファイル作成）プレビューで不正なインデントで表示される問題を修正
・ターン中にキューされたユーザープロンプトが、transcript内で全幅の背景ハイライトとして表示されない問題を修正
・Ghosttyでアクティビティスピナーのパルスが間違ったグリフサイズに留まる問題を修正
