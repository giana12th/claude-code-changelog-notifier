🔧 **Claude Code アップデート**
**v2.1.202**
・`/config` に「Dynamic workflow size」設定を追加。動的ワークフローの規模（エージェント数: small/medium/large）を制御できる
・ワークフローが起動したエージェントのテレメトリに `workflow.run_id` と `workflow.name` OpenTelemetry 属性を追加
・スキャン中に確定またはキャンセルした際のインライン Ctrl+R 履歴検索クラッシュを修正
・ジョブ再起動時にバックグラウンドセッションの `/rename` が元に戻る問題を修正
・クライアント証明書のインプレースローテーション中に設定が再適用された際の一時的な mTLS ハンドシェイク失敗を修正
・Remote Control（モバイル/ウェブ）からインタラクティブセッションに送信されたコマンドが「Unknown command」で失敗する問題を修正
・Remote Control モバイル/ウェブアプリからキャプションなしで送信された画像・ファイルが無言で無視される問題を修正
・SSH 経由で `claude auth login` および `claude mcp login --no-browser` が出力するサインイン URL がクリックできない場合がある問題を修正
・`claude agents` からチャットを開く際に「currently running as a background agent」で失敗することがある問題を修正
・文字列に Unicode クォートエスケープを含むワークフロースクリプトがパース前に破損する問題を修正
・マイク失敗時に音声入力が無限ループでリトライし続ける問題を修正。連続キャプチャ失敗時は音声入力を一時停止するよう変更
・`/remote-control` セッションがモバイル/ウェブアプリで誤ったパーミッションモードを表示する問題を修正
・大規模な git worktree 環境で、名前によるセッション再開や再開ピッカーの表示に数分かかる問題を修正
・ダウンロード中の接続切断時にインストーラー/アップデーターのダウンロードが即座に「aborted」で失敗する問題を修正
・既に読み込み済みのスキルを再度呼び出した際にコンテキストに重複した指示が追加される問題を修正
・`/workflows` エージェントリストのレイアウトを改善: タイトル幅拡大、専用の時間カラム追加、モデル名を短縮
・サーバー設定問題に関する MCP エラーメッセージを改善
・`/review <pr>` を高速シングルパスレビューに戻した。マルチエージェントレビューは `/code-review <level> <pr#>` を使用
🔗 https://code.claude.com/docs/en/changelog#2-1-202
