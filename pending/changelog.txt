🔧 **Claude Code アップデート**
**v2.1.186**
・インタラクティブな `/mcp` メニューを開かずにCLIからMCPサーバーを認証できる `claude mcp login <name>` と `claude mcp logout <name>` を追加。SSH経由で完了させるための `--no-browser` stdinリダイレクトサポートも追加
・`/workflows` のエージェント詳細ビューにステータスフィルタリング（`f`キーで実行）を追加
・`/plugin` のInstalledタブに「Skills」セクションを追加
・`teammateMode: "iterm2"` 設定を追加。autoモードが `it2` CLIを見つけられない場合は警告を表示
・`awsAuthRefresh` が設定されている場合、`/login` に「Claude Platform on AWS - refresh credentials」オプションを追加
・`!` によるbashコマンドの実行後、Claudeが出力に対して自動的に応答するようになった。以前のコンテキストのみの動作を維持するには、settings.jsonで `"respondToBashCommands": false` を設定する
・マシンがスリープから復帰した後、ストリーミングリクエストが「Content block not found」やJSONパースエラーで失敗する不具合を修正
・サブエージェントのトランスクリプトのスクロール位置が、終了時にメインのトランスクリプトに引き継がれてしまう不具合を修正
・エージェントのプランがロードされる前に、バックグラウンドタスクのプレビューに生のツール名が一瞬表示されてしまう不具合を修正
・同時実行のCLIセッションでプロダクト内の権限ゲートがオフの場合、Chromeのタブグループ分離が適用されない不具合を修正
・バックグラウンドセッションのrecapが重複表示される不具合を修正。エージェント自身のターン終了時のサマリーがrecap行として表示されるようになった
・`claude agents` からバックグラウンドセッションを開いた際、前の画面が背後に描画されたまま残る不具合を修正
・名前付きサブエージェントの起動に対して `Agent(type)` の拒否ルールと `Agent(x,y)` の許可タイプ制限が適用されない不具合を修正
・メインターン終了後もバックグラウンドエージェントが実行中の間、EscとCtrl+Cが反応しない不具合を修正
・オプションのテキストがオーバーフローした場合、権限プロンプトのオプション番号がずれる不具合を修正
・エージェントパネルで完了済みのサブエージェントに対して `x` を押しても消えない不具合を修正
・古いセッションを再開した際、意図的に廃止されたツールに対して誤解を招く「MCP server disconnected」通知が表示される不具合を修正
・すでに最上部までスクロールしている場合に `/plugin` のInstalledが「more above」インジケーターを表示する不具合を修正
・アシスタントのメッセージで `~~strikethrough~~` が取り消し線としてレンダリングされず、チルダがそのまま表示される不具合を修正
・コールドな初回起動時、フラグがロードされる前に `--tools` がフィーチャーゲートされたツールを通過させてしまう不具合を修正
・`claude agents` で返信した後もバックグラウンドジョブのステータスに古い「needs input」メッセージが表示される不具合を修正
・ライトテーマのターミナルで `claude agents` からバックグラウンドセッションを開いた際にダークテーマが一瞬表示される不具合を修正
・`claude agents` でマウス選択したテキストを削除した後もハイライトが残る不具合を修正
・usageベースのEnterpriseおよびTeamサブスクライバーでセッションコストが表示されない不具合を修正
・agent teamsを修正：tmux/paneバックエンド経由で起動されたチームメイトが、リーダーの `--effort` レベルを継承するようになった
・Workflowの `agent({schema})` サブエージェントが、スキーマ検証の失敗を繰り返した際に5回試行後に中断せず無限ループしてしまう不具合を修正
・`claude mcp get` と `claude mcp remove` を改善：タイプミス時に設定済みの最も近いサーバー名を提案し、長いサーバーリストを省略表示するように
・メモリ機能を改善：サイズ制限に近づくと、エージェントが `MEMORY.md` のインデックスを圧縮するよう促されるようになった
・skillのfrontmatterを改善：`display-name`、`default-enabled`、`fallback`、`metadata.*` キーがkebab-case、snake_case、camelCaseに対応するようになった
・不正な形式の `SKILL.md` のYAML frontmatterの処理を改善：サイレントに失敗する代わりに、空のmetadataでskillの本文をロードするようになった
・`CLAUDE_CODE_MAX_RETRIES` の上限を15に変更。無人セッションでは代わりに `CLAUDE_CODE_RETRY_WATCHDOG` を使用する
・バックグラウンドのサブエージェントが、自動拒否する代わりにメインセッションで権限プロンプトを表示するように変更。ダイアログにはどのエージェントが要求しているかが表示され、Escはそのツールのみを拒否する
・`/review <pr>` を `/code-review medium` と同じレビューエンジンを使用するように変更
🔗 https://code.claude.com/docs/en/changelog#2-1-186
