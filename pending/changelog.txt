🔧 **Claude Code アップデート**
**v2.1.170**
・Claude Fable 5 の導入：Mythos クラスのモデルで、一般利用向けに安全化。これまでに一般公開されたモデルの中で最高の能力を備えています。v2.1.170 へのアップデートでアクセス可能です。
・セッション保存の修正：VS Code 統合ターミナルまたは Claude Code 環境変数を継承したシェルから起動した場合、セッションがトランスクリプトを保存せず `--resume` に表示されない問題を修正しました。

**v2.1.169**
・`--safe-mode` フラグ（`CLAUDE_CODE_SAFE_MODE` 環境変数）の追加：すべてのカスタマイズ（CLAUDE.md、プラグイン、スキル、フック、MCP サーバー）を無効にしてトラブルシューティング用に起動できます。
・`/cd` コマンドの追加：セッション中のプロンプト キャッシュを壊さずに、セッションを新しい作業ディレクトリに移動できます。
・`disableBundledSkills` 設定と `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` 環境変数の追加：バンドルされたスキル、ワークフロー、組み込みスラッシュ コマンドをモデルから非表示にします。
・キーボード操作の改善：上下矢印キーが長い入力の折り返し行をジャンプするのではなく、各行を移動するように改善しました。
・エンタープライズ MCP ポリシーの修正：再接続時・IDE 型設定・`--mcp-config` サーバー・初回インストール後・リモート設定読み込み前に `allowedMcpServers`/`deniedMcpServers` が確実に適用されるようになりました。
・macOS パフォーマンス改善：Claude.ai 認証情報でログインしている macOS ユーザーの各ターン開始時の UI スタッシュ（約 30～50ms）を修正しました。
・Windows パフォーマンス改善：`claude -p` が Windows でスラッシュ コマンド/スキル スキャン中に遅い、またはハングする問題を修正しました（v2.1.161 でのリグレッション）。
・リモート コントロール修正：OAuth トークン更新と同時にセッションを再開した後、「再接続中」でスタックする問題を修正しました。
・Git Credential Manager ポップアップの修正：Windows スタートアップ時にキャッシュされていない認証情報で背景 git コマンドが実行される際に「GitHub に接続」ポップアップが表示される問題を修正しました。
・UI フッター ヒント修正：カスタム statusline を使用するユーザーに対してフッター ヒント（例：「esc で中断」）が表示されない問題を修正しました。
・リモート セッション権限プロンプト修正：再接続のたびに古い/重複したプロンプトが再表示される問題を修正しました。
・`claude agents --json` の改善：ブロック済みと新規ディスパッチされたバックグラウンド セッションが省略されていた問題を修正。`--all` フラグと新しい `id`・`state` フィールドを追加しました。
・エージェント ビュー修正：WSL で Windows Terminal からエージェント ビューをナビゲートして戻る際に古い/文字化けしたフレームが表示される問題を修正しました。
・バックグラウンド セッション設定修正：プリウォーム ワーカーにディスパッチされる際にプロジェクト レベルの設定 `env` 値（例：`ANTHROPIC_MODEL`）が無視される問題を修正しました。
・プラグイン キャッシュ修正：Windows で MCPB プラグイン キャッシュが誤って無効化され、不要な再抽出が発生していた問題を修正しました。
・`.in_use` PID ロック ファイル修正：無限に蓄積される問題を修正。クラッシュしたセッションからの古いマーカーは 1 日 1 回スイープされます。
・信頼されていないプロジェクト設定の修正：信頼確認なしに OTEL クライアント証明書パスを設定できていた問題を修正しました。
・`/workflows` コマンド：ターン実行中でも即座に開くようになりました。
・TaskCreate 信頼性向上：不正な入力は自動的に修復され、アンロードされたツールの検証エラーにはスキーマが含まれます。
・API キー認証エラー メッセージの改善：組織が API キー認証を無効にしている場合、アクティブ API キーの場所に基づいてガイダンスが表示されます。
・CPU 使用率削減：レスポンス ストリーミング中およびスピナー アニメーション中の CPU 使用率が低下しました。
・Vertex/Foundry アイドル タイムアウトの修正：デフォルトの 5 分間のアイドル タイムアウトが復元されました。`API_FORCE_IDLE_TIMEOUT=0` で無効にできます。
・リモート管理設定の改善：無効なエントリがあっても有効なポリシーを適用し、検証エラーを表示するようになりました。
・バックグラウンド セッション フラグ保持の改善：`--ide`、`--chrome`、`--bare`、`--remote-control` などのフラグが retire→wake 全体で保持されるようになりました。
・共有チェックアウト編集ブロック通知：バックグラウンド セッションは、ワークツリーに入るまで共有チェックアウト編集がブロックされていることが通知されるようになりました。
・CLAUDE.md 警告閾値：「CLAUDE.md が長すぎる」警告の閾値がモデルのコンテキスト ウィンドウに応じてスケーリングされます。
・Windows 自動更新機能：`claude.exe` が別プロセスによって保持されている場合、セッション内での再試行を停止します。
・スキル タグの色コントラスト改善：スラッシュ コマンド メニューでのスキル タグの色コントラストが改善されました。
・プロモ クレジット請求メッセージの改善：Apple/Google 課金のサブスクライバーで支払い方法がない場合、どこに追加するかが説明されるようになりました。
・複数同時セッション実行時のヒント追加：複数の同時セッションを実行する際に `claude agents` を実行するよう提案するヒントが追加されました。
