🔧 **Claude Code アップデート**
**v2.1.145**
・`claude agents --json` を追加。tmux-resurrect、ステータスバー、セッションピッカー向けにライブのClaudeセッションをJSONとして一覧表示できる
・`claude_code.tool` OTELスパンに `agent_id` と `parent_agent_id` 属性を追加し、バックグラウンドサブエージェントのスパンが Agent ツールスパン配下にネストされるようトレースの親子関係を修正
・ステータスラインのJSON入力に、GitHubリポジトリとPR情報（検出された場合）が含まれるようになった
・`/plugin` の Discover・Browse 画面でインストール前にプラグインのコマンド、エージェント、スキル、フック、MCP/LSPサーバーが確認できるようになった
・`claude agents` のターミナルタブタイトルに入力待ち件数が表示され、別タブのウィンドウでもエージェントの注意が必要なタイミングがわかるようになった
・フルスクリーンモードでスラッシュコマンドと@メンションのサジェストリストがマウスホバー・クリックに対応した
・Stop と SubagentStop フックの入力に `background_tasks` と `session_crons` フィールドを追加
・Bashコマンドで許可リスト未登録の環境変数へのベア変数代入が自動承認されていた権限プロンプトのバイパスを修正
・MCPプロンプトスラッシュコマンドで必須引数が省略された際に生のサーバーバリデーションエラーが表示されていた問題を修正（不足引数名と期待される使い方を表示するよう改善）
・ターミナルのリサイズ・再フォーカス後にスピナーと経過時間の表示がキーを押すまでフリーズする問題を修正
・デフォルトの Windows PowerShell 5.1 でクロスプロジェクト再開ヒントが失敗する問題を修正（Windowsのコマンド区切りに `;` を使用するよう変更）
・エージェントビューの返信ペインで音声プッシュトゥトークが機能しない問題を修正
・複数タスクを一度に作成するとタスクリストがランダムな順序でレンダリングされる問題を修正
・マーケットプレイス既インストール済み状態で「Anthropicマーケットプレイスのインストールに失敗」バナーが古いまま残る問題を修正
・`gh pr create` などPR状態変更コマンドの実行直後にフッターのPRバッジが即座に更新されない問題を修正
・Agent Teams でASCII以外の名前を持つチームメイトが無効なヘッダーエンコーディングにより全APIコールに失敗する問題を修正
・`/review` がClassic Projectsを持つリポジトリでエラーになる廃止済みの `projectCards` GraphQLクエリを使用していた問題を修正
・`claude plugin validate` で `skills:` エントリがディレクトリではなくファイルを指している場合にフラグが立たなかった問題を修正（エラーメッセージで親ディレクトリを提案するよう改善）
・`context: fork` を使うスキルが自分自身を繰り返し再起動する無限ループを修正
・Read ツールがファイル全体の読み取りがトークン制限を超えた場合にハードエラーではなく「PARTIAL view」通知付きで最初のページを切り詰めて返すよう改善
