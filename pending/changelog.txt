🔧 **Claude Code アップデート**
**v2.1.154**
・Opus 4.8 が登場！最も難しいタスクには `/effort xhigh` で高エフォートがデフォルトに
・ダイナミックワークフローを導入：Claudeにワークフローの作成を依頼すると、バックグラウンドで数十〜数百のエージェントにわたる作業をオーケストレーション。`/workflows` で実行状況を確認可能
・Opus 4.8 の Fast mode が従来の一部コストで利用可能に：標準レートの2倍で2.5倍の速度
・Haiku、Sonnet、Opus 4.7以前を除くすべてのモデルでリーンシステムプロンプトがデフォルトに
・Claudeは、すでに判断に十分なコンテキストがある場合は多肢選択質問を使用せず、本当に自力で決定できない場合のみ使用するよう改善
・`/simplify` がクリーンアップのみのレビュー（再利用、シンプル化、効率化、altitude改善）を実行して修正を適用するようになり、`/code-review --fix` の全バグ検出レビューを実行しなくなった
・`/effort` スライダーのラベルを "Speed"/"Intelligence" から "Faster"/"Smarter" に変更して明確化
・`claude agents`：`! <command>` でシェルコマンドをアタッチ/デタッチ可能なバックグラウンドセッションとして実行。`claude --bg --exec '<command>'` としても利用可能
・`claude agents`：`/logout` がバックグラウンドセッションに送られず正しくサインアウトするように
・`←←` でエージェントビューを開く操作がBedrock・Vertex・Foundry・テレメトリ無効環境でも機能するように
・Claude in Chrome：`/chrome` → "Select browser…" または複数ブラウザ接続時のブラウザアクション実行中にチャット内で使用ブラウザを選択可能に
・プラグインが `plugin.json` またはマーケットプレイスエントリで `defaultEnabled: false` を宣言可能に。`/plugin` または `claude plugin enable` で有効化
・`/plugin` の Discover タブで現在のディレクトリに関連するプラグインを "suggested for this directory" として固定表示
・ストリーミングツール実行がテレメトリ無効時やBedrock/Vertex/Foundryでも常に有効に（以前はfeature flagで制御）
・Stdio MCPサーバーのサブプロセスが `CLAUDE_CODE_SESSION_ID` と `CLAUDECODE=1` を環境変数として受け取るように
・`claude mcp list`/`get` で未承認の `.mcp.json` サーバーが自動承認・接続せず `⏸ Pending approval` として表示されるように（出力パイプ時）
・`/remote-control` のオートコンプリートがRemote Control有効時に "Disconnect Remote Control" を表示するように
・`/claude-api` スキルにClaude Opus 4.8サポートと4.7→4.8移行ガイダンスを追加
・`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` を非推奨化（06/01に削除予定）。Opus 4.6でfast modeを使用する場合は `/model claude-opus-4-6[1m]` で切り替え後 `/fast on`
・auto modeの分類器によるデータ窃取検出精度を向上、特にリポジトリコンテンツの一括転送に対して
・`HOME` にトレーリングスラッシュがある場合に `rm -rf $HOME` が危険なパスとしてブロックされない問題を修正
・同一セッション内のサンドボックス化/非サンドボックス化のBashコマンド間で `$TMPDIR` が異なるディレクトリに解決される問題を修正
・`claude agents` でClaude Codeテーマがターミナル背景と一致しない場合のハイライト行テキストが読めない問題を修正
・バックグラウンドエージェント完了通知が一部の1Mコンテキストモデルで早期の "out of context" 動作を引き起こす問題を修正
・スケジュールされた `/command` 発火時にバックグラウンドセッション分類器がユーザーの目標を失う問題を修正
・Claude Code更新後にピン留めされたバックグラウンドセッションが毎分再スポーンして繰り返しエージェント開始通知とアイドル時のプロセス増加が発生する問題を修正
・アイドルグレース期間後も "blocked"・"running"・"working" 状態のバックグラウンドセッションが終了しない問題を修正
・バックグラウンドセッションのサブエージェントがworktreeアイソレーションガードをバイパスして共有チェックアウトに書き込む問題を修正
・デーモン終了後にmacOSで孤立した `claude --bg-pty-host` プロセスがCPU 100%で動き続ける問題を修正
・オプションダイアログの区切り線より下のオプションで数字キーショートカットが機能しない問題を修正
・リンクされたworktree内からサブエージェントをスポーンまたは `EnterWorktree` を呼び出す際に `worktree.baseRef: "head"` がメインチェックアウトのHEADに解決される問題を修正
・前の行がターミナル幅ちょうどで終わった場合に折り返し行の先頭に余分なスペースが入る問題を修正
・VS Codeで思考スピナーの色数を制限することで断続的なターミナルレンダリング破損を修正
・プランモードのプロンプトが貼り付けた画像やテキストで始まる場合にプランファイル名に `[Image #N]`/`[Pasted text #N]` プレースホルダーが含まれる問題を修正
・画面内に収まる短いANSIカラー行に不要な "ctrl+o to expand" ヒントが表示される問題を修正
・管理設定で無効な `allowedMcpServers`/`deniedMcpServers` エントリが1件あると管理設定ポリシー全体が破棄される問題を修正（不正エントリは削除され `claude doctor` で警告）
・`CLAUDE_CODE_ALWAYS_ENABLE_EFFORT` 設定時にeffortパラメータ非サポートモデルでAPI 400エラーが発生する問題を修正
・Windows：使用中の `claude.exe` による更新失敗で汎用エラーが表示される問題を修正（他のセッションを閉じて再試行するよう案内するように）
・ショートカットヘルプパネルから古い "& for background" ヒントを削除
・[VSCode] Auto modeがモードピッカーに表示されるためにbypass-permissions設定が不要になり、初めてアクティブ時に新規セッション画面に解説通知を表示
・ワークフローのみ実行中にプロンプト下のタスクパネルに選択不可能な "main" 行が表示される問題を修正
・MCPサーバーのツール名や説明が長い/複数行の場合の `/mcp` ツールリストとツール詳細表示の問題を修正
・fast modeがオンのAPI（従量課金）ユーザーに `/model` ピッカーのDefaultオプションでfast modeの価格が表示されない問題を修正
・安全分類器が推論中に出力トークンを使い切った場合にauto modeが誤って "could not evaluate this action" でアクションをブロックする問題を修正

**v2.1.153**
・`github`/`git` プラグインのマーケットプレイスソースにGit LFSダウンロードをスキップする `skipLfs` オプションを追加
・npm グローバルインストールが自動更新できない場合に一度限りの通知を表示するように。`/doctor` で修正方法を確認可能
・ステータスラインコマンドが `COLUMNS` と `LINES` 環境変数を受け取り、スクリプトがターミナル幅に合わせて出力サイズを調整できるように
・`claude agents`：ディスパッチ入力のオートコンプリートがプロジェクトスキルだけでなくネイティブスラッシュコマンドとバンドルスキルも提案するように
・`claude agents`：PRカラムで単一PRは `PR #N`、複数PRは `N PRs` を表示するように
・`claude doctor` が最後の更新試行の結果を表示するように
・MCPサーバーとコネクタの "認証が必要" 起動通知を1つのメッセージに統合
・macOS：バックグラウンドエージェントがPrivacy & Securityに "Claude Code" として表示され、アップグレード後もパーミッション設定が維持されるように
・オプションのGET SSEストリームがないステートフルMCPサーバーが `tools/list` で再接続ループになる問題を修正（v2.1.147で発生したリグレッション）
・カスタムAPIゲートウェイがゲートウェイ独自のトークンの代わりにユーザーのAnthropic OAuthクレデンシャルを受け取るリグレッションを修正
・サブエージェント（Agentツール）のフロントマターMCPサーバーが `--strict-mcp-config`・`--bare`・リモートモード・エンタープライズ管理MCP設定・管理設定のMCPサーバー許可/拒否ポリシーを無視する問題を修正
・`--strict-mcp-config` が明示的に渡されたエージェント定義（`--agents` / SDK `agents`）のインライン `mcpServers` を削除しなくなり、ブロックされたサブエージェントMCPサーバーが可視化された警告を表示するように
・WindowsのPowerShellインストーラーがインストール失敗時に "Installation complete!" と報告する問題を修正
・`claude update` がnpmインストールで設定されたリリースチャンネルのバージョンではなく最新版をインストールする問題を修正
・多数のセッションが保存されているマシンでトランスクリプトファイルパスによるセッション再開時の過剰なメモリ使用（複数GB）を修正
・アップグレード後も `claude agents` と `claude --bg` がバイナリテイクオーバーサポート前に起動された古いデーモン上で動作する問題を修正
・stream-jsonモードでstdinがEOFなしに閉じられた場合にCLIが終了できず古いセッションマーカーが残る問題を修正
・Claudeのレスポンス内の不正な `file://` リンクがターミナルでクリックできない問題を修正
・ターミナル幅が92カラムより狭い場合に `claude --help` が折り返しなしで表示される問題を修正
・MCPツールの進捗通知が折りたたまれたツールビューで表示されない問題を修正
・`Agent` ツールで `subagent_type: 'claude'` を指定した場合に一時的なworktreeで実行され、gitignoreパスへの出力が無視される問題を修正
・`/bg` でClaude応答中にバックグラウンドセッションで応答を継続するように（以前は応答が失われていた）
・バックグラウンドセッションでタスク実行中に `/btw` キーボードショートカットが反応しなくなる問題を修正
・バックグラウンドセッションが `$CLAUDE_JOB_DIR` に一時ファイルを書き込む際に "sensitive file" パーミッションプロンプトが表示される問題を修正
・作業ディレクトリが削除されたバックグラウンドエージェントの回復時にスタックトレースが切り取られた形で表示される問題を修正
・バックグラウンドセッションで `EnterWorktree` が即座に利用できない問題を修正（以前は先に `ToolSearch` が必要）
・iTerm2/Terminal.appで `cmd+k` がアタッチされたバックグラウンドセッションを再描画しない問題を修正
・WindowsのアタッチされたバックグラウンドセッションでIME候補ウィンドウが入力カーソルの隣ではなく画面下部に表示される問題を修正
・256色のみのターミナルからバックグラウンドエージェントにアタッチした後でファイルdiffをレンダリングした際に背景色がブリードする問題を修正
・tmux内のバックグラウンドセッションにアタッチ中に `/copy` とコピーオンセレクトがシステムクリップボードの更新に無音で失敗する問題を修正
・Remote Control有効時に `claude agents` を開くとCodeタブに終了後もゾンビセッションエントリが残る問題を修正
・バックグラウンドセッションで `/rename` がセッションバナーを即座に更新しない問題を修正
・Windows更新ロールバック修正：更新失敗時にClaude Codeが元の実行ファイルをコピーして復元し、回復方法を案内するように
・[VSCode] VS Code終了時にWindowsでClaude Codeプロセスが正常にシャットダウンされず "unclean exit" の誤報告と孤立したMCPサーバーが発生する問題を修正
・`/model` が選択内容を新しいセッションのデフォルトとして保存するように（IDEと一致）。ピッカーで `s` を押すと現在のセッションのみ切り替え
・`modelPicker:setAsDefault` キーバインディングをカスタマイズした場合はkeybindings.jsonで `modelPicker:thisSessionOnly` にリネームが必要（`d` アクションが `s` に変更された）
