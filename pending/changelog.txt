🔧 **Claude Code アップデート**
**v2.1.268**
・Claude apps ゲートウェイ: `gateway.yaml` に `pricing:` を設定すると、署名済み Claude Code クライアントがマネージド設定で同じ料金を受け取り、`/cost` やテレメトリが支出メーターと一致するように
・ゲートウェイで `access_control.allow_cidrs` が空の場合の起動時警告と、パブリックアドレスからの初回リクエスト時の一回限り警告を追加
・`gatewayInternalNetworks` マネージド設定を追加。管理者が組織のパブリック IPv4 ブロック上の Claude apps ゲートウェイへの `/login` を許可できるように
・`claude self-hosted-runner --remove-session-state`（デフォルト無効）を追加: セッション終了時に `<base-dir>/_sessions/` 以下のセッション別ディレクトリを削除
・`claude auth status --json` の出力に `configDirectory` を追加
・`claude plugin install`/`uninstall`/`update`/`enable`/`disable` に `--json` を追加、`claude plugin list --json` の各行に `errorDetails`/`noteDetails` を追加
・公開 Artifact のブラウザタブアイコンを追加（Claude がページに合わせて選択）
・2.1.265 以降、サードパーティ Anthropic 互換エンドポイント（`ANTHROPIC_BASE_URL`）で全ターンが HTTP 400 で失敗する問題を修正: Artifact ツールの入力スキーマ内の正規表現が原因
・WebFetch がレスポンスを閉じないサーバーで無限ハングする問題を修正。300秒後に失敗するように（`CLAUDE_CODE_WEBFETCH_DEADLINE_MS` で変更可能、0で無効化）
・信頼していないフォルダの同名エージェントファイルから、再起動したインプロセスのチームメートがツールやシステムプロンプトを引き継ぐ問題を修正
・長時間アイドルセッションでのビジーループによる継続的な高 CPU 使用率を修正（アイドル中にコアが張り付く問題とセッションリキャップ中の急速なフォーカス報告が原因）
・MCP ツール呼び出し後に Claude が「メッセージが空で届いた」と応答することがある問題を修正
・シンボリックリンクされたディレクトリ（macOS の `/etc`/`/tmp`/`/var`、Linux の `/bin`）での deny/ask 権限ルールが実際のパスで指定された場合に適用されない問題、および Bash コマンドがシンボリックリンクパスのスペルで書かれた deny ルールを無視する問題を修正
・`env -C`/`eval` などの解析不可コマンドが同一行にある場合に Read/Edit の deny ルールが適用されないケースを修正
・プラグインとマーケットプレイスのエラーが git ソース URL のトークンやパスワードを表示する問題を修正
・`/mcp`/`/plugin` サーバー詳細、`claude mcp list`/`get`、MCP ログインエラーが MCP 設定の `${VAR}` から解決したシークレットを表示する問題を修正
・`excludeDynamicSections` を使用した SDK セッションで、プロンプトキャッシングと extended thinking がセッション途中で壊れる問題を修正（最初のメッセージがリクエスト毎に再レンダリングされていた）
・キャッシュされたモデルアクセス拒否が古い場合に、再起動後または Desktop Code タブで利用権ユーザーがモデル制限メッセージを受け取る問題を修正
・別の Claude Code プロセスが古いモデルアクセスエントリを更新した際、実行中セッションが組織のデフォルトモデルにサイレント切り替えされる問題を修正
・Fable モデルで長コンテキスト 429 が Pro/Team プランで使用クレジット同意プロンプトを表示する問題を修正（正しくは 1M コンテキストメッセージ）
・プロファイル経由のワークロードアイデンティティフェデレーション（claude-code-action が使用）で `401 … jti reused` エラーが発生する問題を修正
・MCP サーバー OAuth サインインがローカルコールバックポート範囲をバインドできない場合に "No available ports for OAuth redirect" で失敗する問題を修正
・`/compact` と自動コンパクトで生成される会話サマリーが `$` シーケンスを含むテキストを破損する問題を修正
・`/compact` で終了した会話を再開すると、復元されたファイルノートの順序が毎回異なる問題を修正
・SDK プロンプト候補、サイドクエスチョン、`/rename` がコンパクション前の会話を送信する問題を修正
・上矢印で以前のプロンプトを呼び出して編集した後、`@` ファイルや `/` コマンドの候補が表示されない問題を修正
・`claude agents` で ← を自然なペースで押してエージェントリストに戻ろうとすると、1秒以上待たないと無視される問題を修正
・`claude agents` のセッション削除でワークツリーを削除できない場合にスタックする問題を修正（原因と次のステップを表示し、git ワークツリーなら ctrl+x で強制削除可能に）
・agents パネルでバックグラウンドエージェントとワークフロー行にテキストの改行が含まれると複数行に展開される問題を修正
・Claude in Slack が org マネージド設定で MCP 許可リストを設定すると Slack ツールを失う問題を修正
・Claude in Chrome がナビゲーション URL でスキームは有効だがホストが解析できない場合に "https" ホストの許可を求める問題を修正
・現在のタスクラベルが長い場合にスピナーが複数行に折り返される問題を修正（ラベルと "Next:" タスク行が1ターミナル行内に収まるように）
・ネイティブカーソル有効時に `/bug`/`/feedback` の説明フィールドにカーソルが表示されない問題を修正
・`claude remote-control` が提供する Remote Control セッションが `ListAgents` でセッションタイトルの代わりに生成名を表示する問題を修正
・`claude plugin validate` がプラグインローダーは受け入れるにもかかわらず、ディレクトリ名が2つのドットで始まるプラグインパスを拒否する問題を修正
・プラグインがチェックできないデフォルトモニターファイルやルート SKILL.md をサイレントスキップする問題を修正
・WebFetch の localhost やドットなしホスト名のエラーメッセージを改善（拒否理由と curl の代替手段を説明）
・`--print` モードで PermissionRequest フックが起動しない問題を修正
・ヘッドレス（`-p`）実行でポリシーヘルパー警告が出力されない問題を修正
・`/resume` が `/fork` バックグラウンドセッションを固有の `⑂` フォーク名ではなく親の名前でリストする問題を修正
・`/remote-control` などの claude.ai ゲートコマンドがサインアウト時に Claude for Enterprise マイグレーションメッセージを表示する代わりに `/login` を提案するように修正
・`CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS` が per-hook の `timeout` を持たない SessionEnd フックを延長しない問題を修正（1.5秒後にキャンセルされていた）
・`/autofix-pr` などのクラウドセッションコマンドが GitHub アカウント未接続時に `/web-setup` またはウェブ接続ページを案内するように修正（再試行や GitHub App インストールを促す誤ったメッセージを修正）
・`/teleport` などのクラウドセッションコマンドが組織ポリシーで無効化されている場合に "Unknown command" ではなく説明を表示するように修正
・Bash サンドボックス指示の過剰な制限記述を修正（ファイルシステム分離が無効な場合の非強制パスリストの削除、strict モードが「コマンドが絶対にサンドボックス外で実行されない」と主張しないように）
・フルスクリーンモードの改善: プロンプト行の追加・削除が文字入力と同速度で再描画（トランスクリプト全体の再レンダリングなし）
・`--continue` / `--resume` の改善: SessionStart フックを待たずに会話が即座に表示され、最初のメッセージでトランスクリプト全体を再読み込みしないように
・ツール多用のターン中の応答性を向上（ツールバッチ毎の非表示リマインダーのためのトランスクリプト再描画を廃止）
・`.claude/workflows/` スクリプトを持つプロジェクトの起動時間を改善（スクリプト一覧表示時に各スクリプトを解析しないように）
・auto モードの拒否メッセージを改善（ブロックしたルールを明示し、より安全な方法を試みてから停止するよう指示）
・Claude in Chrome の改善: 長いページ読み取りをファイル保存・再読み込みなしでインライン表示
・MEMORY.md 切り詰め警告を改善（切り取られた行数と切り取り開始位置を表示）
・Artifact のターミナル権限プロンプトを改善（質問を先頭に表示）
・プロンプトフッターの改善: エディタや `/diff` セレクションがプロンプト入力内に表示され、フルスクリーンモードではヘッダーに Remote Control ステータスを表示
・「1M コンテキストに使用クレジットが必要」メッセージを改善（セッション中に有効化した使用クレジットは Claude Code 再起動後に反映される旨を説明）
・`/plugin` の改善: インストール、有効化、無効化がメニューを閉じた時点で即反映（`/reload-plugins` 不要）
・Bedrock/Vertex/Foundry のシステムプロンプトを添付ファイルとして配信するように変更（ファーストパーティセッションと同様）
・Bedrock/Vertex/Foundry セッションのツールリストを会話全体でバイト安定に変更（遅延接続ツールはリストを書き換える代わりに遅延ロード）
・タスクトラッキングツール（TaskCreate/Get/Update/List、TodoWrite）を Claude 3.x、Opus 4.0–4.7、Sonnet 4.0–4.6、Haiku 4.5 のみで提供するように変更（他のモデルは `CLAUDE_CODE_ENABLE_TODO_TOOLS=1` で有効化）
・Artifact データ編集の権限プロンプトをドキュメント数と公開範囲を表示するカードに変更
・すべての承認をスキップするローカル Cowork セッションの Artifact ツールを変更: セッションフォルダ外またはシンボリックリンク先のローカルファイルを確認なしで読み取る代わりに拒否するように
・プレーンな `WebFetch` の deny/ask ルールが Artifact ツールの読み取り・更新に適用されないように変更（Artifact ルールまたは `WebFetch(domain:claude.ai)` を使用すること）
・`claude mcp list` と `claude mcp get` でシークレットが漏れていた起動時 MCP サーバー認証通知を改善（各サーバーを毎回でなく一度だけ通知）
