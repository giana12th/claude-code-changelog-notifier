🔧 **Claude Code アップデート**
**v2.1.321** (2026年11月9日)

**追加 (3件)**
・Claude Fable 5.2（`claude-fable-5-2`）を追加、デフォルト Fable モデルに設定。コンテキスト 1M、$8/$40/Mtok、キャッシュ読み取り $0.20/Mtok
・`claude remote-control` に `--settings <file>` を追加。起動するすべてのセッションに設定ファイルを適用する。ファイルが変更された場合、`claude remote-control` を再起動するまで新しいセッションは開始しない
・[VSCode] 認証トークンと API キーの両方が設定されている場合、プロンプトボックスの上に警告を追加（端末の起動時警告と同様）

**変更 (26件)**
・セッションフィードバックメッセージと `allowedProviders` 設定の説明を更新し、Pro と Max に加えて Ultra を追記。`forceLoginMethod` の説明もすべての有料 Claude プランをカバーするよう更新
・バンドルされた dataviz スキルを更新。それぞれに上限がある複数の比率に対して、項目ごとに 1 行のメーターリストを提案するよう変更
・「Upgrade to Max」オプションを「Upgrade to Max or Ultra」に変更
・Claude が書いた mods が auto および bypass モードで、管理された `allowUnsandboxedCommands: false` や `allowManagedDomainsOnly` の下でも確認なしで有効化されるよう変更。`dontAsk` モードでは読み込まれないよう変更
・mods 自身のツール呼び出し（`$.tool.call`、`$.mcp.call`）が、ユーザーの ask ルールや `dontAsk`・`-p` 実行でも permission プロンプトを出さないよう変更。deny ルールと組織ポリシーは引き続き適用
・保存された Fable 5.1 モデルの選択を `fable` に移行するよう変更。Pro と Max プランはすぐに、Team と Enterprise プランは組織が許可後に適用。元に戻すには `/model claude-fable-5-1` を使用
・`/fast`、`/config`、`/model` の fast mode ラベルを更新。現在のモデルが fast mode に対応している場合はそのモデル名を表示するよう変更。VS Code 行から「(Opus only)」を削除
・ネストされたスキル読み込みを変更。`~/.claude/plugins` 内の `.claude/skills` フォルダが Claude のファイル操作時に読み込まれないよう変更
・Self-hosted runner: オンデマンドランナーがサーバーに不要（セッション終了、一時停止、ワークオーダー置き換え）として拒否された場合、exit 1 ではなく exit 0 で終了するよう変更
・Windows: Claude Code が自身で起動するプログラム（git など）の検索方法を変更。相対パスや UNC PATH エントリ、ネットワーク共有へのリンクをスキップし、設定から PATH 変更を反映
・非インタラクティブセッションの OpenTelemetry hook イベントを変更。Bash と PowerShell 呼び出し後、2 つの組み込み hook を `num_hooks` と `num_success` から除外
・Claude Desktop Code タブセッションが他のセッションに再入力を待つ前に送信できるメッセージ数を 10 から 20 に変更
・`claude -p` と SDK セッションでの `AskUserQuestion` を変更。ホストが未文書化の `afkTimeoutMs` 入力フィールドを設定する permission 応答を拒否するよう変更
・管理された `extraKnownMarketplaces` を変更。宣言された名前は他のソースから追加できない。他からのエントリは非表示になり、宣言されたマーケットプレイスのプラグインはそこから再インストールされる
・アプリが提供する Claude in Chrome ツール（Claude デスクトップアプリの Code タブなど）が組織の Claude in Chrome ポリシーに従うよう変更
・Claude apps gateway の `policy_mode: layered` を変更。管理された MCP サーバーがすべての一致ポリシー（`match: {}` を含む）で累積されるよう変更
・Gateway: Bedrock、Vertex、Foundry アップストリームが gateway 環境の `ANTHROPIC_*_BASE_URL` 変数を無視するよう変更。別のエンドポイントを使うには `base_url` をアップストリームに設定
・ヘッドレスセッションがファイル変更時に `.claude/skills` の mods を再読み込みするよう変更。無効化には `CLAUDE_CODE_PLUGIN_DIR_WATCH=0` を設定
・サイバー保護ブロックの Cyber Verification Program の文言を claude.ai と同じものに変更
・Cowork クラウドセッションを変更。PostToolUse hook が AskUserQuestion への応答や ExitPlanMode の結果のプランを置き換えられないよう変更。Claude は元の値を読み取る
・パスで指定された `cp` と `mv`（例: `/bin/cp`）が `cp` と `mv` と同じパスチェックを受けるよう変更
・バックグラウンドコマンドの通知と TaskStop の結果を変更。1,000 文字を超えるコマンドは先頭と末尾のみを Claude に表示し、コンテキストを節約
・アーティファクトデザインのガイダンスを更新。Inter と Space Grotesk を推奨デフォルトタイプフェイスとして記載
・アカウントメールチェックを変更。メールアドレスを含み User-Agent を指定するシェルコマンドのみを確認なしに拒否。他のコマンドやスケジュールされた実行は停止しないよう変更
・Remote Control セッションが開始されたフォルダを維持するよう変更。接続されたクライアントがセッションを別のフォルダに移動できないよう変更
・管理された `extraKnownMarketplaces` による非宣言ソースからの引き継ぎを変更。保存されたデータは `cleanupPeriodDays` の間保留、オプションとシークレットは `claude plugin restore-set-aside` まで保留

**改善 (15件)**
・`/model` ピッカーを改善。「More models」が他のすべての下に番号なしの行として表示され、古いモデルがその下に展開されるよう改善
・Gateway: 高負荷レプリカでの支出制限を改善。チェックのスキップを減らし、支出の記録をより早く行うよう改善
・Claude apps gateway のサインイン制限メッセージを改善。Claude Code と `/device` ページでの表示から gateway 設定の名前を削除（gateway 自身のログには引き続き記載）
・`claude install` とインストールスクリプトを改善。2～4 秒短縮
・クラッシュした Remote Control セッションが新しいメッセージを受け取れるまでの時間を改善
・Windows: PATH からプログラムを見つける起動・初回コマンド時間を改善。ヘルパープロセスなしで PATH を検索するよう変更
・ヘッドレスセッション、デスクトップアプリ、VS Code での auto mode を改善。複数のバックグラウンドサブエージェントのレポートを 1 つのモデル呼び出しで処理（端末と同様）
・ワークツリーのセットアップに失敗した `claude --bg --worktree` セッションのエージェントビュー行を改善。内部タグや末尾 200 文字ではなく、開始時のエラーを表示するよう改善
・別の組織にあるアーティファクトのメッセージを改善。自分のものであれば `/login` を提示し、アカウント移動後のコピー場所を案内するよう改善
・1 つのリクエストに収まらない画像が多いセッションを改善。すでに表示済みの削除された画像かどうかを Claude に伝え、変更のない画像の繰り返し読み取りを制限するよう改善
・`claude remote-control` の最初の質問に答えなかった場合のメッセージを改善。次に何をすべきかを明示するよう変更
・信頼された TLS 証明書の読み込みを高速化して起動時間を改善
・Claude apps gateway のエラーメッセージを改善。ユーザー名やパスワードなしで gateway のアドレスを表示するよう変更
・Claude apps gateway の支出制限エラーを改善。リセット時刻をローカル時間で表示（例: 「resets 4pm (America/Los_Angeles)」）
・Windows: 標準的な Git for Windows インストールでの起動時間を改善。毎回起動時に実行する git.exe の確認をなくすよう変更

・Claude がワークツリーに入った後、SDK とデスクトップセッションでメニューからプロジェクトスキル、コマンド、エージェントが消える問題を修正

・複数のバックグラウンドエージェントのレポートが待機中に Claude が停止した後、1 つのリクエストに意図より多くのレポートが含まれる問題を修正
・Claude が作業中に入力した場合、Claude Desktop Code タブセッションから他のセッションへのメッセージが一時停止したままになる問題を修正

・クラウドセッションで、コネクターが非常に長い名前のリソースをリストする場合のハングまたはメモリ不足クラッシュを修正
・セッションの履歴がまだアップロード中に接続が永続的に閉じた後に Remote Control が接続済みとして表示される問題を修正

・ネットワーク上の何かが接続を受け入れるが TLS ハンドシェイクに応答しない場合のサインイン、トークン更新、ログアウトの無限待機を修正
・名前にテキスト方向や制御文字が含まれるファイルが Claude apps で別の名前で表示される問題を修正。Claude はそのようなファイルの送信を拒否するよう変更
・サブエージェントの進捗サマリーがモデルがツール呼び出しで返答した後にリクエストを末尾まで実行する問題を修正
・`grep -r foo "$PWD/src"` のような Bash の読み取りがパスを明示的に記述した同じコマンドより permission を求める問題を修正
