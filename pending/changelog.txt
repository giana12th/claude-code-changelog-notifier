🔧 **Claude Code アップデート**
**v2.1.300**
**追加**
・mod のプロンプト装飾に `virtualText` を追加: プロンプトボックスに描画されるが、下書きや送信プロンプトには入らないテキスト
・OpenTelemetry の `api_request` イベントに `cache_creation_5m_tokens` と `cache_creation_1h_tokens` を追加（キャッシュ書き込みをライフタイムごとに分割）
・mod に `$.ui.view({ agentId })` を追加: エージェントのトランスクリプトをメインビューに表示可能（`$.ui.view({})` で元に戻る）
・mod の `Text` に `dir` プロップを追加: RTL（右から左）テキストのサポート
・AWS 上の Claude Platform に `/advisor` を追加（`/advisor`、`advisorModel`、または `--advisor` で選択するまで実行しない。`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効化可）
・トレーススパンに OpenTelemetry GenAI セマンティック規約属性（`gen_ai.provider.name`、`gen_ai.conversation.id`、`gen_ai.tool.name`、`error.type` 等）を追加
・`agent.spawn` mod フックでワークフローエージェントの `prompt` と `model` の書き換えをサポート（以前はワークフローエージェントの拒否のみ可能）
・`prompt.change` mod フックを追加（履歴の呼び出し、クリア、元に戻す、プラグインの入力などの入力なしでプロンプトボックスのテキストが変わったときに発火）
・[VSCode] `claudeCode.attachSelection` 設定を追加: エディタで選択したテキストがメッセージに追加されないようにする
・[Claude Tag] Slack Connect チャンネルのサポートを追加（オーナーまたは管理者がオプトイン、デフォルトでオフ）
・[Claude Tag] コネクターアクションの承認が必要な場合、Slack スレッドにプライベートな「許可/拒否」カードを追加（他ユーザーには待機中であることのみ表示）
・[Claude Tag] Claude in Slack で Slack 音声クリップをサポート（Slack に文字起こしがある場合）

**変更**
・終了時、停止要求から 1.5 秒後もバックグラウンドコマンドが実行中の場合は強制終了するよう変更
・`CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` セッションが CA バンドル、ツールプロキシ、git TLS 等の変数を無視するよう変更
・大きな api.anthropic.com へのリクエストにテレメトリー無効時も gzip 圧縮を使用するよう変更（`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` で無効化可）
・`claude-api` スキルが、アーカイブや削除を求められない限り Managed Agents セッションを維持するよう変更
・ローカルセッションのトランスクリプトが各 API リクエストのシステムプロンプト、ツール、パラメーターも記録するよう変更
・`/sandbox` モードオプションの表示を「Sandbox commands」に変更
・フック: PreToolUse および PermissionRequest フックからの `updatedInput` が Claude 自身の入力と同様に検証されるよう変更
・`claude remote-control` から `--sandbox` と `--no-sandbox` フラグを削除（渡すとエラー。`sandbox.enabled` で設定）
・[Claude Tag] 管理者が Slack チャンネルに付けたアクセスバンドルが Slack Connect チャンネルになった後も引き続き適用されるよう変更

**改善**
・Cowork クラウドセッションの WebFetch が直前に失敗したページを再フェッチせずに Claude に通知するよう改善
・アーティファクト更新の改善: 小さな変更は 1 回の呼び出しで変更・再公開可能

**59 件のバグ修正**

**v2.1.299**
**追加**
・`CLAUDE_CODE_DISABLE_FILE_MENTIONS` 環境変数を追加: `@` ファイルメンションのパスのみ Claude に渡す（ファイル内容は送らない）
・アイドル時の自動コンパクトを追加: 200K 超のトークンを持つ会話が約 54 分アイドル状態になると、1 時間のプロンプトキャッシュの期限前に圧縮
・`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` でアイドルコンパクトの 200K トークン最小値を変更可能。`"idleCompaction": false` でオフ（v2.1.290 以降が必要）
・`$.prompt.media` を追加: managed settings でインストールされた mod の `prompt.submit` フックがプロンプトに添付された画像やドキュメントのバイト列を読み取り可能
・managed settings でインストールされた mod に `$.session.identity()` を追加: サインイン方法、組織、メールアドレスを取得可能
・mod の `Text` に `size`、`weight`、`mono`、`tabular` と `Box` に名前付きスペースステップ（`xs`〜`xl`）を追加（`bold` は `weight` に非推奨）
・`claude self-hosted-runner orchestrator` に `--shutdown-drain-sec` を追加: SIGTERM 時に実行中の poll と spawn フックを指定秒数待機
・スキルのフロントマター、ソース、プラグイン名、ファイルパスを mod の `skill.prompt` フックが受け取れるよう追加
・エージェントビューに `/effort` と `/fast` を追加: 新しいセッションの開始設定を変更可能
・`--disallow-tools` と `disallowed_tools` ケースフィールドを `claude plugin eval` に追加
・Claude apps ゲートウェイの `code` ポリシーで `CLAUDE_CODE_ATTRIBUTION_HEADER=0` を設定してアトリビューションブロックを非表示にする機能を追加
・`/usage` に最大 effort、ワークフロー、常時オンコンテキスト、大きなツール結果に対する警告を追加
・[Claude Tag] Claude in Slack がチャンネルで作成したキャンバスの削除をサポート
