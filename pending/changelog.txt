🔧 **Claude Code アップデート**
**v2.1.162**
・`claude agents --json` に `waitingFor` フィールドを追加（セッションがブロックされている理由を表示）
・Grep/Glob をツール名として明示的に指定すると、専用の検索ツールが使用されるように
・`/effort` コマンドで、選択したレベルが新規セッション用にデフォルトとして永続化されることを確認表示
・スラッシュコマンドのオートコンプリートをクリックすると、即時実行ではなくプロンプトに入力され Enter で実行するように変更
・Remote Control が起動メッセージではなく永続フッターピル（セッションへのリンク付き）として表示されるように変更
・Windsurf が Devin Desktop に改名（`/ide` メニュー、`/terminal-setup`、`/scroll-speed` に反映）
・設定ディレクトリが読み取り専用の場合の起動ハングを修正（メモリ内設定でフォールバックし起動エラーを表示）
・WebFetch パーミッションルールが事前承認ドメインに適用されていなかった問題を修正（明示的なルールが自動許可より優先されるように）
・Windows でバックスラッシュ（`~\`、`\\server\share`）やケース異なりのパスのパーミッションルールが機能しない問題を修正
・Read ルールが Glob/Grep 結果からファイルを非表示にしない問題を修正
・ターンの最初の Esc 割り込みが stream-json/SDK セッションで無視される問題を修正
・絵文字による API 400 `no low surrogate in string` エラー（クラシファイアサイドクエリ・MCP サーバー説明）を修正
・MCP `timeout` が 1000ms 未満の場合のフロア処理を修正（1000ms 未満の値は無視し `claude mcp get` に注記）
・LSP `workspaceSymbol` が結果を返さない問題を修正（`query` パラメーターを受け入れ言語サーバーに渡すように）
・`claude agents` でのステータステキスト切り詰め問題を修正（ターミナル幅全体を使用するように）
・`claude agents` での長いセッション名の切り詰め問題を修正（名前列がターミナル幅に応じて拡張するように）
・バックグラウンドサービス再起動後の最初の試行でアタッチがセッションリストにバウンスバックしていた問題を修正
・`claude agents` での Ctrl+V 画像ペーストがディスパッチ入力とセッション返信ボックスで機能しない問題を修正
・バックグラウンドサービス起動失敗時に会話が無音で失われていた問題を修正（セッションはリストに残り Enter で起動可能）
・エージェントビューからの送信失敗した返信が失われる問題を修正（次回セッション起動時に配信キューに入るように）
・`CLAUDE_CODE_TMPDIR` / `$TMPDIR` が深いディレクトリを指す場合、`SendMessage` が無音で破損する問題を修正
・`claude agents` から実行中のバックグラウンドセッションを開く際の5秒スタールを修正
・起動通知の改善：通知が重大度でグループ化され、セッション情報とお知らせが1行を共有するように
・起動警告を短く明確に書き直し（各警告に具体的な修正を含む）
・起動プロンプト警告がアクションするまでプロンプトの下に固定されるように
・失敗したターンがコンパクトな警告行で表示されるように（複数行の赤いエラーブロックから変更）
・エンドポイントセキュリティによる新バイナリのスキャン中にバックグラウンドサービス起動と `claude update` 検証を待機するように改善
