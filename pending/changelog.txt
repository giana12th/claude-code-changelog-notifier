🔧 **Claude Code アップデート**
**v2.1.240**
・バグ修正と安定性の改善

**v2.1.239**
・コスト見積もり（`/cost`、ステータスライン、`--max-budget-usd`）にデータレジデンシーワークスペース向けの1.1倍米国専用推論プレミアムを含むようになった
・Bedrock、Vertex、Foundryなど従来除外されていた環境にフルスクリーンレンダラーの一回限りの提案を追加。新規インストールではフルスクリーンで開始されるようになった
・Pythonプロジェクトを `anthropic` 0.xから1.xに移行する `/claude-api upgrade` を追加。スキルのPythonリファレンスも1.x向けに更新（タイムアウトは `httpx.Timeout` でなく `anthropic.Timeout` を使用）
・クラウドセッション：claude.aiから同期されたプラグインが `name@synced` として表示されるようになり、`claude plugin enable/disable <name>@synced` で操作可能に。同名のローカルインストール済みプラグインを上書きしなくなった
・Alpine/muslビルド：ネイティブの画像ペースト、クリップボード、音声キャプチャアドオンが正常に読み込まれるようになった（以前はglibcビルドのバイナリがmuslランタイムに拒否されていた）
・月次支出上限が既に使い切られている場合の使用制限メッセージにセッションまたは週次制限のリセット時期も表示されるようになった
・Content-Typeヘッダーを削除するプロキシ背後でのBedrock streamingバグを修正（ターンがサイレントに非streamingで再実行されAPIコール費用が2倍になっていた）
・SSO プロファイルと `awsAuthRefresh` を使用したBedrock + HTTPSプロキシ環境でのClaude Code起動時ハングを修正。クレデンシャルの事前チェックが `HTTPS_PROXY` を尊重するようになった
・存在しないディレクトリからClaude Codeを起動した際のクラッシュダンプを修正。明確なメッセージを表示するようになった
・Claude Codeプラグインが接続されているJetBrains IDEターミナルでEditおよびWriteの呼び出しが約5秒間一時停止するバグを修正
・プロンプトがキューに入っている状態でEscを押すと次のターンが早期終了してセッションがアイドル状態になりアクションが繰り返される可能性があったレースコンディションを修正
・WebFetchが期限切れのページコンテンツをセッション全体でメモリに保持し続けていたバグを修正（本来は15分で期限切れ）
・アイドル後のワーカー再起動でクラウドセッションがplan modeを解除して再開する問題を修正
・フルスクリーンモードでターミナルより高いMCPエリシテーションフォームが切り取られる問題を修正。フォームがウィンドウに収まり、非表示フィールドはスクロールで到達でき、Accept/Declineが常に表示されるようになった
・クラウドセッションまたはSDKの `setMcpServers()` 経由のセッション途中再接続時にリモートMCPサーバーが一時的な5xxエラー後も失敗し続けるバグを修正
・64KB超の会話が書き込まれた後にカスタムセッションタイトルが `/resume` から消えるバグを修正
・`claude -c`/resumeが `_`、`-`、`.` などの文字のみ異なる別ディレクトリのセッションを拾い上げる問題を修正
・`/resume` とエージェントビューで、ファイルに触れただけまたは再度開いただけのセッションが最近更新されたとして表示・並び替えられるバグを修正
・全プロジェクトモードの `/resume` が削除されたディレクトリ（削除されたworktreeなど）への `cd` を促す問題を修正。そのようなセッションは現在のディレクトリで再開するようになった
・フルスクリーンモードで `dark-ansi` テーマが展開されたツール結果を背景と同色のテキストでレンダリングするバグを修正
・フルスクリーンレンダラーのプロンプトが回答できない環境でも毎回起動時に表示される問題を修正。3回の起動後に表示を停止するようになった
・`.worktreeinclude` パターンが `**/` で始まる場合にgitignoreされたディレクトリ内のターゲットに対してサイレントにマッチしないバグを修正
・UTF-8 BOMで始まる `.md` ファイルのエージェント、スキル、コマンドがサイレントに無視される問題を修正
・一部モデルで `/insights` がリテラルの `<message>` タグをレスポンスにエコーするバグを修正
・マーケットプレイスの `metadata.pluginRoot` が効果を持たない問題を修正。裸のプラグインソース名がドキュメントに記載通りにそのディレクトリ下で解決されるようになった
・ブラウザベースターミナルでマウスレポートが書き込みをまたいで分割された際に `"35;150;7M"` のようなテキストがプロンプトに挿入されるバグを修正
・カスタムテーマのeffort/ultracodeステータスバッジ色設定が無視されるバグを修正
・OpenTelemetryトレース断片化を修正。`PreToolUse` フックで延期されたツール実行が新しいトレースを開始する代わりに元のターンのトレースで再開するようになった
・エージェントビューのvimモードを修正。EscapeがNORMALモードに切り替わり、テキストをクリアせずに保持するようになった
・Shift+Arrowキーで拡張されたテキスト選択が `selection:copy` キーバインディングでサイレントに失われるバグを修正
・`voice.enabled` 設定で音声入力を有効化した後も `/voice` のスタートアップヒントが表示され続けるバグを修正
・シェルモード（`!`）のTab補完が `./script` パスから `./` を削除してシェルが実行できないコマンドを生成するバグを修正
・フルスクリーンモードで権限プロンプトへの回答やボタンのクリックが、ウィンドウをフォーカスに戻すためだけにクリックした際にも発動するバグを修正
・フルスクリーンモードのスラッシュコマンドパネル（`/config`、`/model` など）が最新メッセージを覆う問題を修正。会話がパネルの上に固定されるようになった
・`/workflows` の詳細ダイアログがClaude応答中にフルスクリーンモードで開かれた際に端末からはみ出してヘッダーが画面外に消える問題を修正
・Linuxサンドボックスが `extensions.worktreeConfig` を設定したリポジトリで存在しない `.git/config.worktree` を読み取り不可にしてすべてのサンドボックス化されたgitコマンドを壊すバグを修正
・セッションの作業ディレクトリが削除された後にフックが "posix_spawn ENOENT" で失敗するバグを修正。プロジェクトルートまたはホームディレクトリから実行されるようになった
・`claudeMdExcludes` がパターンがルールディレクトリやシンボリックリンクをターゲットとしている場合にシンボリックリンクされた `.claude/rules` ファイルを除外しないバグを修正
・Remote Controlへのセッションタイトル同期が暴走するバグを修正（2.1.232のリグレッション）。タイトル更新が重複排除とレート制限されるようになった
・タイトルが `/` で始まるセッションが `SendMessage` でアドレス指定できず `ListAgents` で "(untitled)" と表示されるバグを修正
・Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D、vim `df`/`dt` がカーソルが内部にある場合に壊れた `[Pasted text #N]` プレースホルダーを残すバグを修正
・ログインコードフィールドなどのマスク入力のテキストがダブルEscでクリアした後にCtrl+Yで貼り付けたりプロンプト履歴に保存されてしまうバグを修正
・検索ボックスでCtrl+Backspaceが単語削除ではなく1文字削除になるバグを修正
・組織のポリシーチェックで拒否されたリクエストが拒否表示前に再送信されるバグを修正
・コンパクション後のリマインダーを改善し、スキルの元の引数が新しいリクエストとして再実行されないようにした
・ツール使用行の長いファイルパスが1行に収まるように中間で省略されるようになった
・長時間の `SessionStart` または `Setup` フック実行中もリモートセッションがキープアライブを送り続けるようになり、フック実行中にコンテナがアイドルとして回収されなくなった
・`/goal`: 長時間バックグラウンド作業での繰り返しチェックインが毎30分の繰り返しではなくバックオフ（30分→1時間→2時間ごと）するようになった
・`/goal`: `claude --resume` ピッカーからのセッション再開時にアクティブなゴールが復元されるようになった
・`ListAgents` がセッション自身の名前（他のセッションが `SendMessage` で使用する名前）を通知するようになった。自分の名前への `SendMessage` が "no agent named …" でなく適切なメッセージを返すようになった
・`ListAgents` と `/list-agents` がライブのチームメイトを一覧表示するようになった（以前はサブエージェントと他のセッションのみ表示されていた）
・`keybindingFlavor: "readline"` がBash の単語キーにも対応。Alt+F とCtrl/Option+→が単語の末尾で停止、Alt+Dが単語末尾まで削除（Ctrl+Yで貼り付け）、句読点が単語区切りとして機能するようになった
・持続的リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）が組織の支出上限と残高不足エラーで無限待機する代わりに即座に失敗するようになった
・Claude in Chrome: `/clear` がセッションのChromeタブグループを閉じるようになった。`/resume` とClaude Code終了時に空のタブグループが閉じられるようになった
・リモートセッション：モバイルからアップロードされた画像に保存ファイルパスが含まれるようになり、Claudeが作成するファイルへのコピーが可能になった
・Claude Code on the web: Bashや他のツールからのnon-API anthropic.comホスト（www、docsなど）へのリクエストがセッションのネットワークプロキシを通るようになり、環境の許可ドメインが適用されるようになった
・Remote Control：アカウントでRemote Controlが有効でない場合のメッセージと `claude doctor` の表現が明確化された
・Windows: クロスセッションメッセージングが利用可能になり、macOSやLinuxと同様にマシン間でClaude Codeセッションが `SendMessage` でメッセージを送り `ListAgents` でお互いを見つけられるようになった
・[VSCode] 使用制限バナーの「使用状況を表示」リンクがバナーの中央に浮かぶ代わりに警告テキストとインラインで表示されるようになった
