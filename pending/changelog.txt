🔧 **Claude Code アップデート**
**v2.1.283**
・LLMゲートウェイが1つのユーザープロンプトに対するリクエストをグループ化できるよう、`x-claude-code-prompt-id` をゲートウェイヒントヘッダーに追加。`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1` でオプトイン
・managed設定 `availableModelsMatch` を追加。`"exact"` を指定すると、`availableModels` のエントリは指定したモデルバージョンのみを許可し、新リリースはリストに追加されるまでブロックされる
・managed設定 `deniedModels` を追加。`availableModels` で許可されていても特定のモデルをブロック可能
・`OTEL_LOG_TOOL_CONTENT=1` 設定時、MCP tool・WebFetch・WebSearch の出力を `tool.output` OpenTelemetryスパンイベントに追加
・`/doctor prompt-audit`（`/checkup prompt-audit` でも可）を追加。CLAUDE.mdファイル・skills・agents・commandsの旧モデル向けプロンプトパターンを監査
・フルスクリーンモードで、他のセッションからの切り詰められたメッセージをクリックで展開できる機能を追加
・stream-json `system/init` の `plugin_errors` にある `--plugin-dir` ロード失敗エントリに `path` を追加し、ロードに失敗したディレクトリ名を表示
・Claude appsゲートウェイ設定にオプトイン式 `load_test_mode` ブロックを追加。リクエストはビルド・署名されるが上流には送信されず、デプロイの負荷テストが可能
・Amazon BedrockのMantleエンドポイント用に、Claude appsゲートウェイに `mantle` アップストリームプロバイダーを追加
・ターンが早期終了した際のdeferred tool callや完了したtool result消失、worker再起動後の保留中承認プロンプト、非ストリーミングフォールバックの `result.usage` の問題を修正
・長時間実行のtool callがバックグラウンドに移行した後、MCPのプログレス通知が破棄される問題を修正。バックグラウンドタスクで最新の進捗が表示されるよう改善
・セッション終了時にstdio MCPサーバーが起動中のままの場合、プロセスが残り続ける問題を修正
・ステートレスリモートMCPサーバーからの短時間のHTTP 404（例：再デプロイ中のプロキシ）で、セッション残りの間サーバーが使用不能になりながら「接続中」と表示される問題を修正
・有効なURLがないサーバーへのMCPサインインが不明瞭なSDKエラーで失敗する問題を修正。そのようなサーバーでは `/mcp` がAuthenticate を表示しないよう変更
・テレメトリ無効時、週次Fableの制限が `/usage` とVS Codeの使用量メーターに表示されない問題を修正
・通常のIDが拒否された場合、日付や `-v1:0` サフィックス付きのIDで `[1m]` 付きSonnet 4.6またはSonnet 5が受け入れられる問題を修正
・`ANTHROPIC_DEFAULT_HAIKU_MODEL` で別のモデルを固定している場合、`/model` ピッカーがハードコードされたHaikuのバージョンと価格を表示する問題を修正
・モデルフォールバック中に開始したdynamic workflowsが、設定済みモデルの再試行ではなく全エージェントをフォールバックモデルで実行する問題を修正
・HaikuがセッションのメインモデルであるときにDISABLE_PROMPT_CACHING_HAIKUが効果を持たない問題を修正
・`claude plugin validate` がインストールできないpluginやmarketplace名を受け入れると誤って表示する問題を修正。そのような名前は `marketplace.json` でバリデーション失敗となるよう変更
・`outputStyles`・`themes`・`monitors`・`lspServers` のパスが存在しないか、pluginディレクトリ外を指しているpluginが `claude plugin validate` を通過する問題を修正
・`plugin.json` でサーバーを宣言しているpluginで `claude plugin details` が0 MCPサーバーと表示する問題を修正
・`claude plugin marketplace remove` がmarketplaceと共にアンインストールしたpluginを表示しない問題を修正。アンインストールされたpluginの一覧を表示するよう改善
・IDが大文字・小文字のみ異なる2つのインストール済みpluginで、指定したものに `enabledPlugins` エントリがない場合、`claude plugin uninstall` が対象外のpluginを削除する問題を修正
・バージョン未宣言のpluginで、キャッシュファイルが欠落した際にインストール済みコミットではなくソースの最新コミットに暗黙的に復元される問題を修正
・bind-mountedのdevcontainerなどでhomeまたはconfigディレクトリが移動された後、ユーザーインストール済みpluginおよびmarketplaceが「cache-miss」でロードに失敗する問題を修正
・無効なplugin idのレコードを含む場合、`installed_plugins.json` がpluginを表示しない問題を修正
・読み取れないレコードを含む場合、`installed_plugins.json` が書き換えられてレコードが消失する問題を修正。`claude plugin` コマンドがレコード名と復旧方法を表示するよう改善
・スクリーンリーダーモードで、許可ダイアログが引用されたコマンドとパスをダイアログ自体のテキストとして読み上げる問題を修正
・`/context` がMCPサーバーの指示をカウントしない問題を修正。独立した行として表示され、合計にカウントされるよう改善
・Warpターミナルでmarkdownリンクがクリック可能なハイパーリンクではなくプレーンテキストとして表示される問題を修正
・サンドボックス内などでユーザーまたはローカル設定ファイルへの書き込みができない場合でも、`claude mcp add`・`add-json`・`remove` が成功を報告する問題を修正
・クラウドセッションで、返答の最初の単語がClaudeの書き込みとともにストリーミングされず遅れて表示される場合がある問題を修正
・Claudeのキーバインドガイドでchordのタイムアウトを3秒ではなく1秒と表示し、`cmd` を `meta` のエイリアスと誤って説明していた問題を修正
・`keybindings.json` が `ctl+k` などのタイプミスのmodifierをエラーなく受け入れる問題を修正。デバッグログで警告と修正案を表示するよう改善
・`keybindings.json` で `footer:openSelected` をリバインドまたはアンバインドした後もフッターヒントが「Enter to view」と表示し続ける問題を修正
・素早く入力されたキー（先行入力・キーリピート・ssh/tmux経由のバースト入力）が古い状態で処理される場合がある問題を修正
・CA証明書が `GIT_CONFIG_COUNT` 環境変数のペアとしてgitに渡される場合、worktreeのチェックアウトで証明書検証が失敗する問題を修正
・サンドボックス内の `git` がcredential helperにサンドボックスプロキシのログインを保存するよう要求し、「failed to store」が表示される問題を修正
・ネストされた値の1つが無効な場合、managed `sandbox` 設定が完全に無視される問題を修正。無効な値はフェイルクローズになり、他の設定は引き続き適用されるよう改善
・gitリポジトリのサブディレクトリでClaude Codeを起動した場合、Claudeによる自身の自動メモリノートの編集がセンシティブファイルへの書き込みとしてブロックされる問題を修正
・`DISABLE_TELEMETRY` または `DO_NOT_TRACK` でテレメトリを無効にした場合、有料プランでRemote Controlが使用できなくなる問題を修正
・狭いターミナルで `/remote-control` メニューのQRコードヒントが単語の途中で切れる問題を修正
・vimモードで `.` がShift+Enter改行を消失させ、アクセント文字内にカーソルが残り、最終行での `3J` またはVisualモードの `J` の後に古い変更が繰り返される問題を修正
・vimモードのカーソル位置を修正。ノーマルモードで10,000文字超のプロンプトを呼び出してもカーソルが末尾を超えず、`V` 後の `p` が最初の非空白文字に着地するよう改善
・vimモードの `J` が異なるスペース（`)` 前のスペースやタブ後など）で行を結合し、最終行での `3J` またはVisualモードの `J` がVimと同様にカーソルを移動しない問題を修正
・[Windows] PowerShellツールが `cmd /c rd`・`rmdir`・`del`・`erase` を使ってドライブルート・homeフォルダ・`Remove-Item` が拒否するフォルダを削除できてしまう問題を修正
・`/mcp` のツールリストを改善。一度に多くのツールを表示、ページキーとマウスでスクロール可能、組織にブロックされたツールを警告アイコンで表示
・MCPツールの結果を改善。MCPツールが返す画像をファイルにも保存し、Bash・Readなど他のツールで開けるよう改善
・`/tasks` を改善。各行にステータスアイコンと名前・詳細を表示、多数のタスクでもタイトルとキーヒントを画面に表示、ページングキー・マウスホイール・クリックを追加
・`/help`・`/hooks`・`/copy`・`/chrome`・`/memory`・`/ide`・`/release-notes`・`/rewind`・`/diff`・`/remote-env`・`/plugin` 等のリスト操作を改善。ページキー・マウスホイール・クリックに対応
・`/skills`・`/artifacts` などの検索ボックス隣のリストを改善。検索ボックスがフォーカスを持つ間、リストのポインターをグレー表示し、1つのポインターのみをハイライト
・コンパクションスピナーを改善。タイマーがコンパクション開始時にスタートし、要約のトークンをストリーミングしながらカウント表示（パーセンテージバーを置き換え）
・MCPサーバーへのサインイン後に表示されるブラウザページを改善。中央揃えレイアウト・ダークモード・新しいアートワークを追加
・ロードに失敗したpluginに属するskillに対するSkillツールの返答を改善。skillが未インストールと表示する代わりに、pluginがロードできなかった旨をClaudeが通知
・Claude Code設定の `prompt-audit` を改善。古いパス・古いコマンド・矛盾した指示ファイルがレポートの冒頭に表示され、Claude Codeが文書化しているthinkingキーワードを保持
・`installed_plugins.json` が全く読み取れない場合の復旧を改善。ファイルの内容を再構築前に隣のファイルに保持し、`claude plugin list` がそのファイル名を表示
・artifactデータベースの読み取りを改善。全ページを返す順序付きクエリが、1ページであることと残りの読み取り方を表示
・初回返答のレイテンシを改善。セッションの最初の返答終了時に実行されていたパターンコンパイルステップが、返答のストリーミング中に実行されるよう変更
・事前接続済みのAPIコネクションを再利用することで初回リクエストのレイテンシを改善
・起動を改善。`claude -p` とClaude Code RemoteがインタラクティブUIを読み込まなくなり、auto-modeクラシファイアのルールとArtifactツールが起動時ではなく初回使用時に読み込まれるよう変更
・Artifactツール機能が未確認のclaude.aiアカウント（初回実行時など）の起動を改善。プロンプトが最大1.5秒待機しなくなり、最初のメッセージが必要に応じて待機するよう変更
・サードパーティプロバイダーまたはテレメトリ無効のインタラクティブセッションが、permissionモード未設定時にautoモードで起動するよう変更。`permissions.defaultMode` で引き続き上書き可能
・`/ultrareview` の起動ダイアログに、ローカルブランチのレビューでトラッキング済みファイルの未コミット変更がアップロードされる可能性があることを明記
・`/model` ピッカーのOpus行とデフォルトモデル名から、Opusがすでに1Mコンテキストウィンドウを持つ場合「(1M context)」の表記を削除。ウィンドウサイズは変わらず
・ターミナルのプロンプト候補が20件連続で未使用の場合、表示頻度が低下するよう変更。1件使用すると頻度が戻る
・`--system-prompt` と `--append-system-prompt` がテキスト形式と `-file` 形式を同時に受け入れるよう変更。ファイルのテキストが先に来る
・`Skill(anthropic-skills:<name>)` の拒否ルールがClaude Desktopがpluginとしてskillをデリバリーする場合もブロックするよう変更。`Skill(skill:<name>)` の拒否がskillのエイリアスと表示名にも一致するよう変更
・`/rewind` と `/diff` のリストが他のリストと同じキーバインドアクション（`select:*`）で移動するよう変更。`messageSelector:*`/`diff:*` のリバインドは引き続き動作
・`/workflows` の実行リストが他のリストと同様にサイズ設定されるよう変更。ターミナルの半分をインラインで使用し、プロンプトが下に表示されてもタイトルが画面に残る
・`claude plugin eval` がgitインストール時にgit 2.31以降を必要とするよう変更。古いバージョンでの実行はバージョン名を示すメッセージとともに拒否される
・artifact watchingを変更。自動的にセットされたwatchが3.5時間無活動後に終了するよう変更。artifactを再公開または再watchで再度セット可能
・[セルフホストランナー] ライフサイクルフックのgitがリポジトリのGit LFS `pre-push` フックをスキップし、書き込み可能なシステム `core.hooksPath` を無視し、`--configure-git` なしでコミットに署名しないよう変更
・[セルフホストランナー] Anthropic管理gitにおける `GIT_SSL_CAINFO` と `GIT_SSL_NO_VERIFY` を変更。ランナー自身のgitは常にAnthropicのgitルートを検証し、warning行が適用範囲を表示
・2.1.282での `claude-ai` 名の予約を元に戻した。その名前のskills・commands・workflows・MCPサーバーのskillsとpromptsが再びロードされ、`Skill(claude-ai:*)` ルールは通常のプレフィックスルールになった
・[VSCode] 自動切り替えに失敗した後もautoまたはbypassモードで実行し続ける場合、permissionモードインジケーターがDefaultと表示し続ける問題を修正。切り替えが成功するまで再試行するよう改善
・[VSCode] webからteleportされたセッションで、Claudeが作業中に送信されたメッセージが消失する問題を修正
・[VSCode] 古いバージョンが空のローカルコピーを保存した場合、Webセッションがセッションリストに表示されず、代わりに空のチャットが開く問題を修正
・[VSCode] 再度開いたセッションが、自動継続などのターン途中に受信したメッセージでターンが分割される問題を修正
・[VSCode] リロードしたセッションがrewindで削除されたターンや、コンパクション前の行のみを表示する問題を修正
・[VSCode] 狭いパネルでフッターのagentsピルのアイコンが中央からずれ、ステータスドットが端に当たる問題を修正
・[VSCode] 改行で終わる行を長いプロンプトに貼り付けた後、チャット入力のテキストがカーソルと選択範囲の少し下に表示される問題を修正
・[クラウドセッション] 実行中のクラウドセッションへのリポジトリ追加を改善。GitHubアカウントで読み取りは可能だがプッシュはできないプライベートリポジトリが読み取り用に接続できるよう変更
・[クラウドセッション] サーバーサイド再起動からの復旧後、クラウドセッションが完了済みのステップを再実行する場合がある問題を修正
・[クラウドセッション] 新しいルーティンスケジュールのデフォルトを時刻ちょうどの数分後に変更。時刻ちょうどに設定されたルーティンは数分遅れて開始される可能性があることを注記
・[Claude Tag] 「Channels Claude can search」管理設定を追加。組織・ワークスペース・チャンネル単位で、ClaudeのSlack検索を追加済みのパブリックチャンネルに制限可能
・[Claude Tag] Claudeアカウント接続後に表示されるページに「Back to Slack」ボタンを追加。元のスレッドに戻れるよう改善
・[Claude Tag] attachルール経由でアクセスバンドルを取得するチャンネルで、configureページにconectorsやpluginが表示されない問題を修正
・[Claude Tag] 大量の選択済みリポジトリに制限されたGitHub Appインストールで、アクセスバンドルのリポジトリ検索がリポジトリを見つけられない問題を修正
・[Claude Tag] 返信中に新しいメッセージが割り込んだ場合、Claudeが同じ返信を2回投稿する場合がある問題を修正
・[Claude Tag] Slack Connect共有後などでSlack channel IDが変更された古いプライベートチャンネルで、チャンネルルーティンが実行されなくなる問題を修正
・[Claude Tag] 「Channel only」設定のチャンネルで、非ゲストメンバーが参加した際にSlackのメンバーシップ確認が遅れると全会話が終了する問題を修正
・[Code Review] GitHubがpull requestを返さなかった場合に「@claude review」リクエストが無音になる問題を修正。リクエストを1回再試行し、それでも失敗した場合はコメントで説明
・[Code Review] 何も検証されないまま時間制限で停止したレビューへの課金を修正。未完了と表示され、課金されず、1回再試行されるよう変更
