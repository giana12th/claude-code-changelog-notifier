🔧 **Claude Code アップデート**
**v2.1.132**
・`CLAUDE_CODE_SESSION_ID` 環境変数を Bash ツールのサブプロセス環境に追加し、フックに渡される `session_id` と一致させた
・`CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 環境変数を追加して、フルスクリーン代替スクリーンレンダラーをオプトアウトし、ターミナルのネイティブスクロールバックを保持できるようにした
・Ctrl+V イメージペースト中に「Pasting…」フッターヒントを追加した
・外部 SIGINT（IDE ストップボタン、`kill -INT` など）がグレースフルシャットダウンを実行しないことを修正 — ターミナルモードが復元され、`--resume` ヒントが表示されるようになった
・ネイティブビルド下でセッション中にターミナルが閉じられたり SSH が切断されたりしたときの未キャッチ例外を修正した
・ツールエラートランケーションが絵文字を分割したときの `--resume` で `no low surrogate in string` エラーが発生することを修正 — 破損したセッションは読み込み時に消毒される
・`-p --continue`/`--resume` でプランモードセッションを再開する際に `--permission-mode` フラグが無視されることを修正し、同じセッション内で `ExitPlanMode` 後にプランモードが再適用されないことを修正した
・ノートパソコンのスリープ/起動後または Ctrl+Z/`fg` 後のフルスクリーンモードでの次のキーストロークまたはストリーム出力まで空白画面が表示されることを修正した
・Indic 合字または ZWJ 絵文字が行をまたがるときの Ctrl+E/A/K/U/矢印キーでカーソルが音素の途中に着地することを修正した
・分解形（NFD）の強調された文字を含むテキストを破損させる vim オペレータを修正した
・`/` で始まるテキストの貼り付けが入力を無言で飲み込んだり、未知のコマンド応答をトリガーしたりすることを修正した
・フォーカスイベントやマウストラッキングレポートが角括弧貼り付けと交互に表示されるときにストレイエスケープシーケンスをプロンプトにダンプすることを修正した
・Cursor および VS Code 1.92–1.104 での上流の xterm.js バグによるマウスホイールスクロールが速すぎることを修正した
・JetBrains IDE 2025.2 ターミナルでのスクロールホイール処理（虚偽の矢印キー、方向が違うイベント、暴走加速）を修正した
・Linux/X11 でのクリップボードへの統計スクリーンショットコピーで `/usage` Ctrl+S がハングすることを修正した
・Windows ターミナルで矛盾したエラーを示す `/terminal-setup` を修正 — Shift+Enter はそこでネイティブサポートされている
・`/effort` ピッカーが `CLAUDE_CODE_EFFORT_LEVEL` 環境変数オーバーライドを反映しないことを修正した
・`/status` でいくつかのユーザーに対してデフォルトモデルが間違って表示されることを修正した
・スラッシュコマンドオートコンプリートポップアップが表示可能なコマンドで上限が付けられることを修正 — ターミナルの高さでスケーリングするようになった
・ステータスラインの `context_window` トークンカウントが現在のコンテキスト使用量ではなく累積セッション総数を反映することを修正した
・macOS ターミナルで「Option as Meta」が有効になっていない場合（iTerm2、Terminal.app のデフォルト）での Alt+T（思考トグル）が機能しないことを修正した
・`claude agents` からバックグラウンドセッションを再度開いた後の Windows でのデッドキーボード入力を修正した
・stdio MCP サーバーが stdout にプロトコル以外のデータを書き込むときの無限メモリ増加（10GB+ RSS）を修正した
・接続するが `tools/list` に失敗する MCP サーバーが「接続済み・ツール取得失敗」と表示されるようになり、0 ツール（サイレント）が表示されることを修正した
・認可されていない claude.ai MCP コネクタが「失敗」ではなく「認証が必要」として表示されるようになり、ヘッドレス `-p` モードが非一時的な 4xx 接続エラーを再試行しなくなった
・スラッシュコマンドダイアログと `/login`、`/upgrade`、`/extra-usage` ダイアログのスペースで視覚的一貫性を改善した
・`/tui fullscreen` スタートアップバナーを更新して、追加のレンダラー利点（メモリ使用量の削減、マウスサポート、選択時の自動コピー）を説明するようにした
・`ENABLE_PROMPT_CACHING_1H` が設定されている場合の Bedrock および Vertex 400 エラーを修正した
🔗 https://code.claude.com/docs/en/changelog#2-1-132
