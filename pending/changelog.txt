🔧 **Claude Code アップデート**
**v2.1.218**
・`/code-review` をバックグラウンドのサブエージェントとして実行するよう変更。レビュー作業が会話を埋めなくなり、スタックされたスラッシュコマンドがレビュー対象として保持される
・`--ax-screen-reader` モードで、単語・行削除（`Option+Delete`、`Ctrl+W`、`Cmd+Backspace`、`Ctrl+U`、`Ctrl+K`）の際に削除テキストをスクリーンリーダーがアナウンスするよう追加
・`\u` プレフィックスのセグメント（`C:\Users\unicorn` など）を含む Windows パスがツール入力でCJK文字に破損され、ファイルにアクセスできなくなるバグを修正
・左矢印キーで確認なしに会話が破棄されるバグを修正：編集直後の押下は確認を求めるようになり、エージェントビューでの Esc はバックグラウンド化した会話に戻るよう変更
・`claude mcp list` および `/mcp` で、サーバー接続失敗時に HTTP ステータスとエラーテキストを表示するよう追加。MCP設定値に非表示の先頭・末尾スペースがある場合の警告も追加
・`Ctrl+J` として改行をエンコードするターミナルで、複数行ペーストが `j` で1行に折りたたまれるバグを修正
・メッセージピッカーからコンパクト化した後、`/context` がコンパクト前の古いトークン使用量を報告するバグを修正
・「review my auth changes」のような説明的な引数で `/ultrareview` が失敗するバグを修正。現在のブランチのレビューが、テキストを所見へのメモとして適用した上で実行されるよう変更
・非インタラクティブセッションで `/code-review ultra` がサイレントにローカルレビューを実行するバグを修正。クラウドレビューを起動するよう変更
・Bedrock の application-inference-profile ARN やその他の設定マッピングされた上流モデル ID について、設定済みモデルのレートで価格を計算するよう gateway 支出計測を修正
・長い IDE セレクションが絵文字の途中で切り詰められた際の文字化け、およびツールエグゼキューターエラーがサイレントにドロップされる場合を修正
・ファントムターンを開始・放棄する可能性があったエンジン終了時の競合状態を修正。クローズ後にプッシュされた入力を一貫して拒否するよう変更
・ツール呼び出し中断後の誤った「[Request interrupted by user]」メッセージ、およびツールが応答途中で中断した際にトランスクリプトに残る不対応の `tool_use` ブロックを修正
・`--ax-screen-reader` モードで、入力末尾のスペース入力時に VoiceOver が文字をエコーせず「new line」と読み上げるバグを修正
・プラグインおよび設定パネルがターミナルカーソルをフォーカス行に移動しないバグを修正。スクリーンリーダーや拡大鏡が矢印キーナビゲーションを追跡できるよう変更
・深くネストされた監視ディレクトリツリーの削除・移動時、および深くネストされた UI ツリーのレンダリング時に発生するクラッシュ（最大コールスタック超過）を修正
・セッション終了直後にPRを作成またはリンクした際にプルリクエストイベントが失われる場合があるバグを修正
・分割された AWS リージョンおよびプロキシ専用ネットワーク上で、assume-role プロファイルのプロファイル検証が失敗する Bedrock セットアップウィザードを修正
・システムクロック調整後に稀に発生するターン時間の負値・不正確な計測をモノトニッククロックで計測するよう修正
・claude.ai に接続されていない claude.ai コネクターを過剰カウントする起動時の「N MCP servers need authentication」通知を修正
・履歴の書き込みが競合または失敗した際にプロンプト履歴エントリが失われたり重複したりするバグを修正
・大きな思考バジェットを伴うコンテキストオーバーフローエラー後に同一のリクエストを再送する再試行ループを修正。`Ctrl+B` によるバックグラウンド化が他のパスと同様のバックグラウンドシェル制限を適用するよう変更
・信頼されていないフォルダからエージェントのフロントマターフックが実行されるバグを修正：フックはエージェントファイル自身のフォルダがワークスペース信頼を受理済みであることを要求するよう変更
・ヘッドレスおよび SDK セッションでのコンパクション後にフォークセッションのリネージが失われるバグを修正
・再開したセッションの履歴に不正な形式のデルタアタッチメントが含まれている場合に、全ターンが失敗またはクラッシュするバグを修正
・`/ultrareview` のエラーフィードバックを改善し、無効な引数を変更なしに再試行するのではなく Claude が修正できるよう変更
・auto モードの改善：dangerous-rm、バックグラウンド `&`、不審な Windows パスのチェックが許可ダイアログを開かなくなり、auto-mode 分類器が代わりに判断するよう変更
・IDE インタラクションのサンドボックスコマンド制限を改善
・信頼ダイアログが付与の対象となるリポジトリルートを明示するよう改善
・`/deep-research` を手動呼び出し時のみ開始するよう変更。Claude が自律的に起動しなくなった
・auto を使用したプランモードで、静的アナリザーが読み取り専用と証明できない Bash コマンドに対してプロンプトしなくなった。auto-mode 分類器が代わりに判断する
・`/config model=<x>` またはリモートコントロールによってモデルを切り替えた結果 fast モードが変更された際にアナウンスを追加
・サーバー管理設定で、機能・コスト切り替えなどの軽微な変更が設定承認プロンプトをトリガーしなくなるよう変更
・エージェントのマークダウンファイルで、プラグインネームスペースに予約された `:` を含むエージェント名を拒否するよう変更
・`context: fork` を持つスキルをデフォルトでバックグラウンド実行するよう変更。スキルごとに `background: false` でオプトアウト可能
・スキルおよびプラグインのフロントマターブール値として `yes`/`no`/`on`/`off`/`1`/`0`（大文字小文字不問）を `true`/`false` に加えて受け入れるよう追加
・ワーカーが置き換えられた後もリモートセッションがハートビートを送り続け、長時間稼働するデスクトップおよび IDE プロセスが数秒ごとに拒否リクエストをリトライし続けるバグを修正
