🔧 **Claude Code アップデート**
**v2.1.316**

**追加**
・`CLAUDE_CODE_DISABLE_ULTRATHINK` を追加：`ultrathink` キーワードを無効化する
・Claude apps gateway にプールドグループ予算を追加：グループメンバーが共有する月次予算をメンバー個別の制限に加えて設定可能（spend limits admin API の `pooled_budget` で設定）
・`CLAUDE_CODE_DISABLE_LOOPED_CROSS_CERT_DROP` を追加：ループ状のプライベートCAが必要なサーバー向けに、相互認証するシステムクロス証明書を保持する
・`CLAUDE_CODE_SUBAGENT_EFFORT` を追加：セッションのエフォートを継承する代わりに、何も指定がない場合のサブエージェントのエフォートレベルを設定する
・Claude apps gateway に `managed.policy_mode: layered` を追加：開発者に一致するすべてのポリシーが適用され、最初のポリシーだけでなく下位のポリシーにマージされる
・Claude apps gateway の Bedrock upstreams に `guardrail.input_tagging` を追加：Amazon Bedrock guardrail のプロンプト攻撃フィルター用 input タグでプロンプトをラップする。`all_messages_and_system` はシステムプロンプトもタグ付けする
・[VSCode] チャットパネルから Claude apps gateway へのサインインを追加（ターミナル不要）
・[Cloud sessions] フォームカードを cloud sessions に追加：MCPサーバーが要求するフォームへの回答・辞退が可能に（以前はリクエストが自動キャンセルされていた）
・[Cloud sessions] クラウドまたはRemote Controlセッションに切り替えた際、メッセージが追いついている間に "Catching up…" 表示を追加
・[Code Review] Code Review 分析ページに severity 別 findings カードを追加：期間の総件数、severity 別積み上げ日次チャート、各 severity のカウントを表示

**変更**
・Opus 4.8 の fast mode を 2026年10月30日付で非推奨化。2026年11月30日に削除予定。削除後は fast mode リクエストがエラーになり標準 Opus 4.8 にフォールバックしない。スピードアップを維持するには Opus 5.5 に移行
・`autoMode.allow` リストに `"$defaults"` がない場合でも、スケジュールタスクプロンプトの組み込みルールが削除されなくなった
・Team・Enterprise の server-managed settings 変更：Anthropic API から取得した設定は承認プロンプトなしで適用されるようになり、検証できないストアドコピーは拒否される
・[VSCode] `ultrathink` がターミナルと同様に `xhigh` エフォートで実行され、チャットボックスでレインボー表示されるようになった
・[Cloud sessions] Enterprise メンバーが自分のクラウド環境のネットワークシークレットを自分で追加・削除できるようになった（以前は表示のみ）
・[Claude Tag] Slack チャンネルの "Respond automatically" スイッチが "How Claude participates" の選択肢に変更（チャンネルの Configure ページおよび Claude Tag 管理設定）

**改善 (5件)**
・Claude Desktop またはウェブの Code タブから開始した `/code-review` の改善：クラウドと `claude remote-control` セッションでプレーンテキストリストではなく findings カードが表示されるようになった
・大規模リポジトリでの `/diff` を改善：更新ごとに git コマンド数を削減し、git が遅い場合は更新を分散する
・`/ultrareview`・クラウドセッション・クラウドエージェントが GitHub リモートを見つけられない場合のメッセージを改善：https://github.com/new でのリポジトリ作成を案内し、`/ultrareview` が無効な `gh` コマンドを提案しなくなった
・SSL 証明書エラーを改善：中間証明書の省略など原因の特定と各修正方法を具体的に表示するようになった
・[Cloud sessions] Changes ペインの改善：リストの省略事項の注記がdiff上の行ではなくブランチ名の横のバッジになった

**バグ修正 (34件)**
・macOS/Linux で資格情報拒否やクラウドセッションのアーカイブ時など、Claude Code が自動終了した際にシェルコマンドが実行中のまま残る問題を修正
・bash エイリアスの値に改行を含む場合（Git Bash を除く）や、名前がダッシュで始まる関数が Bash tool のシェルで壊れる・消える問題を修正
・Bash tool から起動した bash スクリプトが `SHELLOPTS` がエクスポートされている場合に最初のコマンドの後で停止する問題を修正
・コマンドが型キャスト・`param`・`using`・属性で始まる場合に PowerShell hook が exit code 2 でブロックしない問題を修正
・圧縮されたレスポンスが切断または破損した場合に一部のネットワークリクエストがハングする問題を修正
・Vertex AI・Amazon Bedrock で `sonnet`/`opus`/`haiku` を使用時、最新モデルがアカウントやリージョンで利用不可の場合にセッション途中でエラーが表示される問題を修正（旧モデルへのスイッチが正常に動作するように）
・Claude apps gateway がリクエスト中のすべてのモデルを `availableModels`/`deniedModels`/`models` に対してチェックしない問題を修正。ブロック対象モデルを指定したリクエストはフィールドを明示した 400 エラーを返すようになった
・managed settings で Claude apps gateway が必須の場合に `claude auth login` が実行を拒否する問題を修正：ターミナルではゲートウェイサインインを表示するようになった
・`--restricted` セッションで Read allow ルールが対象の場合、作業ディレクトリ外のファイルをアップロードできる問題を修正
・不可視文字を含むプロンプトの送信に2回 Enter が必要な問題を修正。通常プロンプトは1回 Enter でクリーンアップして送信、コマンドは引き続き確認を待つ
・親サブエージェントのモデルを継承したサブエージェントが、バックグラウンドジョブやメッセージで起動した際にメインモデルに移動してしまう問題を修正
・managed `autoMode.allow` リストに `"$defaults"` がない場合に、ホストアプリの `--settings`・`/permissions` への最初のルール追加・`/auto-mode-setup` から組み込み例外が復活する問題を修正
・auto mode でサーバーが安全性判定を返さずターンを停止した場合に、クラウドセッションとクラウドスケジュールタスクが失敗としてマークされない問題を修正
・バックグラウンドエージェント実行中に auto mode がターンを停止した理由が `claude -p` のテキスト出力に表示されないことがある問題を修正
・プロキシや実験的 beta が無効の LLM gateway を使用したホストアプリケーション（Claude Desktop 等）から開始したセッションで `CLAUDE_CODE_AUTO_MODE_SERVER=1` が無視される問題を修正
・資格情報を名前とする環境変数がスイッチ値（`1` など）に設定されている場合に、plugin MCP `headersHelper` スクリプトが破損した `CLAUDE_PLUGIN_ROOT` とサーバー URL を受け取る問題を修正
・SDK `register_repo_root` コントロールリクエストが作業ディレクトリ外のディレクトリの CLAUDE.md を読み込まない問題を修正（`CLAUDE_CODE_ADDITIONAL_DIRECTORIES_CLAUDE_MD=1` の場合）
・Artifact tool が `self` レベルのアーティファクトデータベースアクセスルールに `?` を表示し、それらのルールを削除するリパブリッシュを拒否する際に引用しない問題を修正
・`/model <id>` で認識されないモデルを指定した際、auto-compact が 200K コンテキストウィンドウを想定することの警告が表示されない問題を修正
・"hold space to speak" ヒントが1セッションで3回分を使い切り、push-to-talk が未バインドの場合に空のキーが表示される問題を修正
・検索プロセスがタイムアウトで強制終了されても終了しない場合に Grep・Glob が返ってこない問題を修正（Windows で発生）
・会話の一部が保存中に `/clear` や `/resume` が実行された場合に、再開時にプランが復元されないまれな問題を修正
・ターミナルが狭い場合にファーストラン設定でセキュリティ注意書きとターミナル設定説明の文字が欠ける問題を修正
・Enterprise のサーベイカードで短いポーズ後に 1 または 0 の入力が通ってしまう問題を修正：入力には Enter が必要になった
・[Self-hosted runner] Claude が作業中に送信されたメッセージが Stop の後にセッションプロセスが置き換えられてから回答される問題を修正
・[Self-hosted runner] セッションが別のマシンに移動した場合に MCP サーバーのオン/オフスイッチが失われることがある問題を修正
・[Windows] rc ファイルで errexit と pipefail が設定されていて winpty エイリアスのみまたはエイリアスが未定義の場合に、Git Bash での Bash tool がエイリアスと関数を失う問題を修正
・[VSCode] `opus[1m]` など `[1m]` タグが付いたモデル設定の場合に Effort スライダー・Ultracode スイッチ・モデル名が表示されない問題を修正
・[VSCode] 設定ファイルにエラーがある間に保存済みの `/btw` サイドクエスチョン履歴が早期に削除される問題を修正
・[VSCode] "Yes, and manually approve edits" でプランが承認されたあとリロードまたは再起動した際に会話が Auto mode で戻ってくる問題を修正
・[Cloud sessions] Files ペインのファイル検索で Claude がディレクトリ変更後にフォルダが `../..` パスで表示される問題を修正：結果がプロジェクトルートからのパスで表示されるようになった
・[Claude Tag] チャンネルで作成した canvas が別のチャンネルや DM にも共有された後、そのチャンネルから claude が canvas を編集・追記できなくなる問題を修正
・[Claude Tag] Slack Connect スレッドでタグなしの返信が未回答になる問題を修正（両組織が Claude をインストールしていて Slack が返信を他組織のアプリに配信した場合）
・[Claude Tag] クラウドスケジュールタスクの Slack ライブステータスチェックリストが半完了のまま残る問題を修正：実行中に投稿したトップレベルメッセージを同じ実行で編集できるようになった
