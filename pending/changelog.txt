🔧 **Claude Code アップデート**
**v2.1.281**

**追加機能**
・Claude apps gatewayにて、新しいClaude Desktop keysの`desktop`ポリシーブロックサポートを追加（`blockReadsOutsideWorkingDirectories`と`disableBypassPermissionsMode`を含む）
・Claude apps gateway BedroアップストリームでのSTSを使用したIAMロール経由のBedrockアクセス機能`assume_role`を追加（別AWSアカウントへのアクセスや開発者ごとのセッション設定も可能）
・Amazon Bedrock guardrailをすべてのリクエストに適用する`guardrail: {id, version}`をClaude apps gateway Bedroアップストリームに追加
・Claude apps gatewayの設定に`telemetry.resource_attributes`を追加（Claude DesktopおよびAPIセッションのテレメトリに固定ラベルを付与）
・`settings.json`に`"attribution": false`を追加してコミットやPRの帰属表示をすべて非表示にする機能を追加
・2026-07-28プロトコル接続上のMCP URL-modeのelicitation機能を追加（サーバーがClaude Codeにブラウザベースのフローを開くよう要求可能、完了確認ができないサーバーでは待機ダイアログが残らない）
・`claude plugin validate`にMCPサーバーチェックを追加（読み込み時にサイレントにドロップされる`.mcp.json`エントリ、未宣言の`${user_config.*}`参照、安全でないURLを報告）
・`/insights`にauto modeの推奨機能を追加（最近のセッションでauto modeが処理できたpermissionプロンプト数の推定値を表示）
・フルスクリーンモードの`/skills`、`/mcp`、`/plugin` Installedリストにスクロールバーを追加（マウスオーバー中に表示、クリックやドラッグ可能）

**改善**
・Claude Desktopのサインインと使用制限エラーメッセージをターミナルコマンドではなくアプリを指すように改善
・マネージド設定とポリシーフェッチが成功不可能なリクエストのリトライを行わないように起動を改善
・gitの読み込み、起動テレメトリ、Bedrock/Vertexモデルアップグレードチェックが最初のフレームの前に実行されないようにインタラクティブ起動時間を改善
・多くのファイルを読み込んだ長いセッションの再開時間を改善（復元されたファイルキャッシュが読み込まれた通りのファイルに一致するように）
・コンパクションされた非常に長いセッションの再開時間を改善（Agent SDKおよびClaude Desktop経由で最も顕著）
・1つの非常に大きな最初のプロンプトで構成されるセッションでの"Prompt is too long"回復を改善（そのプロンプトが要約から省かれる代わりに単独で要約されるように）
・セッションを新しいプロセスで再開した後のauto mode改善（permissionクラシファイアが以前のプロンプトキャッシュを再利用できるように）
・auto modeの拒否メッセージを改善（Claudeが拒否を正確なコマンドだけでなく結果として扱うように）
・危険なrm検出を改善（シェル変数と最上位ディレクトリ名の組み合わせ、作業ディレクトリから派生した変数、またはバックスラッシュのみのターゲットでの削除にもフラグを立てるように）
・macOSのsandboxガイダンスを改善（ローカルdev serverがポートをバインドできない場合に`sandbox.network.allowLocalBinding`を指摘するように）
・`--agents`がインラインJSONに加えてJSONファイルへのパス（`-p`）も受け入れ、空の`prompt`を許可するように改善
・`/batch`がgitリポジトリ内だけでなくWorktreeCreate hookがエージェントworktreeを提供する場所でも実行できるように改善
・プラグインのhook失敗エラーが問題のプラグインを名前で示すように改善、`claude plugin validate`がスペースを含むプラグインパスで`${CLAUDE_PLUGIN_ROOT}`が引用符なしのshell-formフックに警告を追加

**変更点**
・send now (ctrl+enterまたはctrl+x ctrl+s)が実行中のツールをキャンセルするのではなくバックグラウンドに移動するように変更
・auto modeを変更（クラシファイアレビューがサーバーサイドで実行される場所では、読み取り専用およびsandbox化されたシェルコマンドもそのレビューを待機し、フラグが立てられた場合はブロック）

・Claude apps gatewayが`managedMcpServers`エントリの`envHelper`パスが`\??\`または`/??/`で始まる場合に起動を拒否するように変更

・プロンプト下のセッションArtifactリンクが1つのフッターピル（`⧉ name`または`⧉ N`）に変更（`/artifacts`を開き、このセッションのArtifactを最初にリスト）
