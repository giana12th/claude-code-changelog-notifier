🔧 **Claude Code アップデート**
**v2.1.175**
・`enforceAvailableModels` マネージド設定を追加 — 有効にすると、`availableModels` 許可リストが Default モデルも制限するようになる（許可されていないモデルに解決される Default は最初の許可モデルにフォールバック）。ユーザーまたはプロジェクト設定でマネージドの `availableModels` リストを拡大することも不可になる

**v2.1.174**
・フルスクリーンモードでのマウスホイールスクロール加速を無効にする `wheelScrollAccelerationEnabled` 設定を追加
・`/model` ピッカーが Default の解決先モデルファミリーを非表示にする問題を修正
・`ANTHROPIC_DEFAULT_SONNET_MODEL` で別の Sonnet が固定されている場合、`/model` ピッカーがハードコードされた Sonnet バージョンラベルを表示する問題を修正
・エンタープライズアカウントで「Fable 5 is now consuming usage credits」バナーが誤って表示される問題を修正
・Bedrock GovCloud リージョン（`us-gov-*`）が誤った inference profile プレフィックスを導出する問題を修正
・バックグラウンドセッションが別セッションの `ANTHROPIC_*` プロバイダー環境変数を継承する問題を修正
・macOS・Linux で Claude Code 終了時に 1〜2 秒の停止が発生する問題を修正
・git コミットの共同著者帰属に誤ったモデル名が表示される問題を修正
・`/advisor` ダイアログで `availableModels` 許可リストによりブロックされた保存済みアドバイザーモデルが事前選択される問題を修正
・スキルのホットリロードでスキル一覧全体が再送信される問題を修正
・Workflow ツールの `agent()` サブエージェントにエージェントごとの帰属ヘッダーが欠落する問題を修正
・[VSCode] Account & usage ダイアログにキャッシュミス・長文コンテキスト・サブエージェント、スキル/エージェント/プラグイン/MCP ごとの使用量帰属を追加
・事前ウォームアップされたバックグラウンドワーカーが「Could not resolve authentication method」で失敗する問題を修正
🔗 https://code.claude.com/docs/en/changelog
