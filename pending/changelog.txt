🔧 **Claude Code アップデート**
**v2.1.257**
・Claude Fable 5.1（`claude-fable-5-1`）を追加。デフォルトの Fable モデルに変更 — 1M コンテキスト、$10/$50/Mtok、キャッシュ読み取り $0.25/Mtok
・「時刻フォーマット」（`timeFormat`）と `timeZone` 設定を追加。ターン終了時刻とトランスクリプトのタイムスタンプに 12時間制・24時間制・UTC・strftime パターンを指定可能
・auto モードに Containment Escape ルールを追加。クラウドメタデータ認証情報の取得・外部通信の回避・クロステナントアクセスは、環境が想定済みとマークしない限り自動承認されない
・`CLAUDE_CODE_SUBAGENT_MODEL_FORCE` を追加。すべてのサブエージェントに `CLAUDE_CODE_SUBAGENT_MODEL`（またはメインモデル）を適用し、スポーン時とエージェント定義のモデル指定を無視する
・`/effort` に `s` オプションを追加。`/model` と同様に現在のセッションのみ effort を変更可能
・強制終了されたセッションが残したサンドボックスマスクファイルに対する `/doctor` 警告を追加
・auto モードで、作業ディレクトリ外の最初のファイル読み取り前に一度だけプロンプトを表示。そのような読み取りをブロックするオプション（`permissions.blockReadsOutsideWorkingDirectories`）を追加
・ゲートウェイが提供する `description` を `/model` ピッカーの検出エントリ（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY`）でサポート。説明がないエントリは「From gateway」と表示
・起動後に作成された `.claude/` フォルダ内の設定が再起動するまで反映されなかったバグを修正
・`←` で開いたエージェントビューからディスパッチされたセッションが常に元セッションのパーミッションモードで起動し、対象ディレクトリの `defaultMode` やエージェントの `permissionMode` を上書きしていたバグを修正
・`keybindings.json` での Ctrl+G の再バインドが `claude agents` で無視されていたバグを修正。Ctrl+S / Ctrl+T も新しい `Agents` コンテキストで再バインド可能に
・self-update 中の macOS npm インストール時と、再利用されたプロセス ID を指す古いデーモンロックファイルがある Windows でバックグラウンドセッションが起動に失敗するバグを修正
・スラッシュコマンドパネルの裏でレスポンスがストリームされている間に作業中スピナーが停止するバグを修正
・バックグラウンドセッションの `state.json` の `detail` が、スケジュールされた wake-up 後に自身のディスパッチプロンプトを繰り返すバグを修正
・`claude agents` で再プロンプトしたバックグラウンドセッションが再度完了した後も Completed に埋もれたままになるバグを修正。Completed が最新の終了時刻順に並ぶよう変更
・削除済みディレクトリから `claude --bg` を実行すると「backgrounded」と報告してクラッシュしたセッション行が残るバグを修正。理由を表示して exit 1 するよう変更
・Remote Control がセッション途中に接続すると Bash ツール定義が再送信されてプロンプトキャッシュミスが発生するバグを修正
・Bedrock・Mantle・Vertex・WIF でカスタム `Authorization` ヘッダーが二重登録されて設定済み認証情報を上書きするバグ、および Vertex セットアップウィザードが `~/.config/anthropic` の残留 Anthropic プロファイルを拾うバグを修正
・Claude apps gateway が Foundry・Vertex・Bedrock に不正な `Authorization` やプロファイルヘッダーを送信するバグ、および `ANTHROPIC_FOUNDRY_API_KEY` 設定時に Foundry Entra ID アップストリームが起動しないバグを修正
・API キーモードで Foundry サブスクリプションキーと一緒に Anthropic API キーまたは認証トークンが送信されるバグを修正
・メッセージロールなしで保存されたプロンプトを持つ `/schedule` ルーティーンが何もせずに実行されるバグを修正
・`claude agents` で、バックグラウンドセッションが別のセッションからのメッセージ承認待ちであること、および送信元が誰かが表示されないバグを修正
・バックグラウンドセッション内で Ctrl+S でスタッシュしたプロンプトが、セッションがアイドルになるか停止して再度開いたときに失われるバグを修正
・サーバー管理設定経由でプッシュされたテレメトリー（OTEL）設定が、デスクトップアプリの Code セッションを含むウォームスタートで無視されるバグを修正
・チームメイトのパーミッションリクエストが、リーダーのメールボックス書き込みが一時的にロックされたときに二重に回答されるバグを修正
・スラッシュコマンドの自動継続レスポンスがストリームされている間に、進行中のターンの下にファントムの重複スラッシュコマンド行がレンダリングされるバグを修正
・タイマー最大値（2147483647）を超えた `policyHelper` の `timeoutMs` と `refreshIntervalMs` が失敗またはミリ秒ごとの再実行を引き起こすバグを修正。最大値にクランプするよう変更
・別のサブエージェントのトランスクリプトに切り替えた後にトークンカウンターがフリーズまたは極端に遅くなるバグを修正。バックグラウンドサブエージェントとチームメイトのカウンターがレスポンスストリーム中にリアルタイム更新されるよう改善
・末尾にドット（`example.com.`）付きで記述されたサンドボックスネットワークホストのバグを修正。`deniedDomains` エントリがサンドボックス内でホストをブロックせず、「再確認しない」が引き続きプロンプトを表示していた問題
・Remote Control の同意プロンプトを Esc または `n` で却下すると同意とみなされ、次のリクエストで確認なく接続されるバグを修正
・`/mcp` の再接続と有効化で、起動後にロードされた管理 MCP 許可/拒否リストまたは `strictPluginOnlyCustomization` によってブロックされるべき設定ファイルの MCP サーバーが引き続き接続されるバグを修正
・`strictPluginOnlyCustomization` が MCP をプラグイン専用サーバーに限定している場合、`claude mcp remove` がリモートサーバーの保存済み OAuth 認証情報を残すバグを修正
・`claude remote-control` セッションが Claude アプリから起動されたときに選択したモデルを無視してマシンのデフォルトで実行されるバグを修正
・`allowManagedPermissionRulesOnly` が有効なとき、最初の設定リロード後に `--disallowedTools` とセッション拒否ルールが削除されるバグを修正
・`--resume` が一時停止中の会話を二重リストし、`--continue` がその停止前のコピーを再開するバグを修正。`--continue` が完了したバックグラウンドセッションも開くよう変更
・フルスクリーンモードでシェルコマンド出力の `!` をクリックして展開できないバグを修正
・自動更新をまたいで古い Claude Code バイナリを実行したままのバックグラウンドセッションが蓄積される代わりに廃止されるよう修正
・`claude agents --json` が終了時に別プログラムのターミナル設定を元に戻す raw モードに一時的にターミナルを切り替えるバグを修正
・Proactive 出力スタイルのセッションが、バックグラウンドコマンドや Monitor が実行中にアイドルせず、フィラーメッセージと繰り返しのログ読み取りでビジーループするバグを修正
・コンピュータのスリープ・接続断・サーバーエラーでレスポンスがミッドストリームで切断されたときにサブエージェントが停止するバグを修正。不完全なレスポンスで終了する代わりに自動的に継続するよう変更
・`claude agents` セッション内の `/btw` パネルで `←` が何もしないバグを修正。エージェントリストに戻るよう変更（回答の途中でも機能）し、セッションを再度開くとパネルが戻るよう変更
・アドバイザーモデルが設定されたセッションで、バックグラウンドリクエスト（コンパクション・`/recap`・プロンプト提案）でプロンプトキャッシュが欠損し、毎回キャッシュなしで全会話を再送していたバグを修正
・`claude -p` が Monitor を起動した後、その Watch がまだ実行中なのに最終結果から約 5 秒後に終了するバグを修正。Watch が発火またはタイムアウトするまで待機するよう変更
・auto モード で、`permissions.ask` ルールが複合コマンドまたはサブシェル内で実行されたマッチコマンドでスキップされ、確認プロンプトなしに実行されるバグを修正
・プラグインが、宣言されたコマンド・エージェント・スキル・フックまたは他のコンポーネントのパスがシンボリックリンクである場合、自身のディレクトリ外のファイルを読み取れるバグを修正。そのようなパスはエラーで拒否されるよう変更
・`/add-dir` が現在の作業ディレクトリ内のディレクトリを拒否するバグを修正。起動時の `--add-dir` と同様にスキル・コマンド・エージェントをロードするよう変更
・メインエージェントが、停止したサブエージェントをトランスクリプトビューから再開したときに通知されないバグを修正
・ANSI カラーテキスト（CI ログなど）を `/feedback` などのダイアログに貼り付けたときのクラッシュを修正
・`claude mcp add/remove` がプロジェクトの `.mcp.json` が FIFO またはデバイスファイルシンボリックリンクのときにハングまたはメモリを使い果たすバグを修正。エラーで素早く失敗するよう変更
・非 JSONL データが `claude -p --input-format stream-json` にパイプされたときの無制限なメモリ増大を修正。わかりやすいエラーで素早く失敗するよう変更
・`←` または Ctrl+B でターンをバックグラウンド化している間にサブエージェントまたは他のツールが実行中だった場合、バックグラウンドセッションがそのツールを拒否済みとして扱うことがあるバグを修正
・Bash の `Read()`/`Edit()` 拒否ルールが `< file` リダイレクトと `tac`・`egrep` などのリーダーコマンドに適用されないバグを修正。引数またはリダイレクト先のいずれかに拒否ルールがあるとコマンドを拒否するよう変更
・多くの画像を読み込んだ後にトランスクリプトが 5 MB を超えたサブエージェントへの返信やメッセージが「No transcript found」で失敗するバグを修正
・ワークツリー分離セッションで、git にまったく触れない Bash ループ・`$VAR` 読み取り・`"$(…)"`・ヒアドキュメントが「ワークツリー内に留まることを確認するには複雑すぎる」として拒否されるバグを修正
・会話を空に巻き戻した後に `/model` と `/effort` がプロンプトキャッシュ警告を表示するバグを修正
・リクエストごとのサイズ上限を画像が超えた後、長いスクリーンショット多用セッションでプロンプトキャッシュミスが毎ターン発生するバグを修正
・Edit パーミッションプロンプトの差分ビューが絵文字や複数コードポイント文字を不正な幅でレンダリングするバグを修正
・WebSocket MCP サーバーの接続失敗が「\[object ErrorEvent]」としてログされるバグを修正
・npm 更新をダウンロード中の別の Claude Code プロセスがある間、「Couldn't start the background service」でバックグラウンドセッションが開けないバグを修正。起動が待機するよう変更
・`timeout` や `setsid` などでシェルからデタッチしたバックグラウンドコマンドが、タスク停止または Claude Code 終了後も生き残るバグを修正
・Claude がタスクパネルまたは接続クライアントからバックグラウンドコマンドを停止したときに通知されないバグを修正
・バックグラウンドサブエージェントを停止してもその Monitor が実行し続けるバグを修正
・サブディレクトリへ `cd` した後、リンクされたワークツリーでのサンドボックス化された git コマンドがリポジトリ共通の `.git` ディレクトリへの書き込みアクセスを失うバグを修正
・Opus 4.7 以降で Bedrock および Bedrock Mantle リクエストが長いhidden-thinkingフェーズ中に無音になり、アイドルタイムアウトが接続を切断するバグを修正。ストリームが進捗イベントを送信するよう変更
・Claude apps gateway の有効期限切れまたはセッション取り消し後に Claude Code を起動すると、ネットワークエラーを報告する代わにセッション終了と `/login` を案内するよう修正
・クラウドセッションが起動時にネットワークプロキシの起動に失敗したときに git/GitHub 認証情報を残りのセッション中失うバグを修正。バックグラウンドで再試行して回復するよう変更
・中断されたバックグラウンドデーモン起動後にシステム一時ディレクトリに残る `cc-daemon-*` フォルダを修正。`cleanupPeriodDays` 保持スイープで削除されるよう変更
・zsh が bash と異なる方法でパースする `[[ ]]` 条件式の一部を Bash パーミッションチェックが自動承認するバグを修正。これらのコマンドは承認を求めるよう変更
・設定が詳細なトレースやraw APIボディロギングをオフにする場合、またはトレースエクスポートをオンにする場合に、管理設定承認プロンプトがテレメトリー用の文言ではなく汎用警告を表示するバグを修正
・tmux/iTerm2 ペインのエージェントチームメイトがシャットダウンリクエストを確認した後も開いたままになることがあるバグを修正
・キーレス Console サインイン（「Console アカウントでサインイン」）が組織のサーバー管理設定を適用せず、`/status` がそのサインインで Organization を表示しないバグを修正
・レンダリングパフォーマンスを改善。長い会話での1ターンあたりの再レンダリング作業を削減し、ストリーミングがレスポンスの増大に伴って遅くなることがなくなり、バックグラウンドエージェントの更新が画面全体を再レンダリングしなくなった
・プロンプト入力の応答性をキー入力ごとのレンダリング作業を削減して改善
・ポリシーヘルパーの診断を改善。リフレッシュ失敗が `/status` に表示され、管理設定ダイアログを却下すると終了理由が表示され、タイムアウトがタイムアウトとして報告される
・`/code-review --comment` が GitLab マージリクエストに `glab mr note` 経由で発見事項をポストするよう改善（以前はサポート対象外として報告されていた）
・通知を改善。別のダイアログの下でキューに入った MCP エリシテーションまたはパーミッションリクエストが、表示されているリクエストと同じ遅延でアイドルデスクトップ通知を送信するよう変更
・詳細/トランスクリプト出力を改善。同時に到着した非同期フックの完了通知がフックごとに1行ではなく1行にまとめて表示される
・`claude self-hosted-runner --configure-git` を改善。git push ネゴシエーションも有効化し、古いクローンからの新規ブランチの最初のプッシュが全ツリーではなく新しいコミットのみをアップロードするよう変更
・レスポンスがゲートウェイ keep-alive で保持されている間、SDK ホストへのライブネス報告を改善。`CLAUDE_STREAM_IDLE_TIMEOUT_MS` を引き上げた長い待機がハングしたセッションと誤認されない
・MCP 接続と OAuth デバッグ/エラーログを改善。サーバーの URL やリクエストヘッダーに含まれる認証情報が編集されるよう変更
・`/fork` を改善。元の会話のプロンプトキャッシュを新しいバックグラウンドセッションに維持するよう変更。ワークツリーブリーフィングがシステムプロンプトの変更ではなくメッセージとして届くよう変更
・絵文字オートコンプリートを改善。残りの GitHub/Slack ショートコードエイリアス（`:satisfied:`・`:telephone:`・`:collision:` など）を受け付けるよう変更
・`--effort` を変更。新しいモデルのデフォルト effort ホールドをそのセッションのみ解除するよう変更（以前は永続的だった）。Remote Control セッションで claude.ai で選択した effort がホールド中に適用されるよう変更
・起動時にキャッシュされたサーバー管理設定によってシャドウされた MDM または `managed-settings.json` の `policyHelper` が、次回起動時ではなく、フェッチがそれらを削除したと報告した時点で実行（または終了）するよう変更
・`managedSourcesBehavior: "merge"` を変更。`sandbox.credentials.awsPairs` と `sandbox.ripgrep` を、それらを設定している最高優先度の管理ソースからまとめて取得するよう変更（以前はソースの値を結合していた）
・`CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` が設定されていてもゲートウェイモデル検出（`CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1`）を実行するよう変更（自分のゲートウェイのみに問い合わせるため）
・`claude --resume <session-id> --bg` を変更。何も実行していない場合にそのセッションを自身の ID で継続するよう変更（以前はコピーを無音で起動していた）。コピーは今後アナウンスされる
・`/btw` の履歴閲覧を `←`/`→` から `Shift+←`/`Shift+→`（または `[`/`]`）に変更。最近のサイドクエスチョンとライブ回答を切り替えて閲覧可能
・`.claude/settings.json` または `.claude/settings.local.json` の `defaultMode: "bypassPermissions"` を無視するよう変更。ユーザー設定または管理設定で設定するか、`--permission-mode` を渡す
・`fable` と `best` を Claude apps gateway セッションで引き続き Fable 5 に解決するよう変更（Fable 5.1 に未設定のゲートウェイがそれを拒否するため）。Fable 5.1 を使うには `/model` で選択
・`--add-dir`・`/add-dir`・`additionalDirectories` がネットワークパス（UNC 共有・`/net/<host>` オートマウント）を触れる前にメッセージで拒否するよう変更。Windows ではマップ済みドライブレターを使用
・Claude apps gateway のサインインとトークンリフレッシュリクエストがゲートウェイのピン留めされた TLS 証明書を検証するよう変更
・Cowork と claude.ai クラウドセッションを変更。自分のものでないアーティファクトを読み取る際に、auto モードでも常に事前に確認を求めるよう変更
・Bash および PowerShell パーミッションプロンプトから Ctrl+E のコマンド説明を削除
・\[VSCode] セッションリストパネルに折りたたみ可能な ACCOUNT & USAGE と SESSION MANAGER セクションヘッダーを追加。アカウントメール・使用量メーター・使用状況ダイアログを開く「View details」リンクを表示
・\[VSCode] 現在のモデルを表示してモデルピッカーを開くモデルピルを入力フッターに追加。Effort 行と「More models」ページを含む
・\[VSCode] セッションリストの Ungrouped セクションに折りたたみトグルを追加
・\[VSCode] コマンドメニューに出力スタイル選択（カスタムスタイルを含む）を追加
・\[VSCode] サードパーティプロバイダーデプロイメント（Bedrock・Vertex など）で claude.ai 専用機能（リモートセッション・ディクテーション・使用状況）が引き続き表示され、残留ログインで claude.ai を呼び出すバグを修正
・\[VSCode] パネルロード後もセッションリストパネルの使用量メーターが空白のままになるバグを修正。最後の既知の使用量を即座に表示するよう変更
・\[VSCode] 「Enable Remote Control for all sessions」トグルをオン/オフにすると、新しいセッションだけでなく既に開いているセッションにも適用されるよう修正
・\[VSCode] スクリーンリーダーのアナウンスを修正。フェンスや見出しの前のコントロール文字で可視行がスピーチから脱落しなくなり、見出しにまたがる太字マーカーの誤ペアが解消された
・\[VSCode] アクションメニューを変更。スラッシュコマンドをインライン表示からフィルタリング可能な「Slash commands」ダイアログに変更。選択すると実行される。MCP サーバーダイアログにも同じフィルターボックスを追加
・\[VSCode] 「Delete session」を「Archive session」に変更。アーカイブされたセッションはリスト下部の折りたたみ可能な「Archived sessions」グループに移動し、Unarchive アクションを持つ
